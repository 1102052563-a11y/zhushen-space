# 鬼戏台

鬼戏台是从鬼湖灵异中显现的未知县城内木制戏台，顶挂洁白长布、台下列满红漆长凳。看似空无一人，却有唱戏杂音；杨间判断台下红凳可能坐满需特定媒介才能看见的厉鬼。（原文回跳第1104章）

戏台布条与总部裹尸布、红凳与大东市曾遇红色木凳相似。县城灵异正在驱散鬼湖积水，队长因未知风险未触碰戏台，县城随后会否消失待后文。（原文回跳第1104章）

#### 原文回跳第1105章·李军试探红凳后撤离

李军以鬼火烧毁县城大部分衍生物，戏台未受影响；触碰红凳后，掌上出现孩童血手印，证实木凳上有不可见厉鬼。李军登台后，鬼火快速熄灭、至少二十余条红凳自行后移，队伍随即撤离，未直接触及戏台厉鬼。（原文回跳第1105章）
