# 大东市王家诅宅

王家诅宅位于大东市普通街道旁，外观是墙皮剥落、爬满苔藓的欧式民国老宅，外部仅有锈铁门和锁链，普通行人可接近。踏入铁门后，院落会扩展成堆满老旧棺材的巨大鬼域空间，古宅内部存在更强灵异干扰。（原文回跳第847章）

## 风险

李阳的堵门鬼在铁门处即被古宅灵异压制。杨间五层鬼域只能入侵到一楼大厅，无法覆盖古宅深处；熊文文预知指出正门会触发无法摆脱的古宅诅咒，队伍改从窗户突入。（原文回跳第847章、原文回跳第848章）

古宅内聚集十余名受摆钟诅咒的驭鬼者，三楼白发驭鬼者柳白穆等人可借环境伏击。六点钟声响起后，怀表时间倒退半小时，已死亡的驭鬼者连同体内鬼全部复现，证明古宅至少能在内部局部重启时间；范围、次数、代价和摆钟本体位置均不明。（原文回跳第848章、原文回跳第849章）

后续观察显示，重启者遗失回退的半小时记忆，被棺材钉压住的厉鬼不会随之复原；古宅时间六点的第二次钟响未触发重启。古宅还会出现每十二天显现一次的上行台阶门、无边黑暗房间及李阳遭遇的黑白媒介鬼，说明摆钟重启外仍有多层未知灵异。（原文回跳第850章至原文回跳第854章）

杨间清剿二楼和黑暗房间成员后撤离诅宅。古宅时间随后被陈桥羊影响而在前后半小时内紊乱，柳白穆人头被抛到外界，显示隐藏地牢异常已介入诅宅；杨间暂不深入台阶，改先向王察灵交涉。（原文回跳第855章至原文回跳第859章）
