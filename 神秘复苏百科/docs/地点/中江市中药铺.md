# 中江市中药铺

中江市老城区一条旧街上的中药铺。店铺年代久远、内部昏暗阴冷，普通人会下意识避开；杨间确认此处受灵异保护，外人无法彻底窥视内部。（原文回跳第1269章）

铺内以淡绿色鬼火油灯和蜡烛照明，店主瞎眼老人、女子小茹均带有异常灵异状态。陈桥羊、张羡光等上一辈驭鬼者与此处有关，且此处传闻可医治厉鬼复苏。（原文回跳第1269章）

杨间到访时获老人承认：其与大川市王家古宅的老尸是故人。药铺的治疗方式、完整规则和民国时期关联待后文。

#### 原文回跳第1270-1271章·延缓复苏的中药与民国选择

老人说出罗文松、李庆之、张洞、孟小董、张幼红、罗千等民国驭鬼者姓名，并称药铺不负责根治厉鬼复苏，只以特殊中药延缓复苏、尽量延长驭鬼者探索的时间。（原文回跳第1270章）

杨间获赠三包灵异中药。老人准备在死后由小茹用太平古镇棺材铺的棺材料理后事，并让中药铺一同消失；其死亡时间、药物具体配方和服药代价待后文。（原文回跳第1271章）

#### 原文回跳第1292章·首次实战压住刘奇复苏

杨间在白水镇将一包灰白药末强塞入灵异失衡的刘奇腹中。药力短时间内压住其体内多只鬼，使濒临复苏的刘奇恢复意识和五官，证实药铺中药确可强行延缓复苏；持续时长与药效消退后的后果待后文。（原文回跳第1292章）
