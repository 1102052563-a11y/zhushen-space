# 灵异公交古宅鬼林

鬼林位于灵异公交古宅外，正常沿小路穿行时可暂时阻止公交下车厉鬼和灵异雨水进入；但离开小路擅自抄近道会迷失其中。（原文回跳第916章、原文回跳第920章）

万州与两名驭鬼者错过公交后进入鬼林，先后遭遇成组黑影与树后探头的密集厉鬼，被困死。三人死亡后，树林外围多出三棵颜色较浅的新树，显示鬼林可能把死者转化或吸收为树林一部分；转换机制和新树是否等同厉鬼均待后文。（原文回跳第920章）

第三日，白灯笼保护下的杨间等人确认鬼林后方有五座老坟与对应白米饭祭品；树下埋有大量尸体，部分穿黑衣，部分裹破白布，挖掘会使对应怪树在第四日倒塌、释放灵异。鬼林本身具广域迷失效果，周登深入后遭大量黑衣鬼追杀，须以人皮面具伪装、盖脸纸假死逃生。（原文回跳第935章至原文回跳第938章）

第六日出殡，黄泥小路唯一通往五坟空地。301室老婆婆能在鬼林中自由往返，不受迷失影响；周登将其引入老林后，鬼很快折返，且因周登被抹除增殖出第二只。此处抹除规则与鬼林迷失共同封锁抬棺队，逆转结果待后文。（原文回跳第955章至原文回跳第959章）
