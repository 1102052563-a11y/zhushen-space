# 88号房

88号房是凯撒酒店异常走廊内的电视灵异房间。房中老式电视无需电源即可显示房间画面，画面按阶段推进：厉鬼坐沙发、起身、贴近屏幕后观看另一台电视。（原文回跳第1154章）

杨间触碰电视后被置换进电视画面，外界李阳等只能看见其站在门口。每完成一轮画面，房中会多出一只厉鬼，电视黑屏时被困者进入更深层88号房；其脱离方法和累积上限待后文。（原文回跳第1154章）

杨间在深层卧房找到楚南、朱见、董玉兰等人留下的血字，证实楚南真实复活房是701号、88房厉鬼坐在沙发。杨间以鬼湖水经电视媒介反向穿透嵌套，依次回到三鬼、二鬼和现实层88房脱困；该房可困死队长级驭鬼者。（原文回跳第1155章、原文回跳第1156章）
