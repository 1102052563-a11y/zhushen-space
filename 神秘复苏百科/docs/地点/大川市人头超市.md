# 大川市人头超市

## 概述

大川市人头超市是一家被改造成大量人头储存点的大型购物超市。货架不再摆放商品，而是整齐陈列不同年龄、性别的新鲜人头；腐坏人头会被鬼奴取下、放进购物车处理，再为无头身体换上新头。此地是杨间通过李乐平卫星定位手机找到的地点，和大川市换头异常存在直接联系。（原文回跳第797章、原文回跳第798章）

## 运作表现

两名被灵异侵蚀的拼接者负责维护：一人推车收集开始腐烂的人头，另一人从货架取新头装回无头身体。头颅被装回后，身体会重新活动；杨间判断这些维护者属于鬼奴而非源头。人头为什么需要持续替换、货架人头总量与来源、是否所有人头都仍有意识均不详。（原文回跳第798章）

货架上出现与李乐平外貌完全一致的人头，旁边摆有其卫星定位手机。杨间由此判断白天接待自己的“李乐平”是借记忆与人头伪装的假身份，而真正李乐平可能已死或仍因其被遗忘特性藏在某处；这只是结合现场作出的判断。（原文回跳第798章）

## 围困与影子线索

杨间、李阳进入后，城市内大量无影鬼奴涌入超市并包围两人。源头通过不同鬼奴反复回应问题，显露其身体腐烂、不断替换身体的需求；开灯后，杨间确认鬼奴无影而自己与李阳有影，推断源头会以影子作为袭击媒介。（原文回跳第798章、原文回跳第799章）

杨间首次以棺材钉压制一名鬼奴未成功，后见一具鬼奴脚下出现有五官的残缺人头影子，并与自己的无头鬼影试图拼接。李阳以胸口女尸鬼干扰该影子，未能完成关押；杨间暂定其为无头鬼影缺失的人头拼图，但其完整能力、源头是否仅有一只和超市能否关押它均不详。（原文回跳第799章）
