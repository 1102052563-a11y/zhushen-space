# 明月小区

明月小区位于大川市未拆迁老城区深处，由约九至十栋五层老楼组成，建成约三十余年。其附近拆迁时爆发灵异事件，负责人李乐平介入后将老城区封锁，事件被代号为“猛鬼区”。鬼邮局二楼红信与三楼黄信均指定向小区7栋301室投递，说明该址与邮局存在持续关联。（原文回跳第783章、原文回跳第791章、原文回跳第806章）

## 已知环境

小区外表为淡绿色旧楼、楼道使用砖砌菱形窗；进入后则被灰黑浓烟覆盖，墙面、地面与树木皆被熏黑。浓烟有焦尸气味，呼吸会使活人体内如被灼烧、逐步脱水，普通人久留可变成干尸；杨间因无头鬼影持续修复侵蚀而受影响较小。（原文回跳第807章）

浓烟是李乐平驾驭厉鬼形成的鬼域。他曾伪造张小小等同伴资料，将其称为死后遗留厉鬼；后亲自说明浓烟鬼域、鬼找人与梦游鬼均属于自己。它令室外看似正常、内部却呈烟域状态；鬼域强度和持续范围只能按杨间现场估计，不能据此确认全部机制。（原文回跳第807章、原文回跳第814章）

## 徘徊风险

李乐平遗留的手机短信称，小区及猛鬼区至少有三只鬼：仅夜间活动的梦游鬼、藏在浓烟内且会“找人”的厉鬼，以及一只身份和规律未知的原生厉鬼。后续确认前三者均为李乐平自身驾驭厉鬼，301室倒视人偶才是独立未知灵异。李乐平曾在此遭遇凶险后遗忘整日经历，故301室相关规律仍有大量空缺。（原文回跳第806章、原文回跳第807章、原文回跳第814章）

杨间一行入内后，在烟域中发现一具穿负责人制服、胸牌写有“李乐平”的熏黑干尸。该尸体与仍有电话、短信指引的“李乐平”身份冲突，尸体是否为本人、是否被鬼影头伪造均未确认。（原文回跳第807章、原文回跳第808章）

## 7栋301室

杨间等人抵达疑似7栋的301室时，房内亮着与鬼邮局相似的昏黄灯光，室内未被浓烟熏黑，且有灵异力量驱散门外烟域。杨间判断其中存在厉鬼或灵异物品，但尚未确认具体实体；他进入后身影在灯光中消失，李易、杨小花、柳青青随后跟入，信件尚未确认送达。（原文回跳第809章）

黄信被杨间留在301室地面后任务完成。倒视可见的人偶灵异随即追出房间，杨间重启八音盒、以六层鬼域和柴刀将其拆散；该事件证明301室至少仍存在高危灵异，其他房间和物品未完成调查。（原文回跳第811章至原文回跳第814章）
