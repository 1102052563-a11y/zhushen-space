# 王家厉鬼地牢

王家厉鬼地牢位于诅宅三楼每十二天出现一次的木门之后。进入上行台阶须闭眼倒退十级，才会在身后出现锈铁门；门后是规模大于诅宅本体的昏暗牢房走廊。（原文回跳第853章、原文回跳第855章）

牢房以间隙很大的锈铁栅栏分隔，没有关人用的牢门，却存有不腐尸体、红漆木凳、黑暗囚室、残破栅栏和无形脚步等多种灵异异常。陈桥羊确认此处为王家数代用于关押厉鬼的地牢，地牢维持机制与栅栏为何能关鬼均不明。（原文回跳第856章、原文回跳第858章）

陈桥羊被诅咒笔记困于书桌前，获张庆、万铜合上笔记后脱困，并意图释放地牢中的厉鬼。其后古宅出现巨大撞击、时间紊乱和错误钟声，地牢风险已外溢；具体逃出厉鬼数量尚未确认。（原文回跳第858章、原文回跳第859章）
