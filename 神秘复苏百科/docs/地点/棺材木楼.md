# 棺材木楼

棺材木楼是亡魂道路深处一栋独立两层木楼，屋檐挂有五颜六色霓虹灯，周围亡魂会主动避开。楼内一层横放十余口褪色旧棺，二层有无来源的昏黄光亮。（原文回跳第1293章、原文回跳第1294章）

杨间在楼内发现鬼童手脚印，确认王珊珊曾到此查探。鬼童足迹由一层进入二层，再从一扇在外部无法辨认、无法打开的后门离开；其通往何处待后文。（原文回跳第1293章）

杨间进入二层房门后，狂风抹去木楼环境，将其置入看似三年前大昌市的旧出租屋，并取代当时的自己；七层鬼域重启无法脱离。该区域是否是真实过去、记忆或其他灵异空间待后文。（原文回跳第1294章）

#### 原文回跳第1295-1299章·确认连接白水镇过去映照

杨间和先一步进入的王珊珊确认，二层门后并非可改变的真实三年前，而是白水镇范围内映照出的过去区域。人皮纸利用王珊珊将自身带入此处，杨间则在区域内被预示会于当日六点十分死在白水镇；离开方法待后文。（原文回跳第1295章至原文回跳第1299章）

#### 原文回跳第1315-1319章·映照崩散后的多鬼木楼

过去映照崩散后，杨间、王珊珊和鬼童实际仍在木楼二层；房内木架摆有无眼皮、眼眶幽暗的干尸。张洞的最后袭击使杨间意识卡在虚幻与真实夹缝，肉身暂无法行动。（原文回跳第1315章、原文回跳第1316章）

木楼不是单一厉鬼，而是棺材、地板、木柱、窗户、楼梯等多处构件各自承载灵异。刘奇以血媒介将恶犬引入后，一楼棺材开启、二楼地板化为会进食的八仙桌映照，木柱、窗户和楼梯亦开始复苏；截至第1319章，王珊珊、刘奇、鬼童与杨间均未离开木楼。（原文回跳第1317章至原文回跳第1319章）

#### 原文回跳第1320-1324章·合棺反噬与楼梯鬼域

王珊珊合上无头尸体所在棺材后，二楼餐桌鬼暂时撤离，但其余棺材与建筑构件同步复苏，证明单独合棺不能视为安全关押。杨间苏醒后救出刘奇、鬼童，再以鬼火在楼梯鬼域中开路。（原文回跳第1320章至原文回跳第1324章）

楼梯鬼域会改变距离、显出无尽黑暗与分叉台阶，追随者为闭眼老尸；杨间仅以棺材钉暂时压住该尸，未确认其是否为楼梯灵异源头。众人截至第1324章仍在楼梯内，未离开木楼。
