# 油画世界鬼邮局

油画世界鬼邮局位于一楼、五楼油画共同连接的灵异空间深处，外观与现实鬼邮局一致。通往各油画景象的岔路均汇入该处，杨间在此首次发现完成五楼三信者的意识备份群体。（原文回跳第1007章、原文回跳第1008章）

这里收容的是完成最终送信、离开现实邮局者的灵异备份。备份可保有生前部分灵异能力和意识，但不能离开油画世界；外界无人记得其存在时，备份将消失。张羡光将此称为灵异囚笼或无间地狱。（原文回跳第1008章）

杨孝、张羡光等亡魂同意杨间的改造计划，准备借鬼画获得有限的现实活动范围、协助处理灵异事件。该空间内亦存放厉鬼油画和危险染缸，完整地图、出口及实际管理权限仍待后文。（原文回跳第1009章至原文回跳第1014章）
