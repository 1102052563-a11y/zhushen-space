# 太平古镇

太平古镇是中州市近郊、可追溯至民国的旅游古镇，鬼湖与现实连接的小河经此流过。外部新街仍有游客和商铺，旧牌坊之后则隐藏受灵异影响的老街；杨间、李军、沈林、柳三据此锁定此处为鬼湖关键连接点。（原文回跳第1058章）

古镇内存在需五层鬼域才能显现的隐藏古街，街中有跨年代行人影像、面具摊和异常三元纸币。杨间进入后鬼域被压制；纸人柳三靠近祠堂时被独眼男子识破为死人并喝退。古镇、古街、祠堂与鬼湖的具体关联待后文。（原文回跳第1059章）

午夜时，鬼湖连接河道的废弃渡口会被浓雾覆盖，黑色渡船携油灯靠岸。队长以异常纸钱付船费后，渡船驶离现实，沿河通往鬼湖灵异空间。（原文回跳第1064章）
