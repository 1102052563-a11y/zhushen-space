# 100号房

100号房是香兰的信息记录房，室内暂未发现厉鬼。桌上摆有冷饭、热菜和插红筷的供祭，留有记录她反复探索异常走廊的笔记本。（原文回跳第1164章）

笔记记录104号飞骨必杀、105号暂休、49号需跟唱鬼歌、38号火炉须投骨等规则，并将出口线索指向1号房和10号房。笔记末页出现字迹异常警告“当你打开这本笔记的时候就说明鬼已经在你身边了”，后果待后文。（原文回跳第1164章、原文回跳第1165章、原文回跳第1166章）

笔记倒翻后会随页面依次预告门口一至四只鬼、背后鬼，且现象确实发生。童倩以鬼脸转头看见死尸而未触发袭击；三人离开后，笔记仍提示身后鬼持续跟随，具体规律待后文。（原文回跳第1166章、原文回跳第1167章）
