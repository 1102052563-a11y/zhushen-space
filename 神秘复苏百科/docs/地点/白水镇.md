# 白水镇

白水镇是大山市一座依水而建的小镇。王珊珊带鬼童前往外婆家后失联，大山市负责人萧阳亦在此失联，杨间与刘奇遂进入调查。（原文回跳第1280章）

小镇超过半数建筑不在总部最新地图上，显示其正与未知灵异地域缓慢重叠。白天，萧阳的鬼雨侵蚀镇民，使其陷入无意识、近似不死的沉睡状态以避开厉鬼；夜晚六点后，街道、鬼店和游荡鬼全面显现，成为危险的鬼镇。（原文回跳第1280章至原文回跳第1284章）

## 已知区域

- **王珊珊外婆家**：王秀丽受灵异侵蚀、失去心跳呼吸却未死亡，杨间以黄纸暂时压制其异常。（原文回跳第1281章）
- **鬼旅店、面馆、服装店**：夜间开启的灵异店铺。服装店内多件衣物实为厉鬼伪装，杨间取回鬼寿衣后曾遭其中厉鬼围堵。（原文回跳第1283章、原文回跳第1284章）
- **亡魂道路**：夜间有被雨水侵蚀的行人和死者亡魂混杂行走；传言可带回死去亲人，但进入者多迷失并成为行尸走肉。王珊珊与鬼童沿此路失联。（原文回跳第1284章）

#### 原文回跳第1285-1289章·六点转移计划与亡魂道路恶化

萧阳与杨间定于次日早上六点、灵异和现实交替时转移镇民。夜间深入后，纸花标记现实边界消退；亡魂道路会令进入者迷失、与同伴分散，并显现阻拦带亡魂离开的厉鬼。（原文回跳第1285章、原文回跳第1287章至原文回跳第1289章）

#### 原文回跳第1290-1294章·鬼雨中断与棺材木楼线索

萧阳在亡魂道路死亡，鬼雨停下，白水镇活死人状态将失去维持。杨间救回刘奇后仍追随鬼童足迹，于道路深处发现摆满旧棺的独立木楼；木楼二层入口可将人置入疑似过去的大昌市。（原文回跳第1290章至原文回跳第1294章）
