# 古宅红房

古宅红房位于右侧第二间上锁房内，黄铜钥匙开启后显现。房内红墙、红地板、红布条和红灯笼如旧式婚房，但红色架子床、鬼橱、条凳、衣架衣物、镜子与化妆物品均已缺失。（原文回跳第941章）

短暂苏醒的民国驭鬼者意识称，房间及散落的红色物件均是一只厉鬼的拼图，正试图复苏。杨间据空位与已知物品推断鬼橱、301室红架子床等可能源于此处；这是基于现场对应的推断。（原文回跳第941章、原文回跳第943章）

杨间离开后，房门和过道中对应位置一并消失，其他人未察觉其开门、交谈经过。红房是否由民国意识主动转移、是否还会再次出现均待后文。（原文回跳第943章）
