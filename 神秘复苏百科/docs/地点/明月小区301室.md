# 明月小区9栋301室

异常源实际位于明月小区9栋301室，而非鬼邮局信件写明的7栋301室。外部无法看见室内灯光，杨间踹开门后才见昏黄灯光外泄；房间干净得像被固定在某个时刻，能抵住小区浓烟鬼域。杨间一度将黄信误放此处，后取回；真正7栋301室为空房，黄信随后自行消失，送信任务仍告完成。（原文回跳第809章至原文回跳第811章、原文回跳第825章）

## 室内线索

客厅红漆木桌、民国式餐具纹样与鬼橱曾交易的蛋炒饭盘子相似。右侧房内留有疑似制作替死布娃娃的布头、头发、针线和未完成娃娃，也有无脸女木偶、空神台及扭曲人物素描；杨间据此猜测房主可能为与民国灵异有关的人物，但本批未能确认其身份。（原文回跳第810章）

客厅菜篮原有一只闭眼、皮肤青紫的人偶婴儿。人偶消失后，杨间按柳青青提示倒转视线，才见木桌下藏有一个浑身淤青的无衣成年人形厉鬼，手持人偶。倒视接触其目光会触发追杀；该鬼从301室追出后被杨间柴刀肢解，人偶本体也同步被拆为碎块。（原文回跳第810章至原文回跳第813章）

## 当前风险

杨间后续进入左侧卧房，发现一张能屏蔽鬼眼的红漆木床，床上躺着枯瘦老人尸体并持有黄信。柴刀媒介显示尸体曾起床取信，且媒介中的老人会部分侵入现实，说明该尸体与301室原主人有关；其完整规律、身份和是否已真正复苏未明。（原文回跳第818章、原文回跳第819章）

黄信被取走后，301室房门无法以普通方式关住，门后疑有灵异可随时外出。杨间认为信可能加速房内平衡破坏，但也可能仅是提醒外界；301室外已出现黑白色媒介老人及疑似红旗袍相关灵异，具体失控程度待后文。（原文回跳第819章）

杨间以六层鬼域暂停楼内灵异后取回黄信，随后离开并以二十米高、五米厚的围墙封锁整个明月小区。9栋301室原主人尸体仍在其中游荡，杨间将后续处置交给李乐平；围墙主要隔绝普通人，不能视为对高阶灵异的完整关押。（原文回跳第825章）

倒视人偶被拆散仅说明暂时失去行动能力，不表示301室已安全；鬼邮局为何选定此处、房间与鬼橱及替死布娃娃的实际关系仍待后文。（原文回跳第810章至原文回跳第819章）
