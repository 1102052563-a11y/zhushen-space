# 原文回跳第1070-1074章剧情梗概

## 原文回跳第1070章·浮尸围船

白烛引发女尸大批围攻渡船。杨间以六层鬼域暂时停住尸体，配合李军将其送入鬼画世界；沈林则离船深入记忆，试图寻找鬼湖源头。（原文回跳第1070章）

## 原文回跳第1071-1072章·沈林反遭源头驾驭

沈林在鬼湖尸体记忆中发现太平古镇渡口黑棺与棺中女尸线索，却被源头厉鬼反向驾驭。他重启无效，只能侵入杨间记忆求救，源头随之继续追入杨间四年前的高中记忆。（原文回跳第1071章、原文回跳第1072章）

## 原文回跳第1073章·黑狼狗阻断记忆入侵

杨间高中记忆中寄存的黑色狼狗群追击源头厉鬼。现实安全屋木棺同步打开、仅留黑毛；狼狗可不断重启，源头厉鬼被持续撕碎，杨间身体却开始受鬼湖灵异侵蚀。（原文回跳第1073章）

## 原文回跳第1074章·全员沉湖与取代规则

杨间被侵蚀、李军被女尸拖下湖，渡船沉没，阿红和柳三也随之落入鬼湖。记忆中的源头厉鬼最终被狼狗撕碎，按沈林灵异的取代规则，杨间将接管鬼湖源头；接管尚未完成，众人生死未明。（原文回跳第1074章）
