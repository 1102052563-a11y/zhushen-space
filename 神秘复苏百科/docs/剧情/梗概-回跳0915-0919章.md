# 原文回跳第915-919章剧情梗概

## 原文回跳第915-916章·最可怕的熄火与逃入老林

灵异公交在十三鬼同车时熄火，所有乘客与鬼被迫下车。杨间带李阳、杨小花逃向古宅方向；秦开被冻尸鬼杀死，老林暂时阻隔公交下车厉鬼。（原文回跳第915章、原文回跳第916章）

## 原文回跳第917章·遗落的古宅

杨间确认老林尽头的古宅与鬼橱照片背景相同。红信信使和部分公交乘客进入宅内，周登想取红灯笼，被杨间暂时制止。（原文回跳第917章）

## 原文回跳第918-919章·未入殓的人与褪色灯笼

古宅大堂有未入殓老人尸体、后堂有棺。右侧第二间锁房与鬼橱钥匙匹配，杨间决定送信成功前不开门。午夜后宅门红灯笼褪为带“奠”字的白灯笼，古宅显出丧事异变。（原文回跳第918章、原文回跳第919章）
