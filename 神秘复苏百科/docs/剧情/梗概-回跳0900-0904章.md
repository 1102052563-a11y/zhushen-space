# 原文回跳第900-904章剧情梗概

## 原文回跳第900章·飘落下来的信

侵蚀信使鬼被压制后，404众人熬过夜晚。晨间仅少数四楼信使幸存，天井飘下一封系在红色气球上的红信。（原文回跳第900章）

## 原文回跳第901章·红色的气球

杨间取得红信和红色气球，确认气球能将带灵异的目标升空并压制，普通人杨小花可正常携带，遂将其交给杨小花保管。（原文回跳第901章）

## 原文回跳第902章·四条要求

红信要求所有四楼信使三日后在大昌市长安路口乘公交，三站后下车，在古宅住七日，并在第七夜零点向收信人交信。杨间判断公交大概率是灵异公交车。（原文回跳第902章）

## 原文回跳第903-904章·线索汇聚与败退

杨间向孙瑞承诺十日内登上五楼，随后把王善尸体封入黄金箱、修复身体。他认为鬼邮局、公交、鬼橱与鬼画线索正汇聚；李阳提出公交中途下车疑点，二人推测可能要等鬼拦车或熄火。熊文文是否随队仍未决定。（原文回跳第903章、原文回跳第904章）
