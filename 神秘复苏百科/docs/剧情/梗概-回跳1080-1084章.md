# 原文回跳第1080-1084章剧情梗概

## 原文回跳第1080-1081章·分割鬼湖救人

杨间无法直接压制融于湖水的银子厉鬼，但确认自身已窃取近四成鬼湖灵异。他分割湖水建立无水界限，救出曹洋和阿红；柳三则被太平古镇旧人夺走纸船，重新沉湖。（原文回跳第1080章、原文回跳第1081章）

## 原文回跳第1082-1083章·古镇旧人与杨间冲突

杨间、曹洋、阿红和古镇四名旧人对峙。油灯阻挡六层鬼域，独眼老人以茶杯挡柴刀又被媒介肢解；妇女以死人衣限制杨间，杨间沉入自身湖水脱衣反制。（原文回跳第1082章、原文回跳第1083章）

## 原文回跳第1084章·黑狼狗强制入梦

黑色狼狗完成鬼梦取代，经鬼湖水面投影现实并扑向古镇旧人。刘老板以七元纸钱避开袭击，妇女被强制入梦、独眼老人半入梦；狼狗能无视现实距离和清醒状态，局势反转。（原文回跳第1084章）
