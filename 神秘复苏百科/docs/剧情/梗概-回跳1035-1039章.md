# 原文回跳第1035-1039章剧情梗概

## 原文回跳第1035-1036章·学习会灵异杀人

学习会熄灯不再是恶作剧，学生杨子锋离奇死亡、尸体在两条楼梯间移动。苗小善带刘紫、孙于佳举鬼烛撤离；万皓等人发现鬼烛可保命后抢走蜡烛，抛下三名女生。（原文回跳第1035章、原文回跳第1036章）

## 原文回跳第1037-1038章·杨间驰援与高明接手

苗小善发送定位求助，杨间从大昌市鬼域赶至大京市，将三人救出。他判断事件是有人借灵异力量杀人而非自然失控；万皓被杨间重伤，高明到场后接手审查与善后。（原文回跳第1037章、原文回跳第1038章）

## 原文回跳第1039章·安置鬼画别墅

杨间将苗小善、刘紫、孙于佳安置进原贺天雄的黄金别墅。安全屋仍封存鬼画衍生物，杨间确认画中鬼没有入侵现实，计划把画转至地狱公寓，借其连接油画亡魂。（原文回跳第1039章）
