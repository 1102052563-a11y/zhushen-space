# 原文回跳第960-964章剧情梗概

## 原文回跳第960-961章·借尸抹鬼与八层重启

杨间让鬼影携鬼眼借用红棺民国老人尸体，获得强制抹除灵异的能力，消去两只完整老婆婆；随后开启八层鬼域重启约半小时，救回周登、杨小花、李阳和柳青青。（原文回跳第960章、原文回跳第961章）

## 原文回跳第962-963章·平静下葬

重启后的出殡路平安，众人在五座老坟旁立第六座坟并下葬红棺。杨间强行从老人尸体脱离、回归自身，队伍返宅等候最后一天。（原文回跳第962章、原文回跳第963章）

## 原文回跳第964章·第七天开始

古宅第七日零点前，周登与李阳从四把黑色太师椅和老人尸体首日换椅异动，推断椅子可能本有七把且彼此互通。五名幸存者在第七日零点汇合，等待收信人出现。（原文回跳第964章）
