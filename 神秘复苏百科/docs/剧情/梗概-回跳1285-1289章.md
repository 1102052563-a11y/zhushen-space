# 原文回跳第1285-1289章剧情梗概

## 原文回跳第1285-1286章·挽联失守与衣鬼关押

萧阳希望在次日六点让杨间带走白水镇居民。服装店五只衣鬼循杨间而至，逐步耗尽门前挽联；杨间以鬼火压制衣中厉鬼，再以鬼湖将五件衣服关押，随后与刘奇、萧阳继续搜寻王珊珊。（原文回跳第1285章、原文回跳第1286章）

## 原文回跳第1287-1288章·深入亡魂道路

三人追随恶犬进入亡魂道路后分散。杨间焚毁围来的熟人亡魂，主动斩断复活旧人的念想；刘奇、萧阳则不舍亲人，决定冒险带刘奇父亲亡魂离开。（原文回跳第1287章、原文回跳第1288章）

## 原文回跳第1289章·带亡魂离路受阻

亡魂只能由亲属牵引，刘奇以转移诅咒削弱前行阻力，并与萧阳压住下水道鬼的手臂。二人随后遭三只残缺女鬼围困，鬼烛无法点燃，萧阳要求刘奇放弃亡魂以求生，结局待后文。（原文回跳第1289章）
