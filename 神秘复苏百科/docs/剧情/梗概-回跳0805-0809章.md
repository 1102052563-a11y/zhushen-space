# 原文回跳第805-809章剧情梗概

## 原文回跳第805章·活命机会

杨间确认箱中被棺材钉压制的鬼影头是无头鬼影缺失的头部。完整拼图或能提升鬼影、压制鬼眼和柴刀诅咒，但李乐平的失败证明意识侵蚀风险极高；杨间仅考虑人皮纸或鬼橱等方案，没有立刻行动。杨小花为脱离鬼邮局请求投靠，杨间提出李易、柳青青、杨小花进入猛鬼区探路，活下来才带其脱离邮局；三人接受。（原文回跳第805章）

## 原文回跳第806章·废弃城区

五人进入大川市猛鬼区。李乐平留在废墟中的手机短信称：明月小区至少有夜间活动的梦游鬼、会找人的浓烟鬼和一只未知厉鬼，自己曾不得不遗忘整日遭遇。杨间决定不先投信，而要确认信件接收者和301室的真相。（原文回跳第806章）

## 原文回跳第807章·熏黑的小区

队伍进入明月小区，外界阳光瞬间被焦臭浓烟鬼域取代，普通人呼吸会被侵蚀、熏成干尸。途中发现穿负责人制服、胸牌为“李乐平”的熏黑尸体，电话留言者身份再起疑云。杨间压下使用鬼眼鬼域的冲动，继续朝疑似7栋推进。（原文回跳第807章）

## 原文回跳第808章·浓烟中的异常

接近第三排楼栋时，杨间发现鬼找人从浓烟中靠近，李易的灵异浑水也验证鬼在附近。众人躲进第二排住户内房，李阳发动堵门鬼拦截。鬼找人进入客厅翻找，最终以焦黑枯手触碰内房门，浓烟仍从门缝侵入，堵门鬼逐渐无法支撑。（原文回跳第808章）

## 原文回跳第809章·301室

李阳主动断后，杨间留下替死布娃娃，带李易、杨小花、柳青青破窗跳下并到达301室。替死布娃娃引走鬼找人，李阳从窗口生还，却在原房听见声音自称李乐平。301室内亮着类似鬼邮局的昏黄灯光、未受浓烟侵蚀；杨间为查明真相先进入，三名信使随后跟入，信件是否送达仍未确认。（原文回跳第809章）
