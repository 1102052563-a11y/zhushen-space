# 原文回跳第1050-1054章剧情梗概

## 原文回跳第1050章·准备与鬼橱积水预警

杨间为鬼湖行动制作可使人被忽略的惨白戒指，并与冯全分配物资。鬼橱化为持续渗出浑水的诅咒重新出现，杨间暂不交易，怀疑其在预示鬼湖风险。（原文回跳第1050章）

## 原文回跳第1051章·中州市队长会合

杨间、冯全抵达中州市，与李军、阿红、柳三、沈林会合。柳三在李军和杨间逼问下证明真身已到；沈林以共同记忆重叠现实的方式现身，杨间拒绝担任领队。（原文回跳第1051章）

## 原文回跳第1052-1053章·白烛引出的淹没之城

白色鬼烛引出鬼湖污染，死城内浮肿尸体、浑水和湿气蔓延，水位不断上涨。李军鬼火可暂时烧掉污染却不能触及源头。队长们判断鬼湖不直接存在现实，需要媒介才能进入，决定分头调查。（原文回跳第1052章、原文回跳第1053章）

## 原文回跳第1054章·各自探查

杨间通过柴刀发现水中尸体来自外地，命冯全在城市四方点白烛以定位鬼湖范围。柳三用纸人覆盖女尸追踪线索；沈林重演中州市旧景并取代一名年轻人，准备经历其死亡以查明规律。（原文回跳第1054章）
