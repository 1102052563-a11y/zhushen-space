# 原文回跳第1225-1229章剧情梗概

## 原文回跳第1225章·卖货郎暂时收货

杨间以鬼影把静悄悄显现体踢入卖货郎收货范围，卖货郎将其收入货箱，曹洋暂时摆脱追索并承诺赴会，但静悄悄源头仍可再现。（原文回跳第1225章）

## 原文回跳第1226-1228章·叶真挑战王察灵

叶真强行与王察灵开战。王家一代爷爷奶奶亡魂压住叶真，叶真虽借替死能力数次复原、甚至将伤害转移给王察灵，仍无法胜出，最终认输。（原文回跳第1226章至原文回跳第1228章）

## 原文回跳第1229章·古宅摆钟与敲打

杨间潜入王家古宅，在摆钟正确位置留鬼湖水媒介，暂不以高代价取钟。叶真离开后，杨间承认曾借叶真试探王察灵，并要求其参会；王察灵在压力下同意。（原文回跳第1229章）
