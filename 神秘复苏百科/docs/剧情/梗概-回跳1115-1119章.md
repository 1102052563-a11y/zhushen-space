# 原文回跳第1115-1119章剧情梗概

## 原文回跳第1115-1117章·大澳市踩点

杨间抵达大澳市，确认骆胜暗中监视。鬼眼排查中，他发现大兴娱乐城存在灵异、居民楼有同款古宅铜锁封门，以及一间以被锁死尸厉鬼产尸油的民国餐厅；他只取走尸油样本。（原文回跳第1115章至原文回跳第1117章）

## 原文回跳第1118章·茶餐厅定赌

杨间在新记茶餐厅现身，惩罚何老板保镖，并以娱乐城赌局解决争端。何老板否认索要尚通大厦，杨间仍认定有人借其设局，约定赴娱乐城继续赌。（原文回跳第1118章）

## 原文回跳第1119章·八亿积分赌命

杨间设定每赢一亿积分便取对方一命、八亿对应何老板等八人，放何老板离开召集幕后援手。熊文文、张伟等进入娱乐城，杨间以水杯中的黑狼狗倒影保护江艳并监视全局。（原文回跳第1119章）
