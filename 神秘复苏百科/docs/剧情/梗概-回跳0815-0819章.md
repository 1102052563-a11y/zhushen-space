# 原文回跳第815-819章剧情梗概

## 原文回跳第815章·再次亮起的灯

李乐平承认异类化成功一半，并称明月小区是其自困地。杨间判断与其开战收益有限，暂时交涉；但301室所在楼整栋亮灯，柳青青疑似仍留在房内，新的异常迫使杨间回查。（原文回跳第815章）

## 原文回跳第816章·再回301

杨间在八音盒保护下独自返回301室，发现整栋楼恢复旧日状态，鬼域受室内灵异干扰。唱片般的音乐出现又消失，菜篮和无脸木偶先后不见，杨间怀疑柳青青与301室灵异深度关联。（原文回跳第816章）

## 原文回跳第817章·屋内的过去

杨间用柴刀媒介重现右侧房旧影：301室老太太曾画出年轻秦老，又让无脸木偶穿红旗袍、画上与鬼画女子相同的脸。由此可知柳青青的旗袍可能承载该房间残留记忆；老太太察觉媒介窥视，杨间不敢贸然出刀。（原文回跳第817章）

## 原文回跳第818章·床上的尸体

左侧卧房红漆木床能屏蔽鬼眼，床上老人尸体手持黄信。媒介显示尸体曾起床取信，且黑白老人影像部分侵入现实；杨间退出后301室门无法关闭，房内灵异开始向外扩散。（原文回跳第818章）

## 原文回跳第819章·补全的影子

李易被未知灵异掏空，仅余会说话的皮囊，后被杨间鬼手压制。杨间要求李乐平接手301室风险并将其移出小区，随后拔出棺材钉，让鬼影头和无头鬼影拼合，赌八音盒能抵住意识侵蚀。完整鬼影开始反向控制杨间，驾驭结果未定。（原文回跳第819章）
