# 原文回跳第870-874章剧情梗概

## 原文回跳第870章·交锋

陈桥羊试图以杨间父亲杨孝天的旧交身份拖延，杨间拒绝受骗。陈桥羊以血字短暂改写厉鬼规律，令四鬼囚笼中的厉鬼锁定杨间；杨间以六层鬼域钉住其中一鬼。（原文回跳第870章）

## 原文回跳第871章·新旧的对抗

陈桥羊用血字剥离自身姓名，躲过鬼童鬼喊人，随后中计夺取无法拔出的长枪。杨间借熊文文预知发动陷阱，以柴刀肢解陈桥羊最强的民国衣鬼，并以七层鬼域重启自身消除反噬。（原文回跳第871章）

## 原文回跳第872章·失控和入侵

杨间鬼影侵入陈桥羊，盗取并抹去其约半数记忆。陈桥羊使摆钟失控，古宅纸人花轿撞入鬼域、将他救走；杨间未能完成击杀。（原文回跳第872章）

## 原文回跳第873章·王家一代

王察灵以王家一代黑白老人撕裂并压住陈桥羊遗鬼。李军以鬼画窗口暂清校时后古宅内出现的厉鬼，和李阳会合；王家二代夫妇引导李阳看见摆钟。（原文回跳第873章）

## 原文回跳第874章·消失的东西

杨间以王察灵仍是普通人为弱点，要求日后取得摆钟并接管诅宅；王察灵退让。李阳确认曾见摆钟，杨间决定暂不取走、在午夜前撤离大东市；王察灵则在安全屋检查饿死鬼。（原文回跳第874章）
