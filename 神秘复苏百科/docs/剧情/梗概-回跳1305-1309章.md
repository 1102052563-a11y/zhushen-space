# 原文回跳第1305-1309章剧情梗概

## 原文回跳第1305章·映照总部团灭

过去映照总部的围杀在机场以团灭收场。杨间先后击杀映照中的王察灵、叶真等人，即使被王家亡魂撕裂也能重启恢复；赵建国等人最终亦未能阻止他。此处伤亡均属过去映照事件，不等同于真实历史。（原文回跳第1305章）

## 原文回跳第1306-1307章·双眼准备与第二波围杀

杨间取走映照中弘法寺白骨树空间内的鬼眼和棺材钉，暂时拥有两只鬼眼、两根棺材钉；鬼童则进入鬼镜吞鬼，又吞食尚未成长的鬼差，迅速补全力量。秦老同时驾驶灵异公交召集孟小董、罗千等民国旧人。（原文回跳第1306章、原文回跳第1307章）

杨间持续删除自己和王珊珊熟人的记忆，令映照世界进一步虚化；在准备离开时遭秦老驾公交撞击。公交撕开鬼域、令他短暂死机，杨间只能靠重启化解。（原文回跳第1307章）

## 原文回跳第1308章·无限重启受阻

罗千以坟场坟土压制杨间的鬼火、鬼湖与鬼影，杨间遂用两只鬼眼交替八层重启，形成理论上的无限重启。孟小董却可由过去持续入侵当下，打破其单纯依靠回退时间脱身的计划。（原文回跳第1308章）

## 原文回跳第1309章·单独对抗孟小董

杨间将时间回退至两点，为避开秦老和罗千而在无人郊外单独迎战孟小董。他确认柴刀会被大量替死娃娃消耗，棺材钉虽能压住单个映照分身，却无法阻止对方持续增殖；鬼火和鬼手亦未能奏效。章末杨间打通映照中的鬼湖，用沉湖压制人偶厉鬼，却未能令孟小董完全下沉，胜负未分。（原文回跳第1309章）
