# 原文回跳第1295-1299章剧情梗概

## 原文回跳第1295-1297章·旧日总部追查王珊珊

杨间在过去映照中联系旧时周正和总部寻找王珊珊，并以未来力量压制姜尚白、林龙和方世明。总部查出王珊珊位于白水镇，杨间赶到后与她会合。（原文回跳第1295章至原文回跳第1297章）

## 原文回跳第1298章·人皮纸的诱导

王珊珊说明人皮纸以“杨间已死”的信息诱使她进入白水镇木楼，实为将纸本身带入过去映照。杨间确认她已经识破此处不是可改变历史的真实三年前，并重新收回人皮纸。（原文回跳第1298章）

## 原文回跳第1299章·六点十分死亡预警

人皮纸预示杨间当日六点十分仍会死在白水镇。杨间返回映照中的大昌市后，死亡地点不变，遂确定整个过去世界仍在白水镇内部；尝试通过鬼湖离开时却连上三年前的完整鬼湖，脱困失败。（原文回跳第1299章）
