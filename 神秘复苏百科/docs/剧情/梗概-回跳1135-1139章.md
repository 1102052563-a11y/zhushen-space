# 原文回跳第1135-1139章剧情梗概

## 原文回跳第1135-1137章·恶犬攻占梦魇

黑狼狗即使被砍死也会以更多同形个体重现，击杀追杀者、逼骆胜和刘逃离。凯丽将二人送回现实后躲入暗间；鬼梦村庄与梦魇城堡间留下通路，狼狗控制城堡并可借现实水面倒影攻击骆胜。（原文回跳第1135章至原文回跳第1137章）

## 原文回跳第1138章·娱乐城兑付

杨间决定不再追砍骆胜媒介，回到娱乐城处理积分兑付。何龙承诺三日内支付一百二十亿，何月莲则以半份遗产为条件准备前往大昌市接触杨间。（原文回跳第1138章）

## 原文回跳第1139章·张伟被抢劫

熊文文预知无法找到张伟，杨间认为鬼镜复活者身份影响预知。张伟实际被人骗至巷中抢劫，杨间救场、收回其武器与筹码，随后准备离开大澳市。（原文回跳第1139章）
