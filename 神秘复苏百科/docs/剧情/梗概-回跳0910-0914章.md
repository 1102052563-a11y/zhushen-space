# 原文回跳第910-914章剧情梗概

## 原文回跳第910章·车辆超载

杨间试图驾驶灵异公交，鬼手和鬼影只能让方向盘微量偏转，无法取得完整控制权。第一站荒村出现等车老人，满载风险随即来临。（原文回跳第910章）

## 原文回跳第911-912章·上车的老人与面具

301室老太太携竹篮上车，电子屏鬼数由十一变十三。杨间与周登各清理一名驭鬼者，腾出两个座位供老太太和竹篮内鬼入座，公交恢复行驶。（原文回跳第911章、原文回跳第912章）

## 原文回跳第913章·平静的县城

黄纸遮脸尸鬼在第二站下车。周登冒险下车取到盖脸纸，杨间短暂打开车门救回他，并获得一张盖脸纸。（原文回跳第913章）

## 原文回跳第914章·下雨的车站

第三站处于灵异雨幕，雨中鬼上车并占据最后空位。红信信使完成三站乘车条件，接下来必须面对熄火或鬼拦车时的离车风险。（原文回跳第914章）
