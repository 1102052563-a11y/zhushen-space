# 原文回跳第1180-1184章剧情梗概

## 原文回跳第1180-1182章·循环者溃败与男尸再现

杨间借燃烧鬼手压制香兰、楚南、朱见、王根全，王根全试图乘电梯逃走却被裹尸布松脱后的高大腐烂男尸杀死。男尸灵异增强，杨间怀疑有其他厉鬼寄存其内。（原文回跳第1180章至原文回跳第1182章）

## 原文回跳第1183章·火海中的出口

高大男尸进入三楼火海、局部熄灭炉火，杨间趁机扩散火势。李阳从尸堆脱困，确认黄金门位于火海方向；男尸熄火后门体显现。（原文回跳第1183章）

## 原文回跳第1184章·关闭黄金门

杨间带童倩、李阳穿过黄金门回到凯撒现实侧。三楼附尸鬼随即推门，危急时高大男尸以裹尸布将其拖回，黄金门重新关闭。童倩昏迷并有颅内淤血，三人随后转往医院。（原文回跳第1184章）
