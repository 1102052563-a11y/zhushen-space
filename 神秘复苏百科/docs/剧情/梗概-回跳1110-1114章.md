# 原文回跳第1110-1114章剧情梗概

## 原文回跳第1110-1111章·黑狼狗认主与大昌清污

黑狼狗在现实中认杨间为主，只能经积水媒介显现。杨间返回大昌市，以掌控的鬼湖水域巡查江河、压制残余灵异；同时得知老家表妹失踪，判断其仍可能活着。（原文回跳第1110章、原文回跳第1111章）

## 原文回跳第1112-1113章·大澳市赌场圈套

王彬、张显贵在大澳市赌场输掉巨额资金，骆胜拒绝干预并索要尚通大厦。杨间判断骗局在试探或诱自己赴大澳市，决定反向入局；他同时收到黑色雨伞鬼域向南移动、凯撒大酒店异常等报告。（原文回跳第1112章、原文回跳第1113章）

## 原文回跳第1114章·水域连通与动身

杨间确认自身掌控的水域可互相连通，鬼湖侵蚀却使新身体也迅速冰冷。他与黑狼狗在梦中形成稳定共处，随后带江艳、熊文文、张伟等搭乘专机前往大澳市。（原文回跳第1114章）
