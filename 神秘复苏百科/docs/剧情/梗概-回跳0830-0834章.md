# 原文回跳第830-834章剧情梗概

## 原文回跳第830章·准备工作

杨间安排童倩在自己死亡后接任队长，并完成求生准备：以染血报纸反复写下“我是杨间”、以特种钢重制柴刀棺材钉长枪、制作黄金内衬铁棺。他准备在八音盒诅咒爆发时，让死机鬼影中的记忆重新选中自己。（原文回跳第830章）

## 原文回跳第831章·迟来的短信

杨间提前进入铁棺，脸覆报纸、解除对完整鬼影的压制，等待诅咒爆发。冯全调查大东市摆钟诅咒时被廖凡、裴东、许峰追杀，鬼出租车撞伤他，鬼雾与坟土复苏；冯全群发求救，童倩、张韩出动。（原文回跳第831章）

## 原文回跳第832章·生与死的对拼

许峰抱人鬼束缚童倩、张韩，裴东准备摸头处决。张韩为童倩断后，被裴东抹除意识死亡；童倩发动递增回音的鬼笑，哭脸回头避过鬼喊人，第三波笑声杀死裴东。（原文回跳第832章）

## 原文回跳第833章·可怕的出租车

廖凡、许峰依靠鬼出租车抵抗鬼笑，车辆启动后进入鬼域、从童倩身后将其撞飞。童倩重伤，二人没有补杀，改道大昌市，准备趁杨间失控夺取资源。（原文回跳第833章）

## 原文回跳第834章·闯入

童倩无法阻止入侵，只能通知队友防范。张韩的鬼镜留影自动复活，但黑布遮镜、无人接应，复活后的普通人被镜中鬼手拖回黑暗，第二次死亡。许峰、廖凡随后抵达尚通大厦，确认杨间未出现后强行闯入。（原文回跳第834章）
