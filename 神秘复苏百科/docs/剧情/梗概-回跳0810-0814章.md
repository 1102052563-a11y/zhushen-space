# 原文回跳第810-814章剧情梗概

## 原文回跳第810章·奇怪的一切

杨间在301室发现红漆家具、民国餐具、疑似替死布娃娃制作台、无脸女木偶和人偶婴儿，推测此地与鬼橱、旧时代灵异存在关联。菜篮人偶突然消失，柳青青则产生对房间的陌生熟悉感。（原文回跳第810章）

## 原文回跳第811章·木桌下的人

柳青青指出人偶常躲在红桌下、需倒转视线才能看见。杨间倒视后发现一只持人偶的淤青人形鬼，目光相接后触发追杀。他将黄信留在301室完成任务并撤出，李易、杨小花离开，柳青青因房内记忆与风险犹豫滞留。（原文回跳第811章）

## 原文回跳第812章·再次释放的诅咒

杨间被301室人偶鬼追赶，替死布娃娃已被鬼找人杀死，鬼找人也再次锁定他；李阳又引来失控的梦游鬼。三鬼夹击下，杨间第二次开启八音盒，鬼眼得以开启六层鬼域，先斩断人偶鬼手臂、再压住鬼找人。（原文回跳第812章）

## 原文回跳第813章·压制与异类

杨间以鬼手抓住鬼找人熏黑干尸，以柴刀将人偶鬼连同人偶本体拆为碎块。李乐平恢复意识后现身，杨间看出其已是保有活人意识的异类。柴刀连续使用的诅咒开始在杨间身上爆发。（原文回跳第813章）

## 原文回跳第814章·诅咒和野心

杨间身体和无头鬼影按柴刀伤势裂解腐烂，但八音盒保住意识；无头鬼影自行融合后，他以鬼域把身体重新拼回。李乐平承认江城、张小小均为伪造身份，猛鬼区的梦游鬼、鬼找人和浓烟鬼域全属其自身驾驭；他正以遗忘鬼取代厉鬼意识，异类化只成功一半。杨间与其持刀对峙，后续冲突与处置待下文。（原文回跳第814章）
