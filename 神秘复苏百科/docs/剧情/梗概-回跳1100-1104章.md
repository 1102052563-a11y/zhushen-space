# 原文回跳第1100-1104章剧情梗概

## 原文回跳第1100-1102章·招魂传承与何银儿复活

总部认定鬼湖暂不可处理，批准封锁。太平古镇内，何连生以红棺、招魂香等手段复活何银儿，却被柳三夜袭杀死；何连生预先招魂交代传承，何银儿继任第四任招魂人，准备回大原市重建太平镇。（原文回跳第1100章至原文回跳第1102章）

## 原文回跳第1103章·封锁计划获准

杨间确认鬼湖不再外扩但已有脱困厉鬼消失。总部正式接受暂搁、封锁中州市的方案，要求杨间监视；队长计划留守三日确认稳定性。（原文回跳第1103章）

## 原文回跳第1104章·鬼湖显现未知县城

第三日，鬼湖湖水媒介显现一座现实无对应的旧县城，县城灵异正在驱散湖水。队长发现其中鬼戏台、红漆凳和唱戏声，杨间判断风险极高而未触碰，仅建立线索。（原文回跳第1104章）
