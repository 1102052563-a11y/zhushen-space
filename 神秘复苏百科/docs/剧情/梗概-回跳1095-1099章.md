# 原文回跳第1095-1099章剧情梗概

## 原文回跳第1095章·水中灵异人救场

杨间制造的一千二百名水中男性灵异人进入中州市，与女尸一对一相互拖入积水，救下濒临撤退的李军、阿红、曹洋、柳三和冯全。（原文回跳第1095章）

## 原文回跳第1096章·源头登船

女尸停止增殖后，鬼湖源头以白衣、红梳、湿发女子姿态站上巨船，哭声弥漫。队长们判断其远比女尸凶险，暂不贸然接触；杨间提出摆钟移离鬼湖或灵异封锁两种后续思路。（原文回跳第1096章）

## 原文回跳第1097-1098章·诅咒侵蚀与暂时撤退

源头显现加剧杨间、柳三、李军的女尸诅咒，柳三差点自投鬼湖，众人撤至服务站。杨间更换由骗人鬼制造的新身体摆脱侵蚀；他用鬼剪刀暂时解除柳三意识层面的侵蚀，自己沾上新的腐烂人头诅咒。（原文回跳第1097章、原文回跳第1098章）

## 原文回跳第1099章·休整与双鬼僵持

队长决定休整、上报，并将鬼湖治理目标暂定为封锁。杨间发现鬼橱诅咒与赵小雅愿望鬼相互僵持，当前无法交易或实现愿望；总部收到档案后判断鬼湖事件无解。（原文回跳第1099章）
