# 原文回跳第1280-1284章剧情梗概

## 原文回跳第1280-1282章·进入白水镇

王珊珊和大山市负责人萧阳在白水镇失联，杨间带刘奇前往调查。小镇已与灵异地域重叠，过半建筑不在地图内；萧阳的鬼雨令居民沉睡游荡，以此保护其不被鬼直接杀死。杨间在王珊珊外婆家以黄纸暂压受侵蚀的王秀丽。（原文回跳第1280章至原文回跳第1282章）

## 原文回跳第1283章·夜间鬼镇与鬼寿衣

夜晚的白水镇显出鬼旅店、鬼面馆和服装店等灵异店铺。杨间在服装店发现鬼童失落的鬼寿衣，强行取回后以六层鬼域、柴刀和金色火域压住店内厉鬼。（原文回跳第1283章）

## 原文回跳第1284章·亡魂道路与萧阳

杨间以恶犬寻到萧阳保护的幸存者。萧阳说明王珊珊和鬼童已经进入会显现亡魂的街道，传闻带回亡魂可复活亲人，但进入者普遍失踪。萧阳选择继续留守，等待带走镇民的办法。（原文回跳第1284章）
