# 原文回跳第950-954章剧情梗概

## 原文回跳第950-951章·染血米饭规则

杨间试出鬼宴白米饭需以活人血染红并贴身供鬼取食，每粒可暂时令一只鬼停滞。众人借此撤去鬼域、稳定第五日，但同一只鬼会再次索取米饭。（原文回跳第950章、原文回跳第951章）

## 原文回跳第952-953章·米饭耗尽与柳青青后手

米饭消耗加快，杨间决定让老鹰、柳青青、李阳依次停用，和柳青青发生冲突。最后杨间以五层鬼域收容李阳、周登，柳青青米饭耗尽后却被红旗袍内的民国灵异庇护；第五日安全结束。（原文回跳第952章、原文回跳第953章）

## 原文回跳第954章·抬棺出殡

第六日，厉鬼离开古宅。杨小花从盖脸纸假死中苏醒，老鹰死于八音盒诅咒；杨间未以其尸体修补李阳，安排杨小花背李阳、自己和周登抬起异常变轻的红棺，自后门出殡。（原文回跳第954章）
