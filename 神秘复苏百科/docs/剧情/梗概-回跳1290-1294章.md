# 原文回跳第1290-1294章剧情梗概

## 原文回跳第1290-1292章·萧阳死亡与刘奇获救

刘奇转移三人行厉鬼的灵异仍未能完全抵抗袭击，萧阳死亡，鬼雨随之停止。杨间赶到后以金色火域、棺材钉和柴刀破坏三鬼配合，救下刘奇；一包中药强压刘奇失衡灵异，令其暂时恢复。杨间收走萧阳尸体，继续寻找王珊珊。（原文回跳第1290章至原文回跳第1292章）

## 原文回跳第1293-1294章·棺材木楼与过去出租屋

杨间、刘奇沿鬼童痕迹深入亡魂道路，发现一栋摆满旧棺的木楼。鬼童足迹经过二层并由异常后门离开；杨间独自入楼后，被二层房门后的狂风送入疑似三年前的大昌市出租屋，连七层重启也无法返回。（原文回跳第1293章、原文回跳第1294章）
