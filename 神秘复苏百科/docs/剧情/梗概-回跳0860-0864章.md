# 原文回跳第860-864章剧情梗概

## 原文回跳第860章·拦路的木凳

杨间带柳白穆尸体返回宁安大厦，与王察灵对质。王察灵承认诅宅时间被校正会释放不同时间段囚鬼；李军随后现身，三位队长暂时合作。大厦内开始出现红色木凳，鬼域受到干扰。（原文回跳第860章）

## 原文回跳第861章·分开行动

李军、王察灵先去诅宅探查，杨间以不信任王察灵和红色木凳事件为由留守宁安大厦。杨间与冯全调查发现木凳从楼下侵入、能阻挡鬼域，随后发现一名刚死员工。（原文回跳第861章）

## 原文回跳第862章·木凳上的人

杨间从死者王丰记忆得知：跨坐红色木凳会让人看见同坐的鬼。冯全控制普通员工留在工位，杨间决定亲自坐下试探源头规律。（原文回跳第862章）

## 原文回跳第863章·无法触及

红色凳子上的鬼压制杨间下半身和鬼影，杨间以棺材钉攻击却直接穿透目标。鬼袭击后木凳破碎，杨间身体失去生命特征但意识仍在；他确认木凳只是媒介，源头鬼无法直接触及。（原文回跳第863章）

## 原文回跳第864章·撤离的众人

大厦内木凳与尸体激增，杨间判断源头正在复苏，决定先带小队撤出、普通人暂留原处以免厉鬼随人扩散。冯全鬼雾带队到一楼，大厅已满是让出同坐位置的尸体；杨间命鬼童前往正门探路。（原文回跳第864章）
