# 原文回跳第825-829章剧情梗概

## 原文回跳第825章·301室结束

杨间以倒视人偶驱散黑白老人媒介，确认异常源实际是9栋301室，真正7栋301室为空。黄信被取回后自行消失，杨小花燃信回到鬼邮局，说明送信完成。杨间封锁明月小区、把9栋风险交由李乐平；柳青青则承认肉身早失、如今由人皮、红旗袍和无脸木偶维持。（原文回跳第825章）

## 原文回跳第826章·影响和方法

李阳将301室事件上报总部，建立A级档案。杨间整理9栋301室信息，思考让八音盒诅咒在完整鬼影上爆发、使鬼影死机的可能性；灵位转移意识风险过高，他转而准备向人皮纸求助。（原文回跳第826章）

## 原文回跳第827章·明显的陷阱

人皮纸先以遗书诱导杨间开启民国古宅第三间房，杨间命鬼童吞食逼其改写。新内容短暂提出“人的意识到底是什么”，随后给出诅咒爆发时放开鬼影、以人皮纸覆脸的方案。杨间认定方案是明显陷阱，只保留意识问题。（原文回跳第827章）

## 原文回跳第828章·杨间的武器

杨间尝试用黄金包覆柴刀和棺材钉制作长枪，防止自己复苏后轻易使用灵异武器；纯黄金枪身过软而失败。他用黄子雅的骗人鬼修复外观、要求购置特种钢，并得知陈博士已来公司。（原文回跳第828章）

## 原文回跳第829章·意识和记忆

陈博士说明：意识可视为记忆与身体反馈；死机鬼承载稳定活人记忆时，才可被人驾驭，反之就是鬼驾驭人。杨间认可该结论，聘陈博士为顾问，确定继续从意识、记忆和鬼影死机的方向寻找生路。（原文回跳第829章）
