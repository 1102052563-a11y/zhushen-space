# 原文回跳第1025-1029章剧情梗概

## 原文回跳第1025-1026章·孙瑞接管与信使制度终结

孙瑞在601管理者名册第四页签名，名册此前记录罗松文、田晓月、张羡光。接管后他重绘邮局，现代化改名“地狱公寓”，把残留厉鬼埋入下层鬼域，五影鬼被驱逐，信使任务和诅咒正式结束。（原文回跳第1025章、原文回跳第1026章）

## 原文回跳第1027章·离开地狱公寓

周泽、钟燕走出公寓后信纸化灰、失去信使身份。杨间留下王勇入队，委托孙瑞调查银子与公寓历史，自己带李阳、王勇返回大昌市；叶真则被杨间引去挑战王察灵。（原文回跳第1027章）

## 原文回跳第1028章·田晓月遗信

孙瑞发现田晓月女尸口中藏有黑信纸，写着“警惕张羡光，并且想办法杀了他”。他判断田晓月与第三任管理者张羡光曾冲突，且女尸仍保有管理者权限，只能暂时共存。（原文回跳第1028章）

## 原文回跳第1029章·李阳拼接第三鬼

李阳离开邮局后两鬼平衡迅速崩坏，堵门鬼复苏将其贴在门上。他以开门鬼手臂对抗、砍下原手臂并缝合鬼臂，独自尝试建立三鬼平衡，结果尚未揭晓。（原文回跳第1029章）
