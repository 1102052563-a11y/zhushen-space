# 原文回跳第930-934章剧情梗概

## 原文回跳第930-931章·骰局拖鬼与李阳取灯

王风以鬼骰局阻拦后门厉鬼，却在第五局掷输死亡；另一驭鬼者接手后亦死。李阳消耗最后鬼烛取下前门白灯笼，并确认提灯者可引鬼游走而不受袭击。（原文回跳第930章、原文回跳第931章）

## 原文回跳第932-933章·拼命肢解与扭转局势

杨间以八音盒诅咒令老鹰暂不死，维持骰局；随后由大强接防，独入大堂四次挥柴刀、两次重启，肢解古宅鬼域源头。李阳提灯在宅外游走，外部群鬼离开，第二夜危机解除。（原文回跳第932章、原文回跳第933章）

## 原文回跳第934章·顺利纠正

杨间判断前三日规则已明确为入殓、守夜、报丧。第三日零点，他接过白灯笼率余下七人离宅报丧；周登与柳青青依然失踪，第四日流程未知。（原文回跳第934章）
