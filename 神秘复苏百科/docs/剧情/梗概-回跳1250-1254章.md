# 原文回跳第1250-1254章剧情梗概

## 原文回跳第1250章·桃花源计划

张羡光坦白计划：由不死的邮局管理者驾驭鬼画，把人类纳入画中世界隔绝灵异。杨间等人拒绝将所有人命运交给张羡光，交涉破裂。（原文回跳第1250章）

## 原文回跳第1251-1253章·五分身与鬼差死斗场

张羡光以五具重启分身、锈刀和鬼差困住八队长。多名队长重伤，何银儿连续招魂，太平古镇强大亡魂化土五分身、带走卫景入黑暗；张先、陈桥羊则在外围准备补刀。（原文回跳第1251章至原文回跳第1253章）

## 原文回跳第1254章·识破光亮媒介

杨间、柳三、李乐平攻入教学楼，发现五盏尸油灯照影制造分身。鬼影熄灯后，杨间识破张羡光只能借光亮显现，以黑暗暂时阻断其攻击。（原文回跳第1254章）
