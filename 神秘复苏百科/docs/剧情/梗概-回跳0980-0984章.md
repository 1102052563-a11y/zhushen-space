# 原文回跳第980-984章剧情梗概

## 原文回跳第980-981章·雨中显鬼与预知

杨间以五层鬼域驱散雨区，确认阴雨会在十五分钟后恢复。队伍撤至村外观察，发现黑雨伞鬼只在下雨时现身；熊文文预知杨间能钉住鬼，但雨域不会消失，进一步预见大量撑伞鬼、黄子雅遇害和积水倒映死人脸的结局。（原文回跳第980章、原文回跳第981章）

## 原文回跳第982-983章·表层鬼与黑伞通道

杨间确认阴雨区外观是张开黑伞，判断鬼与伞组成无法直接关押的循环。他制作黄金雨伞带队入村，以鬼烛引出表层鬼并用长枪钉住；大量撑伞鬼随即出现，柴刀无法联动肢解。杨间改撑夺来的黑伞，被隔入更深雨域；冯全踩积水触发鬼袭，靠坟土隔绝后压住一鬼并夺伞。（原文回跳第982章、原文回跳第983章）

## 原文回跳第984章·第三层同化与撤回

杨间在第二层夺伞进入第三层，发现鬼数显著递减而威胁增强。积水中的人鬼倒影开始对调，使他被黑纱覆盖、体内厉鬼沉寂；他以七层鬼域重启自身，反被雨域排斥回第二层，并带回第三层黑伞。（原文回跳第984章）
