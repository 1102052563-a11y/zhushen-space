# 原文回跳第1060-1064章剧情梗概

## 原文回跳第1060-1062章·古街交易与无脸人

杨间以三元纸币在隐藏古街扎纸店购得纸船，避开纸人交易。深入后他发现无尽废街、棺材铺和无脸人；无脸人自称正在古街寻找自己的脸，离开时不知去向。（原文回跳第1060章至原文回跳第1062章）

## 原文回跳第1060-1063章·祠堂与渡口等待

柳三纸人进入祠堂后被独眼老人处理。李军、阿红、沈林在渡口等待午夜渡船，见到夜间洗衣妇人等古镇异象，但决定不偏离鬼湖任务。杨间和柳三夜查祠堂未果。（原文回跳第1060章、原文回跳第1063章）

## 原文回跳第1064章·黑色渡船启程

午夜黑色渡船抵达渡口。杨间以七元异常纸币支付船费，纸钱缩为三元；杨间、李军、阿红、沈林、柳三登船，河道逐步化为陌生灵异空间，队伍正式驶向鬼湖。（原文回跳第1064章）
