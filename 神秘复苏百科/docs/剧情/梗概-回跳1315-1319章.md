# 原文回跳第1315-1319章剧情梗概

## 原文回跳第1315章·映照旧人溃败与张洞最后一击

鬼童分身反压五名映照旧人：罗千、孟小董、罗文松与秦老先后在鬼童人潮中败退或被吞没。映照世界崩散前，张洞却沿一条小路绕过鬼童预知，掐住杨间脖颈，将其意识留在虚幻与真实的夹缝。（原文回跳第1315章）

## 原文回跳第1316章·回到木楼却未完全脱困

王珊珊和鬼童回到木楼二层，确认此前三年前经历均是意识层面的映照；房中木架摆有一具无眼皮、眼眶幽暗的干尸。杨间肉身无伤却双眼空洞、无法回应，仍被困在夹缝。人皮纸声称杨间已“不在这个世界上”、将永远受困，王珊珊与刘奇据此推测能救他的应是恶犬。（原文回跳第1316章）

## 原文回跳第1317章·血媒介引恶犬入楼

王珊珊用骗人鬼水晶项链制造积水，确认恶犬未在房中。刘奇以自身血液为媒介，在木楼外找到被阻隔的恶犬，并引它沿血路进入二层；恶犬回归杨间记忆后，开始与困住其意识的灵异对抗。过程中一楼棺材开启，木楼内厉鬼开始苏醒。（原文回跳第1317章）

## 原文回跳第1318-1319章·餐桌鬼与人皮纸连环陷阱

刘奇在二楼被地板灵异拖入“八仙桌”映照、遭桌下多只厉鬼撕咬，现实身体同步残缺。王珊珊依人皮纸“趴下可见鬼”的信息命鬼童分担袭击，随后识破人皮纸仍在借真信息设陷，却在救刘奇的压力下将人皮纸喂入受压制的鬼童。（原文回跳第1318章、原文回跳第1319章）

人皮纸又指示她下楼合上开启棺材。王珊珊决定先将人皮纸喂给受束缚的鬼童，再于下一章执行合棺；本批结束时刘奇和鬼童仍被餐桌灵异束缚，木楼各部分的厉鬼正在复苏。（原文回跳第1319章）
