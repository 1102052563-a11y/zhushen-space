# 原文回跳第1105-1109章剧情梗概

## 原文回跳第1105章·李军试探鬼戏台

李军点燃鬼火烧融未知县城，却无法影响戏台。触碰红凳后出现孩童血手印，登台引发红凳集体异动，队长随即撤离，将诡异县城列为X级线索。（原文回跳第1105章）

## 原文回跳第1106章·鬼湖行动解散

三日确认鬼湖未再外扩，队长解散、改为长期监视。杨间与曹洋、柳三交换民国灵异地点线索，随后独自前往地狱公寓，准备处理记忆中的黑狼狗。（原文回跳第1106章）

## 原文回跳第1107-1109章·梦中收服黑狼狗

杨间在孙瑞看护下于地狱公寓入梦接触狼狗。红手镯烙印导致狼狗一度失控，画中杨孝介入，以相似性诱导狼狗误认杨间为主人；杨间醒来后，黑狼狗从积水倒影跃入现实。（原文回跳第1107章至原文回跳第1109章）
