# 原文回跳第850-854章剧情梗概

## 原文回跳第850章·再次活过来的人

杨间确认摆钟将古宅回退半小时，受诅咒的团伙成员失去回退期间记忆。棺材钉压住的厉鬼没有随之恢复，刘玥因此无法复现；柳白穆认清先前惨败后，提出和谈。（原文回跳第850章）

## 原文回跳第851章·一哄而散

杨间假意考虑和谈，实际等待古宅时间过六点，确保下一次击杀不会被回退。柳白穆猜到其意图，带团伙成员逃入古宅深处，准备寻找失踪会长或利用深处风险翻盘。（原文回跳第851章）

## 原文回跳第852章·错误的时间

李阳与队伍错位，独自遇到一名黑白媒介中年女子及窗外一对黑白老人，避开后翻窗离宅。古宅六点钟声未再触发重启，杨间据此让冯全以坟土临时关押抱脚鬼，准备永久清剿。（原文回跳第852章）

## 原文回跳第853章·被留下的身体

柳白穆带张庆、万铜进入每十二天出现一次的上行台阶门，试图寻找摆钟。杨间通过柴刀媒介远程斩首柳白穆；诅咒暂时维持其头颅意识，张庆、万铜带其继续深入。（原文回跳第853章）

## 原文回跳第854章·黑暗之中的房间

杨间在密室杀死徐明，再命童倩进入无边黑暗房间，以快速叠加的鬼笑驱赶躲藏者。部分成员被笑声杀死，部分逃入黑暗深处迷失；李军此时已抵宁安大厦，向王察灵说明自己来监视大东市内所有无底线风险。（原文回跳第854章）
