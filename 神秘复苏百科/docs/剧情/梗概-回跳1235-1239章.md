# 原文回跳第1235-1239章剧情梗概

## 原文回跳第1235-1237章·执法队长的首次裁决

何银儿、柳三在培训基地即将交手，杨间以鬼域、鬼湖、柴刀和黑狼狗强行介入，瞬间压制何银儿并迫其放弃复仇。何银儿随后接受刘老板建议，转为搜集遗物扩充招魂媒介。（原文回跳第1235章至原文回跳第1237章）

## 原文回跳第1238章·十二队长补齐

露天队长会议开启。杨间以鬼域驱散暴雨，林北、周登成为新队长，木质身体的陆志文作为内定队长公开，十二席位补齐。（原文回跳第1238章）

## 原文回跳第1239章·高明亡魂锁定张羡光

何银儿借遗物短暂招来高明亡魂，亡魂留下张羡光画像，确认高明因窥见其前往平安大厦而遭灭口。杨间认可张羡光围绕鬼画布局的推断；执法队长权限同时获会议默认。（原文回跳第1239章）
