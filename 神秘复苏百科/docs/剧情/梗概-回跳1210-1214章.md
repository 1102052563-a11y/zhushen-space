# 原文回跳第1210-1214章剧情梗概

## 原文回跳第1210章·执法队长上任

杨间接受执法队长职位，但限定为必要时约束队长。他取得总部资源调用权，领取替死娃娃、草绳圈等道具，开始三日内上门召集队长。（原文回跳第1210章）

## 原文回跳第1211-1213章·柳三阴宅脱困

杨间到DQ市找柳三，循纸人和黄泥路进入守尸人阴宅。柳三被黑棺尸水困住，杨间发现棺内鬼在棺盖上且无法下楼，救出柳三后以倒梯阻鬼，柳三答应参会。（原文回跳第1211章至原文回跳第1213章）

## 原文回跳第1214章·李乐平的夜间风险

李乐平说明每夜有三小时间歇失控。傍晚失控时，杨间被其遗忘鬼影响而短暂忘记重启，后以鬼湖压制；杨间留下红烛方案，李乐平承诺验证后赴会。（原文回跳第1214章）
