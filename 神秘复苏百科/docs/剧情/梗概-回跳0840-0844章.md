# 原文回跳第840-844章剧情梗概

## 原文回跳第840章·团灭

杨间让鬼童吞下鬼喊人，顾程抽中生签后仍被其扭断脖子；许峰试图开鬼出租逃离，却被鬼域误导，在鬼童喊名时回头死亡。入侵大昌市的裴东、廖凡、顾程、许峰至此全部死亡。（原文回跳第840章）

## 原文回跳第841章·善后

杨间修复李阳、重置黄子雅的水晶挂件，并让黄子雅驾驭许峰遗留的抱人鬼。童倩在高速守住鬼雾受困者，杨间赶到后压制裴东复苏鬼、修复童倩伤势；熊文文取得可叠加生签效果的鬼签。（原文回跳第841章）

## 原文回跳第842章·坟中复活

冯全只余头皮、坟土即将彻底埋没其身体。杨间将鬼骷髅投入坟中，使其填入冯全身体、与坟土和鬼雾形成三鬼平衡；冯全以泥土与骨骼构成的新身体苏醒。（原文回跳第842章）

## 原文回跳第843章·一个小时

杨间在尚通大厦批评童倩救援决策失误，同时安排战后收容并联系总部补充联络员。他公开将在一小时后带队去大东市清算摆钟诅咒团伙，总部要求王察灵配合、派已获救的李军前往。（原文回跳第843章）

## 原文回跳第844章·全员出动

杨间确认自己成为活人意识主导的鬼影异类，继承染血报纸的记忆能力和可传播的八音盒诅咒。他率冯全、童倩、李阳、黄子雅、熊文文与鬼童组成满编队，直接以五层鬼域前往大东市。（原文回跳第844章）
