# 原文回跳第835-839章剧情梗概

## 原文回跳第835章·危险临门

许峰、廖凡闯入尚通大厦，杀死章华及一名保安，破坏顶层安全屋并掠走鬼镜。李阳、黄子雅、熊文文和王珊珊则在观江小区组织防守。（原文回跳第835章）

## 原文回跳第836章·门口的交手

李阳以堵门鬼附着保安亭，硬停鬼出租车；黄子雅阻止其回应鬼喊人，王珊珊命鬼童缠住廖凡。许峰越过预设范围后被李阳胸口厉鬼拉扯，双方陷入拼命对抗。（原文回跳第836章）

## 原文回跳第837章·被打开的安全屋

廖凡高价召来顾程。顾程以鬼域救走重伤的许峰、廖凡并转移鬼童，随后定位一号安全屋；三人强开安全屋，找到杨间铁棺和多件灵异物，决定开棺夺取棺材钉。（原文回跳第837章）

## 原文回跳第838章·我是谁？

顾程、许峰、廖凡将铁棺搬到外面打开，发现杨间尸体、黄金灵异长枪和破裂前的八音盒。染血报纸散尽、八音盒破碎后，杨间站起，红光鬼域压制顾程，仍处于“我是谁”的记忆混乱。（原文回跳第838章）

## 原文回跳第839章·被唤醒的人

许峰抱人鬼、廖凡鬼喊人、顾程吹气同时袭击。鬼喊人反而使杨间确认自身身份，恢复杨间记忆；他夺回长枪，以棺材钉钉死廖凡，许峰与顾程被困在红光鬼域中。（原文回跳第839章）
