# 原文回跳第945-949章剧情梗概

## 原文回跳第945-947章·鬼门送鬼与柳青青归队

红棺压制加速失效，杨间和李阳以鬼门将约二十只古宅鬼送入门后，老人尸体暂时重新坐起；但门后惨白人脸险些反入侵，鬼门被迫关闭。第四日末，柳青青穿红高跟鞋归队。（原文回跳第945章至原文回跳第947章）

## 原文回跳第948章·失控前的伤亡

投影鬼把樊兴拖入墙面并吞噬其体内鬼；李阳被救出却失去一手双腿。杨间、周登、柳青青各自暂时限制其他靠近的鬼，勉强撑到第五日零点。（原文回跳第948章）

## 原文回跳第949章·鬼宴试错失败

鬼宴开始后，三碗白米饭成为唯一线索。老鹰撒米失败、遭多鬼入侵后只能维持骰局；周登置饭又被黑椅鬼袭击，杨间断鬼手救回。正确用法仍未找出。（原文回跳第949章）
