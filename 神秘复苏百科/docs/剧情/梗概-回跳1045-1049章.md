# 原文回跳第1045-1049章剧情梗概

## 原文回跳第1045章·赵小雅的愿望代价

杨间确认赵小雅是赵开明之女，其伴鬼会以亲属死亡支付愿望代价，赵开明全家亲属已化为诅咒投影。杨间以灵异复活、改写记忆的刘思悦取得赵小雅信任，令其带女孩离城观察，并收下愿望贴纸。（原文回跳第1045章）

## 原文回跳第1046-1047章·总部黄金雕像与鬼湖升级

秦老自愿沉睡在总部黄金雕像内，防止老死后厉鬼复苏。总部告知鬼湖已升为S级，曹洋与银子队长先后失踪，杨间同意参加四名队长联手的鬼湖行动。（原文回跳第1046章、原文回跳第1047章）

## 原文回跳第1048章·鬼香与行动阵容

总部提供十根红色鬼烛和鬼香。鬼香可令闻到香味的鬼沉睡；此次行动拟由杨间、柳三、沈林及李军或卫景组成，次日集结。（原文回跳第1048章）

## 原文回跳第1049章·转移鬼画与选择冯全

杨间将鬼画衍生物转存地狱公寓，要求油画亡魂遵守协作约定。他回大昌市召开会议，决定不带其余队员冒险，只召回冯全随队参与鬼湖行动，童倩和黄子雅接替黑雨伞盯防。（原文回跳第1049章）
