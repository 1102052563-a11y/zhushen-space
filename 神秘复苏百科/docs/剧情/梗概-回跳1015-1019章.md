# 原文回跳第1015-1019章剧情梗概

## 原文回跳第1015-1017章·叶真抵达与撕黑信

李阳联系灵异论坛，叶真偿还人情，以鬼域横跨大海市至大汉市并强行进入鬼邮局。孙瑞在杨间鬼影控制下撕碎黑信，信件化灰后邮局所有灯泡炸裂，白天骤然变为黑夜。（原文回跳第1015章至原文回跳第1017章）

## 原文回跳第1018章·连续厉鬼入侵

邮局外的黑影堵门并试图破门，李阳带周泽、钟燕、龙哥防守。杨间钉住只有死人脚的厉鬼；叶真一拳击退柜台哭泣鬼，却踩入天井落下的黑信纸，陷入纸下未知空间。（原文回跳第1018章）

## 原文回跳第1019章·开门鬼被肢解

开门鬼下楼，以亮灯后熄灭的规律袭击王勇。王勇以铁锹和自身厉鬼勉强击退，杨间随即肢解其头和右臂，交李阳作为三鬼驾驭备选。孙瑞仍未完全醒来，黑信诅咒继续酝酿。（原文回跳第1019章）
