# 原文回跳第790-794章剧情梗概

## 原文回跳第790章·信纸

李阳夜间听到的高跟鞋声并未在35至37号房留下目标，杨间暂不把它直接定为厉鬼。三楼天井信箱出现黄信，34号房信使李易现身，解释三楼信使可烧黑色信纸自由进出邮局。杨间以黄金枪换来信纸，准备通过三楼信使的情报加快上楼。李易透露第三封信可被截取、三封信也可能合成特殊任务，但风险都很高。（原文回跳第790章）

## 原文回跳第791章·同一个地址

34号房的李易、郭幽、柳青青原本正要接第三封信，杨间取信后却使31、34号房共同接下任务。黄信地址仍是大川市明月小区7栋301室，与二楼红信完全一致。杨间意识到邮局执意让信使去该地，不再贸然撕信，决定先带信实地调查；34号房信使虽对他的能力存疑，仍决定保留跟进任务的可能。（原文回跳第791章）

## 原文回跳第792章·油灯

杨间准备送信前得知撕第四封信可能令整个邮局长期闹鬼，进一步确认不能无节制使用撕信手段。孙瑞在一楼撑过熄灯，取到一盏可隔绝人与鬼的油灯，并继续杀死新进入邮局的信使。杨间推测油灯可能由希望邮局停摆的未知存在留下，又发现一楼人物油画中的白衣女子与二楼女尸鬼外貌一致，怀疑油画记录了曾与邮局接触、死后复苏的驭鬼者。（原文回跳第792章）

## 原文回跳第793章·大川市

杨间、李阳由孙瑞专机抵大川市，李阳确认双鬼平衡最多只能粗略维持半年。大川市负责人李乐平主动接待，却令杨间无法留下清晰记忆。机场已经封锁，暗处有无头空姐和将头颅复位的工作人员游荡。杨间安排童倩、熊文文待命支援，同时决定先调查大川市而不贸然调动完整队伍。（原文回跳第793章）

## 原文回跳第794章·无影的人

大川市表面运作、实际人气稀薄。档案显示李乐平处理过“被遗忘”和“猛鬼区”两起事件，但过程都未公开。杨间乘车时遇到异常车祸，事后发现司机早已无头；肇事车辆司机则如木偶般一路获得绿灯逃离。李乐平与助理在阳光下全无影子，杨间、李阳正式确认大川市的异常远未结束，送信地址很可能正指向这场城市级危机。（原文回跳第794章）
