# 原文回跳第975-979章剧情梗概

## 原文回跳第975-977章·第三人案件

杨间以鬼域在人群中逐个隔离，找出长期跟随张伟的第三人。第三人是寄生拼尸的残疾驭鬼者，靠“至少三人时被忽略”隐藏，曾杀人盗肢、灭口线人；杨间读取记忆后抹除其人格并关押。（原文回跳第975章至原文回跳第977章）

## 原文回跳第978章·长枪升级

陈博士确认古宅断手规律为接触后令目标失衡即死。杨间将其化为死人皮覆在黄金灵异长枪枪身，使武器增加失衡必死攻击，同时保留柴刀与棺材钉能力。（原文回跳第978章）

## 原文回跳第979章·黑雨伞行动前夜

杨间将鬼骰子借给携鬼童外出的王珊珊，随后通知熊文文参与黑雨伞行动。冯全、黄子雅、熊文文将于次日与杨间处理大昌市外雨区的黑雨伞鬼。（原文回跳第979章）
