# 原文回跳第1130-1134章剧情梗概

## 原文回跳第1130章·封存孙仁女尸

杨间回收707门牌，将孙仁尸体内连鬼湖四成灵异也难沉没的女尸封入三层黄金箱，深埋地下五千米。他进一步推断有隐藏势力正针对总部队长。（原文回跳第1130章）

## 原文回跳第1131-1132章·传教士录音与梦魇城堡

杨间在骆胜别墅触发传教士录音诅咒，主动承受昏睡后进入梦魇城堡。骆胜等人借梦魇试图长期困住杨间，梦中杨间失去灵异能力、仅为普通人。（原文回跳第1131章、原文回跳第1132章）

## 原文回跳第1133-1134章·拖延与鬼梦碰撞

杨间以虚张声势拖住城堡中的追杀者，分析梦魇掌控不完整。黑狼狗最终使鬼梦的老家村庄与梦魇世界碰撞，在杨间被逼入城堡死路时现身敌人后方。（原文回跳第1133章、原文回跳第1134章）
