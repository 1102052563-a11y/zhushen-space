# 原文回跳第1155-1159章剧情梗概

## 原文回跳第1155-1156章·鬼湖反穿电视嵌套

杨间在88号房血字中发现楚南真实复活房为701号。鬼湖水经电视媒介倒灌，使他反向穿过多层88房、找到各层沙发鬼后回归现实层；88房足以永久困死常规驭鬼者。（原文回跳第1155章、原文回跳第1156章）

## 原文回跳第1157-1158章·戏服鬼群的感染诅咒

杨间等寻找102房时遇到三十五只戏服鬼。杨间关入两只后被红戏服鬼诅咒感染，只能舍弃身体、再以鬼剪刀剪断规律；鬼群闭眼游荡，队伍贴墙避过。（原文回跳第1157章、原文回跳第1158章）

## 原文回跳第1159章·楚南骗局揭露

楚南承认把自己与香兰复活房对调，目的是借杨间抵达101房、救回香兰。杨间杀死楚南、尝试读取记忆，楚南身体消失且体内鬼被关押，循环者线索转而指向101房。（原文回跳第1159章）
