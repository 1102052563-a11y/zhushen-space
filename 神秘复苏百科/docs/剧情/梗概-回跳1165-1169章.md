# 原文回跳第1165-1169章剧情梗概

## 原文回跳第1165-1167章·笔记本的预告

香兰笔记记录多间房间规则，并指向1号、10号房。倒翻笔记后，其文字依次预告门外四鬼和身后死尸，现象均出现；童倩用鬼脸回头看见死尸，暂时免于触发袭击。（原文回跳第1165章至原文回跳第1167章）

## 原文回跳第1168章·火炉价值

杨间强行通过38房火炉，肢解红皮鬼后发现火炉火光可削弱自身及李阳的灵异侵蚀，遂用黄金绳拖走火炉。复活后的朱见被未知厉鬼追赶，杨间不予救援。（原文回跳第1168章）

## 原文回跳第1169章·十号房弃入

童倩哭脸杀伤朱见仍无法阻止其追赶。十号房现“活人勿进”血字、墙字化血，杨间判断前后风险叠加，选择鬼域转入5号房，暂避十号房和朱见。（原文回跳第1169章）
