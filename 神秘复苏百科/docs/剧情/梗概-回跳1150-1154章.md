# 原文回跳第1150-1154章剧情梗概

## 原文回跳第1150-1152章·四楼循环幸存者

楚南带队抵四楼安全房，见朱见、董玉兰、王根全。四人来自不同时代，各有首位复活房和信息记录房；杨间推断他们或曾成功离开却在外死亡、再失忆复活，众人决定寻找记录房验证。（原文回跳第1150章至原文回跳第1152章）

## 原文回跳第1153章·安全房失守

安全房的纸灰和门血无法阻止附尸鬼，李阳开门诅咒将其赶走后，房门防护迅速失效。杨间带李阳、童倩与跟随的楚南再次进入异常走廊搜寻信息。（原文回跳第1153章）

## 原文回跳第1154章·电视嵌套陷阱

杨间进入88号房，老式电视显示房内厉鬼逐步接近的画面。他被置换入电视图像，发现每轮循环都会增加厉鬼、使自己进入更深层88号房，暂时被困。（原文回跳第1154章）
