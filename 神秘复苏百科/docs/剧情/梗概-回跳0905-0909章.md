# 原文回跳第905-909章剧情梗概

## 原文回跳第905-906章·控制信使与到齐

杨间封锁长安路口、停运全城公交，命冯全、童倩控制红信信使。老鹰、秦开、柳青青等相继被押送，大强潜入后也被杨间以鬼域逼迫配合；杨小花和红色气球被安置在尚通大厦。（原文回跳第905章、原文回跳第906章）

## 原文回跳第907章·公交车出现

九点前，所有红信信使被送至封锁站点。灵异公交从雾中驶来，杨间确认鬼眼同样会受其压制；冯全、童倩、黄子雅、熊文文和鬼童留在站外接应。（原文回跳第907章）

## 原文回跳第908章·黑色纸伞

下车通缉驭鬼者倪生被杨间钉杀。一只撑黑色纸伞、鬼域更强的厉鬼随即下车，杨间为赶上公交放弃交战，命队员留守观察。（原文回跳第908章）

## 原文回跳第909章·我随便就行

红信信使抢座上车。电子屏显示车内有十一只鬼，李阳坐到最后空座；杨间将司机尸体拖离，自己占据驾驶位，公交驶离大昌市。（原文回跳第909章）
