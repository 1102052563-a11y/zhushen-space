# 原文回跳第1085-1089章剧情梗概

## 原文回跳第1085章·鬼梦杀死洗衣妇人

洗衣妇人在梦中失去灵异衣物，被黑狼狗追至祠堂并撕咬致死，现实尸体同步出现致命咬伤。鬼湖同时全面入侵中州市现实，灵异湖水开始外泄。（原文回跳第1085章）

## 原文回跳第1086章·杨间百公里治湖

杨间以覆盖百公里的鬼域抬山、改城、逆转水系，收束鬼湖扩散；阿红化成卫景，以鬼差能力协助尸体回收和水流倒灌。鬼湖被限制在约十公里，却淹没中州市和太平古镇，仍有少数厉鬼尝试脱困。（原文回跳第1086章）

## 原文回跳第1087章·巨型纸船与古镇旧人退让

独眼老人焚烧纸船，浓烟化为巨船帮助杨间救援。洗衣妇人尸体及灵异衣物被烧毁，仅留最后一件衣；独眼老人、刘老板和无脸人不再阻拦杨间。（原文回跳第1087章）

## 原文回跳第1088-1089章·打捞李军、柳三与无脸重绘

杨间潜湖打捞人皮李军和柳三。源头银子厉鬼对柳三私语、令女尸增殖并留下烙印；李军复苏后被棺材钉压住。无脸人剥去阿红腐烂的脸，杨间以鬼妆盒为其重绘新脸，结果待后文。（原文回跳第1088章、原文回跳第1089章）
