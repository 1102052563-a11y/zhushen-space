# 原文回跳第1020-1024章剧情梗概

## 原文回跳第1020章·黑信纸空间与女尸躯干

叶真在黑信纸构成的空间发现写满死去信使姓名的诅咒信纸及残缺女尸。他以替死能力扛住姓名诅咒、击打女尸，令空间崩解并回到一楼；女尸躯干显现，确认是玻璃瓶尸体碎片的一部分。（原文回跳第1020章）

## 原文回跳第1021-1022章·五影鬼规律与红姐退场

五道影鬼击破邮局大门，龙哥被第一影杀死，杨间被第二影连续杀死后重启并钉住其影。杨间用骗人鬼制造活人测试，确认五影分别杀老人、青年、女人、孩童与带孩童者；牵手可混淆身份。叶真则在楼梯与红姐交手，压制其拼图但无法进入红房，红姐退走。（原文回跳第1021章、原文回跳第1022章）

## 原文回跳第1023-1024章·孙瑞上六层与邮局坍塌

孙瑞恢复意识，看见管理者专属楼梯并携铁锹进入第六层。叶真从505带回最后一臂，杨间拼全玻璃瓶女尸；女尸睁眼后邮局由五楼向下逐层坍塌，真正变化与孙瑞接管结果未揭示。（原文回跳第1023章、原文回跳第1024章）
