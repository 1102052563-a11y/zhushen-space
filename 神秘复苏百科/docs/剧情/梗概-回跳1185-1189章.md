# 原文回跳第1185-1189章剧情梗概

## 原文回跳第1185-1186章·童倩救治与凯撒火后回查

杨间在医院清除童倩颅内淤血、残余灵异并修复大脑，但童倩未立刻苏醒，恶犬梦境也找不到其意识。两日后，杨间和李阳重返凯撒，发现三楼尸海已烧尽为灰烬。（原文回跳第1185章、原文回跳第1186章）

## 原文回跳第1187章·循环者不能离开

杨间保留火炉和三楼残鬼、取走燃烧焦骨，隐藏黄金门。复活后的王根全请愿离开验证，踏出凯撒后即腐朽死亡，循环者无法脱离酒店诅咒得到证实。（原文回跳第1187章）

## 原文回跳第1188-1189章·童倩笑脸意识与返大昌

杨间将黄金门藏入凯撒夹层、改造酒店布局。童倩苏醒后发现意识转入笑脸，须对抗笑声杀人本能与身后死尸；三人返大昌，杨间保存焦骨并面对鬼湖侵蚀加重的后患。（原文回跳第1188章、原文回跳第1189章）
