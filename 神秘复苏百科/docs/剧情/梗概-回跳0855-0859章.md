# 原文回跳第855-859章剧情梗概

## 原文回跳第855章·倒退的台阶

杨间小队清剿诅宅二楼时遇到会随门消失的八九十年代中年鬼影。柳白穆、张庆、万铜在上行台阶闭眼倒退十级后打开铁门，进入王家隐藏地牢。（原文回跳第855章）

## 原文回跳第856章·存在过去的钟

隐藏地牢内布满异常牢房和疑似沉睡厉鬼。杨间通过怀表与预知推断，摆钟和其所在门只存在于过去，普通现在时间中的人无法触及；小队决定不冒险深入。（原文回跳第856章）

## 原文回跳第857章·第二次钟声响起

第二次钟声没有重启，而是把古宅时间从七点推到七点半。柳白穆无头尸体从台阶走出被杨间再次钉住，柴刀媒介却被台阶灵异阻断；张庆、万铜所在牢房书桌出现神秘书写者。（原文回跳第857章）

## 原文回跳第858章·疯子

张庆、万铜合上诅咒笔记，释放被困书桌的民国遗留陈桥羊。陈桥羊自称牧鬼人，知道摆钟存在于过去，却宣称将释放王家地牢里的厉鬼。（原文回跳第858章）

## 原文回跳第859章·陈桥羊

陈桥羊捏碎柳白穆头颅、使摆钟在错误时间响起，古宅时间开始紊乱。杨间率队撤出诅宅，发现陈桥羊已成新高危变量；陈桥羊留下张庆、万铜做跑腿，准备日后寻找杨间。（原文回跳第859章）
