# 原文回跳第880-884章剧情梗概

## 原文回跳第880章·愈合的伤口

张伟抢走档案后，带阿飞等人转查城北。第十九栋602室内，一具由不同受害者肢体拼凑的尸体伤口正在愈合；张伟等人尚未察觉。（原文回跳第880章）

## 原文回跳第881章·安排

杨间将刘小雨安排入住观江小区古宅，与王珊珊同住，避免把重要人员集中于自己的别墅。古宅内仍有封存物和未开启危险房间。（原文回跳第881章）

## 原文回跳第882章·出租车

杨间试驾廖凡遗留的鬼出租车，确认鬼手可掌控方向盘、车灯鬼域可穿过建筑，但完整鬼影压制下最多安全驾驶约三十分钟，随后后备箱厉鬼会开始侵蚀车辆。（原文回跳第882章）

## 原文回跳第883章·一起离开的人

张伟等人查到602室，发现血迹和消失的人形痕迹后撤离。一名带尸臭的陌生存在混入人群，未被及时识别。（原文回跳第883章）

## 原文回跳第884章·江边

观江小区江面浮出死人脸和残肢。杨间小队推断疑似A级鬼湖事件造成远距离水系污染，决定先封锁大昌市水域，暂不放弃鬼邮局第四层任务去处理。（原文回跳第884章）
