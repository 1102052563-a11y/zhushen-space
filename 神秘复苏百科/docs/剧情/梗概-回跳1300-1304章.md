# 原文回跳第1300-1304章剧情梗概

## 原文回跳第1300-1301章·第二张人皮纸

王珊珊以卖掉鬼寿衣获得的鬼钱，买到用活人头发牵引亡魂可降低风险的方法。杨间随后从方镜记忆取到过去映照中的第二张人皮纸；纸面预示求助鬼邮局、秦老都会失败，且六点后必死。（原文回跳第1300章、原文回跳第1301章）

## 原文回跳第1302章·鬼童吞纸与脱离规则

杨间让鬼童吞下第二张人皮纸。鬼童出现思考能力并在沙地写出脱离规则：六点前杀死记忆中的陌生人。杨间据此认定需切断与过去映照的记忆联系。（原文回跳第1302章）

## 原文回跳第1303-1304章·过去总部围杀

过去映照中的总部以方镜死亡为由集结多名驭鬼者围杀杨间。杨间以金色火域先发制人，压住大部分对手，并以棺材钉、柴刀等手段逐个处理高威胁目标；围杀战局尚未完全结束。（原文回跳第1303章、原文回跳第1304章）
