# 原文回跳第1320-1324章剧情梗概

## 原文回跳第1320-1321章·合棺成功却引醒整栋木楼

王珊珊将一楼开启棺材中的无头尸体重新压回、合上棺盖，二楼餐桌鬼暂时停止啃食刘奇和鬼童；但这一步同时引发其余棺材与木楼构件复苏。她意识到人皮纸的每条真信息都可把人引向更深陷阱，试图折返二楼取回人皮纸，却被楼梯灵异困住。（原文回跳第1320章、原文回跳第1321章）

## 原文回跳第1322章·恶犬拉回杨间意识

木楼柱中无脸腐尸、窗外枯瘦影子等灵异相继复苏，腐尸更试图从昏迷杨间身上剥离鬼眼和其他灵异。恶犬最终将杨间意识拉回，杨间以七层鬼域重启自身、柴刀和鬼火压住腐尸，并驱退二楼其余异动。（原文回跳第1322章）

## 原文回跳第1323章·剪断餐桌束缚并取回人皮纸

杨间用刘奇头发作媒介，以鬼剪刀连续剪断连接地板灵异的诅咒线，助其挣脱八仙桌限制；随后同法救出鬼童。他从受压制鬼童腹中取回未被消化的人皮纸，确认王珊珊喂纸本身可理解，但在鬼童被限制时留下了风险。（原文回跳第1323章）

## 原文回跳第1324章·楼梯会合

杨间以鬼火在失控楼梯鬼域中开路，带刘奇、鬼童寻找王珊珊。王珊珊用骗人鬼项链对抗追来的老尸失败，关键时刻被杨间拉入鬼火路径。杨间暂以棺材钉钉住老尸、用骗人鬼项链修复刘奇身体，众人继续寻找离开木楼的路径。（原文回跳第1324章）
