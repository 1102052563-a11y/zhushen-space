# 原文回跳第1040-1044章剧情梗概

## 原文回跳第1040章·苗小善确认关系

苗小善在刘紫、孙于佳鼓励下向杨间告白。杨间因驭鬼者注定伤及普通人的风险犹豫，苗小善仍坚持自己的选择；二人关系由此推进。（原文回跳第1040章）

## 原文回跳第1041章·愿望贴纸代价

高明查明杨子锋以连衣裙女孩提供的愿望贴纸化鬼一小时，杀害曾侵害女友的学习会男生。杨子锋恢复普通人、坦白经过后，愿望代价触发，他在高明面前摔死，贴纸消失。（原文回跳第1041章）

## 原文回跳第1042章·张雷暂稳与协查开始

张雷以鬼妆阿红画出的鬼差图像暂压体内厉鬼，仍需驾驭第二鬼。杨间因愿望贴纸机制罕见，与高明约定由其照看苗小善，转而协查连衣裙女孩。（原文回跳第1042章）

## 原文回跳第1043-1044章·锁定连衣裙女孩
