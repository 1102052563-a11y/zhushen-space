# 原文回跳第1200-1204章剧情梗概

## 原文回跳第1200-1201章·抵达总部

杨间公开乘专机赴大京市，王察灵得知后继续以棋局拖延叶真。杨间抵总部后由秦媚柔、沈良接待，见到濒死的王小明、李军和阿红。（原文回跳第1200章、原文回跳第1201章）

## 原文回跳第1202-1203章·执法队长交易

王小明提议杨间担任执法队长，以召集、制约队长为代价，交出总部全部灵异资源调度权和人皮纸秘密。杨间认为风险与收益并存，约定当晚答复。（原文回跳第1202章、原文回跳第1203章）

## 原文回跳第1204章·高明案的走来的媒介

杨间、李军、阿红到平安大厦附近调查高明案，推断高明撞见隐藏凶手后被随手斩首。杨间触发大范围柴刀媒介，凶手以锈蚀大刀沿媒介反入侵，两人隔媒介交锋，身份待揭。（原文回跳第1204章）
