# 原文回跳第1125-1129章剧情梗概

## 原文回跳第1125-1126章·调包707与正面对峙

杨间早已篡改何月莲认知，令她并未真正挂上707门牌，却让骆胜、孙仁等误以为贵宾室已成凶间。杨间承认钓鱼目的，答应在所谓707房间进行赌局，反将所有设局者留在房内。（原文回跳第1125章、原文回跳第1126章）

## 原文回跳第1127-1128章·鬼湖积水清场

杨间以棺材钉先杀一名驭鬼者，随后面对孙仁女尸、骆胜红线假身、郑义静蜡尸。六层鬼域短暂压制后，鬼湖积水涌入房间，郑义静、张志和骆胜假身相继被清除；孙仁被棺材钉钉住。（原文回跳第1127章、原文回跳第1128章）

## 原文回跳第1129章·孙仁死与张羡光线索

孙仁在女尸与自身重叠时被杨间钉住，失血过多后死亡。何老板被杨间读取记忆并沉入积水；记忆证实二十余年前张羡光与何老板交易，何月莲及鬼画线索均指向张羡光。（原文回跳第1129章）
