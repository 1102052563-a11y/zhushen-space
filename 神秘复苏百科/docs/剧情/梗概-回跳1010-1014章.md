# 原文回跳第1010-1014章剧情梗概

## 原文回跳第1010-1011章·亡魂合作与孙瑞路线

张羡光率先支持杨间，油画亡魂多数同意以处理外界灵异事件换取变化。杨间、周泽、杨孝、张羡光离开油画邮局寻找孙瑞；杨孝提醒，油画亡魂不可完全信任。（原文回跳第1010章、原文回跳第1011章）

## 原文回跳第1012-1013章·染缸复制鬼与孙瑞踪迹

众人在油画深处发现染缸，红色染料会按倒影复制活人及其驾驭灵异。杨间凭七层鬼域重启和剥离鬼眼击败自己的染料复制鬼，确认染料是亡魂克星。随后众人找到已倒地的孙瑞。（原文回跳第1012章、原文回跳第1013章）

## 原文回跳第1014章·孙瑞自愿接任，叶真受邀

杨孝将孙瑞残存意识拉入梦境，杨间以鬼影暂压尸体内厉鬼。孙瑞为避免在大汉市复苏、也为终结邮局，自愿永久留守并成为新管理者。杨间决定让孙瑞撕黑信开启第六层，派李阳邀请叶真前来支援。（原文回跳第1014章）
