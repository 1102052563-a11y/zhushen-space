# 原文回跳第1145-1149章剧情梗概

## 原文回跳第1145-1146章·最后灵异房间与诅咒钢琴

杨间确认夜间凯撒酒店被最后灵异房间吞入，六层鬼域暂停灵异后得以进入本体。顶着香兰头颅的干尸演奏必死曲，杨间肢解干尸、以八音盒曲抵消诅咒，并收走钢琴。（原文回跳第1145章、原文回跳第1146章）

## 原文回跳第1147章·阿南的八十二年循环

阿南自称楚南，是民国大学生，被困至少八十二年，死亡后会在101房失忆复活，经历记录在102房。香兰来自701房，已复活失败；楚南同意带杨间一行见其他幸存者。（原文回跳第1147章）

## 原文回跳第1148-1149章·灵异电梯与三楼尸墙

楚南带队乘电梯绕过三楼，电梯内有鬼、不可抬头。三楼尸墙与未知厉鬼强行截停电梯，李阳堵门鬼只能暂挡；杨间以一根红烛驱退厉鬼，电梯得以继续通过。（原文回跳第1148章、原文回跳第1149章）
