# 原文回跳第795-799章剧情梗概

## 原文回跳第795章·凶险的城市

杨间、李阳确认大川市表面正常、实际遍布无影鬼奴。刘明新、蔡玉、杨小花自行入城观望，在加油站发现无头腐尸和木讷鬼奴；刘明新被灌满汽油后遭鬼奴车内烟头引燃死亡。蔡玉、杨小花逃亡，发现城市车辆和路人都在异常阻拦，无法轻易离开。（原文回跳第795章）

## 原文回跳第796章·各自的遭遇

李易、郭幽、柳青青抵大川市机场，发现机场人少、灯灭后灵异水变成鲜血，判断附近有鬼；三人绕停机坪逃离，躲避机场鬼奴和疑似失控客机。蔡玉内伤严重，要求杨小花联系李易、寻找杨间求援，自己赌救护车是否仍由活人驾驶。酒店方面，无影服务员送人头餐后，杨间、李阳所在五星级酒店爆破崩塌，二人靠堵门鬼保住总统套房。（原文回跳第796章）

## 原文回跳第797章·超市

杨间、李阳追踪假李乐平的卫星手机，遭大量无影鬼奴用车辆连环阻拦。两人抵达大型购物超市，发现货架摆满新鲜人头，鬼奴不断用人头替换腐坏头颅。超市内有李乐平卫星手机，说明假负责人或源头鬼与此地直接相关；大量鬼奴随后涌入，逼两人转移至五楼库房等待对抗。（原文回跳第797章）

## 原文回跳第798章·真假之人

人头超市的鬼奴像工作人员般维护人头库存，杨间在货架上找到真正李乐平的人头，判断白天见到的负责人只是鬼借人头、记忆伪装。鬼奴群发现二人后继续围困，杨间杀掉一个假李乐平鬼奴，确认其记忆互通。超市灯光亮起、人潮聚集，杨间、李阳确定源头鬼开始直接针对他们。（原文回跳第798章）

## 原文回跳第799章·问题和停滞

源头借无数鬼奴发声，称想杀杨间、身体腐烂且“身体就是你”。杨间发现鬼奴无影、灯光会照出活人影子，锁定影子为袭击媒介。影子人头靠近杨间无头鬼影，试图完成拼图；李阳以胸口女尸鬼拉扯阻止，却被鬼奴人潮干扰，拼图未成但源头撤离。杨间确认这很可能是无头鬼影缺失的头部，暂撤至天台并请求总部支援、召童倩与熊文文赶赴大川市。未知来电自称李乐平，事件继续升级。（原文回跳第799章）
