# 原文回跳第1090-1094章剧情梗概

## 原文回跳第1090章·重绘李军与女尸诅咒

阿红被重绘后苏醒，并重绘人皮李军。曹洋以鬼剪刀发现杨间、柳三背后均有鬼湖女尸诅咒；柳三遭整具女尸入侵，湿发和耳语难以彻底剪除。（原文回跳第1090章）

## 原文回跳第1091-1093章·独立女尸清除失败

鬼湖模仿柳三纸人能力，产生大量独立女尸。李军鬼画、柳三纸人、冯全坟土、曹洋人皮口袋均能暂压，却无法阻止女尸继续从积水出现。杨间确认每具女尸都是独立厉鬼，并推断鬼湖靠入侵对象重现其形象和能力。（原文回跳第1091章至原文回跳第1093章）

## 原文回跳第1094章·杨间制造水中反制者

杨间以窃取的鬼湖水域模仿其机制，让王善等复活记忆体淹死后化为水中灵异人。他一次制造一千二百名大川市死者记忆的男性灵异人，准备以自身水域的数量对抗鬼湖女尸。（原文回跳第1094章）
