# 原文回跳第920-924章剧情梗概

## 原文回跳第920章·第一晚

万州与两名驭鬼者在鬼林迷失、被密集鬼影杀死，鬼林外围随后多出三棵新树。古宅内首夜暂未直接爆发袭击。（原文回跳第920章）

## 原文回跳第921-922章·无法理解与第一个

古宅外出现多手拍门，门本未锁却没有来物进入。杨间关闭大门、保留白灯笼；随后因他拒绝交出棺材钉，杀死一名试图动手的驭鬼者，压住其余乘客。（原文回跳第921章、原文回跳第922章）

## 原文回跳第923章·入殓

杨间推断首日是入殓，以完整鬼影将老人尸体移入后堂红棺。古宅哭丧声停止，首日丧事步骤得到验证。（原文回跳第923章）

## 原文回跳第924章·七天变化

第二日夜临近，走廊黑椅被未知鬼推进，黑暗侵入房区。樊兴一行误触空房收音机媒介，被其确认存在；杨间判断当夜可能需守夜。（原文回跳第924章）
