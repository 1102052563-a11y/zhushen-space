# 原文回跳第1030-1034章剧情梗概

## 原文回跳第1030-1032章·大昌市夜游与鬼湖污染

刘小雨约杨间吃饭，熊文文为撮合母亲陈淑美而强行加入，四人随后游览大昌市。江边出现落水声、湿脚印和水中直立不腐尸体，杨间确认鬼湖污染已沿江河渗入大昌市，但暂不处理这疑似S级事件。（原文回跳第1030章、原文回跳第1032章）

## 原文回跳第1031章·李阳三鬼平衡成功

李阳独自撑过开门鬼手臂侵蚀，成功建立三鬼平衡。新手臂可毁掉普通门并触发周边熄灯的开门必死诅咒；其灵异状态暂时稳定，具体是否死机未确认。（原文回跳第1031章）

## 原文回跳第1033-1034章·学习会停电与鬼烛异动

大京市学习会男生以招魂游戏为借口停电，苗小善等人误判为灵异入侵，点燃杨间赠予的红色鬼烛。恶作剧被揭穿后，鬼烛火焰仍不规则膨胀收缩，苗小善决定不熄烛、继续核查，未知风险未除。（原文回跳第1033章、原文回跳第1034章）
