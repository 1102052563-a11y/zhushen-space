# 原文回跳第820-824章剧情梗概

## 原文回跳第820章·意识的侵蚀

完整鬼影侵蚀杨间意识，大川市大量受害者记忆强行涌入，使其痛苦失控。八音盒维持意识不灭，杨间却暂失身体控制；301室黑白老人和状态异常的柳青青开始从楼内外溢。（原文回跳第820章）

## 原文回跳第821章·可怕的扭转

杨间发现自己已部分融入鬼影、可尝试夺回身体控制。黑白老人靠近后，使杨间身体褪色消失、自身逐步具现实颜色，杨间判断其会抹除活人、以受害者为定位让过去灵异取代现实位置。（原文回跳第821章）

## 原文回跳第822章·柳青青的出现

李阳发现杨间试图抓取棺材钉，准备救援。柳青青突然出现，红旗袍替她抵住黑白老人的抹除，她将棺材钉交给杨间。杨间随即钉住地面鬼影，结束鬼影对身体控制的争夺，重新恢复行动。（原文回跳第822章）

## 原文回跳第823章·第七层

杨间先以六层鬼域短暂停滞老人，又首次进入第七层鬼域。七层并未直接攻击目标，而是让杨间自身回到遭抹除前状态；外界只经历瞬间。持续开启使鬼眼复苏压制八音盒，杨间被迫退出。（原文回跳第823章）

## 原文回跳第824章·重启自身

重启后黑白老人仍锁定杨间。杨间取出被拆散的倒视人偶，将其拼回并倒转，让人偶视线锁定老人；老人对杨间的抹除转移到人偶，黑白媒介逐渐消退。老人是否被真正关押、301室尸体是否仍会复苏均未确认。（原文回跳第824章）
