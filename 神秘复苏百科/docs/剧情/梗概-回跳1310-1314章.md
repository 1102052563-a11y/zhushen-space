# 原文回跳第1310-1314章剧情梗概

## 原文回跳第1310-1311章·十层鬼域击退孟小董

孟小董以大量过去分身封锁杨间的重启，并试图将其身体和意识一并取代。杨间以两只鬼眼各开五层鬼域，形成十层鬼域和时间重叠的无数自身投影，以叠加柴刀攻击耗尽替死娃娃、击退过去数小时内的孟小董。（原文回跳第1310章、原文回跳第1311章）

映照中取得的第二只鬼眼随即崩毁，十层鬼域与无限重启无法再用。杨间带走被棺材钉压住的一具孟小董映照尸体，准备交给鬼童吞食。（原文回跳第1311章）

## 原文回跳第1312章·斩断鬼梦联系并让鬼童增殖

杨间焚毁映照中鬼梦残躯和杨孝天头颅，切断最后主要熟人记忆，过去世界开始透明、显出木楼轮廓。他将孟小董尸体交由鬼童带走；鬼童随后显示出借活人媒介大规模增殖的能力，其与孟小董灵异的具体取得关系未明。杨间转赴人口密集的岛国城市准备迎击。（原文回跳第1312章）

## 原文回跳第1313-1314章·五名旧人围杀与鬼童守护

秦老带孟小董、罗千、罗文松、张洞到场。张洞首先令杨间大部分灵异沉寂，罗文松和罗千随即以门与坟土补上必死、埋葬袭击；鬼童以大量分身强行挡住攻击并转移无法行动的杨间。（原文回跳第1313章）

鬼童群体喊出众人姓名，借叠加诅咒削减寿命，又以数量与鬼差压制能力抵住坟土和门。张洞能暂时抹除鬼童灵异，五名旧人仍试图直取杨间；至第1314章，鬼童与旧人的对抗尚未分出最终结果。所有本段人物战斗及伤亡风险均属过去映照，不等同真实历史。（原文回跳第1314章）
