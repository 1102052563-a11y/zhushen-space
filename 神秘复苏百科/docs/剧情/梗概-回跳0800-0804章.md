# 原文回跳第800-804章剧情梗概

## 原文回跳第800章·李乐平的电话

真李乐平通过电话说明：他曾试图驾驭鬼影头，并用遗忘鬼抹掉驾驭当天记忆来规避意识侵蚀，却仍失败，鬼短暂控制他并侵蚀队友。李乐平躲在猛鬼区的明月小区，借小区内另一只鬼抵挡外部鬼影头，也维持小区的封锁。杨间意识到鬼邮局送信地址与李乐平藏身地重合，怀疑7栋301室可能与其有关，但尚未直接进入。（原文回跳第800章）

## 原文回跳第801章·机场汇合

杨小花伤重逃到主干道，杨间确认她有影子、仍是活人后将其带上车。无头鬼影侵入并拼接她的身体，修复骨折和出血，代价是短暂失去身体控制。杨间带她抵机场等待支援，鬼影头仍借鬼奴声音追踪。杨小花承认二楼信使不该越级介入任务，选择继续依附杨间求生。（原文回跳第801章）

## 原文回跳第802章·混入的影子

杨间、李阳、杨小花进入机场，李易、郭幽、柳青青藏在厕所，收到汇合信息后准备出来。三人离开时，鬼影头借保安鬼奴的影子跟随郭幽，影子一度呈现只剩头部的残缺形态，随后消失。此时无人察觉郭幽已被侵蚀，鬼在队伍中埋下内应。（原文回跳第802章）

## 原文回跳第803章·哭笑之声

童倩、熊文文专机强行降落大川市，车辆灯光将众人困在跑道并照出影子。童倩以笑脸鬼大范围清除无影鬼奴，再以哭脸鬼局部抵消笑声，保护活人。李易三人赶到，杨间承认汇合本身也是为了把鬼引出；熊文文开始预知，机场人潮继续逼近。（原文回跳第803章）

## 原文回跳第804章·钉着的影子

童倩笑声清场后，熊文文预知郭幽会杀死柳青青、令杨间复苏死亡。杨间发现郭幽影子方向相反、头部有浓黑轮廓，确认鬼影头侵蚀其意识。棺材钉钉住地面影子后，黑色影子人头从地面浮出并被压制；郭幽因维持意识的灵异中断而死。大川市鬼奴是否完全恢复未知，杨间选择带幸存者在专机休整，翌日再进明月小区。（原文回跳第804章）
