# 原文回跳第955-959章剧情梗概

## 原文回跳第955-957章·老婆婆拦路

出殡队在鬼林黄泥路遭301室提竹篮老婆婆拦路。其疑在过去时间，棺材钉、鬼域、人偶娃娃与柴刀媒介均无法有效关押；柳青青以红旗袍拖延，周登选择进鬼林引走厉鬼。（原文回跳第955章至原文回跳第957章）

## 原文回跳第958章·引鬼失败

周登被老婆婆抹除，第二只老婆婆出现并折返堵路。杨间一行抵达五坟空地前再遭拦截，李阳提议以牺牲换取杨间独自送信，但已无可行窗口。（原文回跳第958章）

## 原文回跳第959章·全员抹除与逆转选择

杨小花、李阳、柳青青先后遭抹除，老婆婆增至五只。杨间拒绝借鬼门逃离，决定开启第八层鬼域重启整片区域，并打开红棺让鬼影借民国老人尸体，试图改变对抗方式。（原文回跳第959章）
