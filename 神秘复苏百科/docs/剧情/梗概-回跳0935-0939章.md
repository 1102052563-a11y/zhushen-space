# 原文回跳第935-939章剧情梗概

## 原文回跳第935-936章·报丧取米与三香交换

杨间率众提白灯笼报丧，在鬼林五座老坟发现白米饭祭品。通过周登提前插入的一炷香及杨间补插的两炷熄香，众人取得三碗白米饭，作为第五日鬼宴的准备。（原文回跳第935章、原文回跳第936章）

## 原文回跳第937章·周登归队

众人在路旁发现盖脸纸覆盖的周登。周登曾被红旗袍女鬼夺灯追杀，借人皮面具混入鬼群、再用盖脸纸假死，直至被揭纸才醒来；他归队并被杨间警告不得擅自行动。（原文回跳第937章）

## 原文回跳第938-939章·吊唁日失控

众人挖鬼林树下尸体，仅找到四件破白丧服。第四日零点白灯笼失效、怪树倒塌，鬼林群鬼侵入；杨间以六层鬼域和棺材钉压住一只鬼婴，但纸人、黑衣鬼等继续涌入，队伍被迫退向红棺。（原文回跳第938章、原文回跳第939章）
