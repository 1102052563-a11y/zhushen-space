# 原文回跳第1195-1199章剧情梗概

## 原文回跳第1195-1197章·岛国人头鬼渗透

岛国除灵社携惠子与六名随员拜访杨间，其中小野因人皮鞋异变断头。杨间点燃黄金尸油灯，显出多名人员身旁的人头阴影和腐烂人头；他识破人皮鞋媒介陷阱，确认具智慧的人头鬼已渗透除灵社。（原文回跳第1195章至原文回跳第1197章）

## 原文回跳第1198章·总部求援

杨间留下惠子任公司翻译，封禁岛国人员进入大昌市。刘小雨报告大京市负责人高明遭猎杀、队长会议难以凑齐，且王小明癌症濒死；杨间同意赴总部。（原文回跳第1198章）

## 原文回跳第1199章·临行前的总部局势

王察灵持续藏匿饿死鬼并以棋局拖住叶真。王小明拒绝灵异续命，准备在死前见杨间；杨间备齐后手，乘专机前往总部。（原文回跳第1199章）
