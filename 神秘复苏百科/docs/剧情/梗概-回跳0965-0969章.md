# 原文回跳第965-969章剧情梗概

## 原文回跳第965-967章·无形收信人与红信完成

收信人不可见、不可触，只能听见脚步。杨间等以四把黑色太师椅困住其活动范围，杨间坐椅与对方形成媒介，令年轻男子收信人显现并将红信交付；任务完成后，男子老化成红棺老人尸体。（原文回跳第965章至原文回跳第967章）

## 原文回跳第968章·天井气球逃离

老人尸体复苏、封锁古宅，众人燃信纸的邮局路也被抹除。柳青青体内民国意识提示天井出口，周登接红色气球后承载众人升空逃离；老人最后抹除袭来，杨小花死亡，余者脱离灵异之地。（原文回跳第968章）

## 原文回跳第969章·返回现实

气球把杨间、李阳、周登、柳青青带至大洲市。柳青青独自离队，周登承诺向总部报告，杨间将李阳带回大昌市，准备找黄子雅修复残肢。（原文回跳第969章）
