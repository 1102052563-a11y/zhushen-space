# 原文回跳第1170-1174章剧情梗概

## 原文回跳第1170-1171章·十号房消失与朱见傀儡

杨间移开火炉后发现十号房已成墙面，确认走廊布局被未知存在篡改。董玉兰、王根全处的朱见是厉鬼傀儡，杨间以柴刀、棺材钉将其压制。（原文回跳第1170章、原文回跳第1171章）

## 原文回跳第1172章·点燃三楼尸体计划

杨间采纳李阳建议，准备以灵异火炉点燃三楼尸墙、削弱层内厉鬼。香兰则集合五名循环者，计划从封存画像取回过往记忆和厉鬼。（原文回跳第1172章）

## 原文回跳第1173-1174章·尸潮掩埋与三楼鬼现身

三人抵达三楼，火炉复燃却影响电梯，电梯离开后无退路。棺材钉暂钉住三楼鬼，尸体墙随即倾泻掩埋三人；杨间以鬼影、鬼湖爬出，确认三楼鬼可附身任意尸体，火炉无法顺利焚尸。（原文回跳第1173章、原文回跳第1174章）
