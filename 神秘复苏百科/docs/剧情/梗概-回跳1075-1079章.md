# 原文回跳第1075-1079章剧情梗概

## 原文回跳第1075-1076章·湖底黑棺与窃取鬼湖

杨间沉至湖底，发现曹洋在第三层仍有意识，黑棺位于第四层。刘老板向冯全讲述黑棺曾由太平古镇祠堂经黑船运入灵异之地，鬼湖由此形成。杨间则逐步窃取鬼湖力量，开始恢复行动。（原文回跳第1075章、原文回跳第1076章）

## 原文回跳第1077章·鬼橱与愿望贴纸对冲

杨间为救阿红，把写有“阿红不会溺死”的愿望贴纸塞入鬼橱。两者冲突后鬼橱炸裂，阿红恢复意识、免于溺亡；赵小雅身边的愿望鬼同步离开。（原文回跳第1077章）

## 原文回跳第1078章·鬼湖现实入侵

杨间窃取鬼湖灵异持续打破旧平衡，鬼湖开始向中州市城郊现实显现。太平古镇四名旧人开始前往应对，冯全也察觉行动严重失利。（原文回跳第1078章）

## 原文回跳第1079章·银子即鬼湖厉鬼

杨间完全恢复水下行动、可分开湖水，打开黑棺后发现失踪队长银子。银子尸体被棺材钉钉中后融为水渍，又以厉鬼姿态从杨间身后重现，鬼湖源头对抗尚未结束。（原文回跳第1079章）
