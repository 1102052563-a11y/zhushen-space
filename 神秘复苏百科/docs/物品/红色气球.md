# 红色气球

红色气球是鬼邮局四楼红信出现时一同从天井上方飘落的灵异物品，红色信封系在细绳末端。杨间取下信件后，细绳会黏入带有灵异力量者的身体并带其升空。（原文回跳第900章、原文回跳第901章）

## 规则

- **压制灵异**：气球能带离地面、压制被细绳系住的厉鬼；飞得越高，压制越强。（原文回跳第901章）
- **普通人可持有**：杨小花直接持线未被带走，能够正常携带，显示气球主要针对具有灵异力量的目标。（原文回跳第901章）
- **脱离方式**：杨间以柴刀斩断细绳后恢复落地，气球也重新降至可触及高度。（原文回跳第901章）

它需先将绳子系到目标身上，适用条件、能否持续压制高危厉鬼及普通人被带离时的后果均待后文。杨间暂命杨小花保管。（原文回跳第901章）
