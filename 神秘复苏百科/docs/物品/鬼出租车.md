# 鬼出租车

鬼出租车是廖凡使用的老旧灵异出租车，外观近似报废古董车。它能进入鬼域、突然改变位置撞击目标，也能压制或驱散冯全鬼雾，并在车门关闭后削弱外部鬼笑声。（原文回跳第831章、原文回跳第833章）

车辆撞中冯全后使其厉鬼短暂停滞；撞中童倩后将其重伤并打断鬼笑。车辆熄火后再次启动会出现浓尸臭、后备箱撞击、车身震动和发动机异常，说明使用或重启可能存在未明灵异代价。（原文回跳第831章、原文回跳第833章）

其完整来源、驾驶条件、能否长时间压制厉鬼及是否会自行失控均不详。（原文回跳第831章至原文回跳第834章）

#### 原文回跳第841章·被杨间封存

廖凡死亡后，鬼出租车留在观江小区。李阳等人暂时封存该物，未再尝试驾驶或启动；其后是否被移交、关押条件是否足以限制车辆待后文。（原文回跳第841章）

#### 原文回跳第882章·杨间试驾并确认三十分钟界限

杨间以鬼手才能转动卡死的方向盘；车灯形成鬼域，可穿过建筑，车辆适合作为团队逃生和隔绝外部厉鬼的工具。普通活人无法稳定驾驭，踩油门会有踩入尸体的触感，车内也会出现尸臭、收音机异响和后备箱撞击。（原文回跳第882章）

完整鬼影压制下可连续安全驾驶约三十分钟；超过该时间，后视镜会显现从后备箱伸出的淤青死手、后排变暗，鬼影也受干扰，显示车内厉鬼将现身。停车可暂时令异象退去。杨间没有打开锈死后备箱，决定日后交给冯全掌控。（原文回跳第882章）
