# 纸船

纸船是杨间在太平古镇隐藏古街扎纸店花三元纸币买下的两层木船纸扎，约二十厘米长、外观普通。扎纸店以“三元任选一件”强制招揽，杨间避开纸人，选择纸船。（原文回跳第1060章、原文回跳第1061章）

纸船用途、能否在鬼湖中变大或承载活人均未验证。杨间因正处理鬼湖而选择它，认为这类古街交易所得物品不应视作普通纸扎。（原文回跳第1061章）

#### 原文回跳第1081、1087章·浮水、焚化与化为巨船

纸船令柳三从鬼湖深处获得上浮机会，后被太平古镇旧人夺走。独眼老人以特殊火柴焚烧纸船，浓烟中显现一艘大型木船并落于鬼湖，成为杨间带李军、柳三脱离湖水的载体。（原文回跳第1081章、原文回跳第1087章）
