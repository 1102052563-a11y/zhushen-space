# 买命钱

买命钱是一张面额“七元”的异常纸币，刘子文在送信任务中获得的烧给死人纸币。将它交给一只厉鬼后，该鬼会永久不袭击持有人，即使满足杀人规律也同样有效。（原文回跳第1003章）

刘子文原有三张、已用两张，最后一张被杨间在其死后取得。该物为一次性且来源罕见，杨间认为其价值可高于替死娃娃、鬼烛，具体交易方式、是否只对一只鬼生效仍待后文。（原文回跳第1003章）

#### 原文回跳第1059章·疑似古街货币

杨间在太平古镇隐藏古街获得一张三元异常纸币，发现其风格与七元买命钱相近，推测二者可能是古街使用的钱币。七元纸币是否确能在古街消费、买命规则是否只是其一种用途待后文。
