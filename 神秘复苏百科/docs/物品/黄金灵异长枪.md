# 黄金灵异长枪

黄金灵异长枪是杨间在观江小区一号安全屋尝试制作的临时武器。其设计为以诡异柴刀作枪头、棺材钉作枪尾，中段以黄金包覆并留出缝隙，既能经鬼域接触柴刀触发媒介，也能以露出钉尾接触厉鬼。杨间希望即使自身厉鬼复苏，灵异本能也不易完整使用这种人为组合武器。（原文回跳第828章）

首次成品因纯黄金过软，被杨间挥动后立即弯折，未具实战价值。他取回棺材钉继续压住鬼影，并计划加入特种钢重新制作；最终是否完成、能否有效限制复苏后的杨间均待后文。（原文回跳第828章）

#### 原文回跳第830章·加入特种钢后的定型成品

杨间取得特种钢后重制枪身，以柴刀作单刃枪头、棺材钉嵌入枪尾，黄金夹层和刻意保留的裂缝让鬼域可接触柴刀触发媒介。成品能承受杨间挥动，不再像纯黄金版本般弯折；其另一端仍钉住杨间鬼影，暂不能自由使用。（原文回跳第830章）

杨间判断复苏后的厉鬼缺乏精准触发媒介的技巧，难以完整使用该武器；这是其设计判断，真实复苏后效果尚未验证。（原文回跳第830章）

#### 原文回跳第838-839章·被夺走后由杨间以鬼手收回并实战钉杀

顾程打开铁棺后取走长枪，试图拆取其中棺材钉和柴刀；杨间苏醒、红光鬼域压住顾程鬼域后，以鬼手隔空夺回长枪。杨间随后以枪尾棺材钉刺穿廖凡头部，压制其灵异并令其无法维持稻草人身体，确认该武器可在实战中完成钉杀。（原文回跳第838章、原文回跳第839章）

#### 原文回跳第848-849章·诅宅内钉杀与柴刀媒介斩杀

杨间在鬼域受诅宅干扰时仍以投枪方式让棺材钉贯穿柳白穆、钉死三楼墙壁。后有刘玥夺取长枪，却无法以柴刀伤到杨间，因其不知以鬼域接触裂缝、触发柴刀媒介的使用技巧；杨间收回长枪后隔空以媒介斩开刘玥头颅。（原文回跳第848章、原文回跳第849章）

#### 原文回跳第978章·覆入失衡必死手掌

杨间将从古宅太师椅鬼斩下的手掌，以五层鬼域拉扯为一层死人皮，覆在长枪枪身。该手掌规律为近距离接触后使目标失去平衡即死；长枪命中目标后可借冲击触发此规律，同时保留柴刀媒介斩击和棺材钉压制能力。（原文回跳第978章）
