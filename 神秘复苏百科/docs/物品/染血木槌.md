# 染血木槌

染血木槌是鬼邮局四楼信使王风持有的一把旧木槌，槌头沾血，具备压制灵异的效果。柳青青打开404卧房衣橱时被它击中，木偶头部被砸瘪；杨间的鬼手被击中后短暂麻木，半边身体近乎失去知觉。（原文回跳第893章、原文回跳第894章）

杨间据此判断，木槌能令鬼短暂失去行动、近似沉睡；连续命中可能叠加压制至意识沉睡，但只是他的现场推测。木槌无法直接杀死杨间或柳青青，准确触发条件、持续时间、使用代价和能否压制全部厉鬼均待后文。（原文回跳第894章）

#### 原文回跳第895章·被杨间夺取并交由李阳试用

杨间压制王风三人、窃取并修改王风记忆后收走木槌，未从王风记忆找到明确使用代价。他因持有柴刀与棺材钉，转将木槌交给李阳，以提升团队对鬼能力；李阳尚未实际使用。（原文回跳第895章）
