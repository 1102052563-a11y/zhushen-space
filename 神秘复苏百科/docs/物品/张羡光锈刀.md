# 张羡光锈刀

张羡光使用的老式锈蚀大刀。杨间握住刀柄会出现手臂僵硬、尸斑和尸臭等侵蚀；握刀时视野会浮现无规则裂痕，沿裂痕挥刀能将对应视线目标及现实空间一并撕裂。（原文回跳第1275章）

刀的撕裂不是普通肢解。它会将目标肉身和灵异分成彼此失联的独立部分：厉鬼可能被分成多只仍能活动的鬼，驭鬼者则因体内灵异平衡被拆散而迅速失去战力甚至死亡。裂痕余留会继续影响现实一段时间。（原文回跳第1275章）

杨间曾以此刀将鬼橱斜向分裂，确认该刀与鬼眼视线高度适配。完整使用限制、侵蚀积累和是否存在其他规律待后文。
