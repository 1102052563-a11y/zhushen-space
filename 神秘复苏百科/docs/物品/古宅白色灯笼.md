# 古宅白色灯笼

古宅白色灯笼原为门口红灯笼，首夜零点后褪为白色并显出黑色“奠”字。周登第二日盗取一盏，提灯沿后门黄泥路进入鬼林；杨间据丧事流程判断，白灯笼被带离古宅等同提前对外报丧。（原文回跳第919章、原文回跳第927章至原文回跳第929章）

提前报丧使古宅内守夜与报丧规则重叠，后堂庇护失效，外部厉鬼开始推动后门入侵。杨间决定以取回前门剩余白灯笼、让李阳携灯执行“报丧”纠正日期。（原文回跳第929章）

李阳取灯后确认，提灯者不会受周围厉鬼袭击，正确报丧应带灯在古宅外游走、引走群鬼，而非返回后堂。其持续提灯绕宅行走，使外部鬼停止入侵；第三日零点，杨间再率众随白灯笼离开古宅，规则得到纠正。（原文回跳第931章、原文回跳第933章、原文回跳第934章）
