# 鬼邮局黑色信件

黑色信件是鬼邮局五楼出现的特殊集体信，由已死信使“老李”长期持有并封在502房间。旧五楼信使把老李制成介于信使、死人和厉鬼之间的异类，以规避不送信即死的诅咒，令任务长期中止。（原文回跳第992章、原文回跳第994章）

其任务要求所有五楼信使共同参与，最终仅成功投信的一人存活，其余人视为失败并承受诅咒。老李推测黑信代表死亡；杨间则怀疑它是在筛选能承担邮局职责的特殊信使，确切目的尚未确认。（原文回跳第994章）

杨间破除502房间媒介、取走黑信后，邮局重新开始运作，外界五楼信使已察觉异动并计划在早六点聚集夺信。最终收件地址、任务期限与失败机制细节待后文。（原文回跳第992章至原文回跳第994章）
