# 玻璃瓶尸体碎片

鬼邮局内散落若干封存于黄色液体玻璃瓶中的尸体碎片，已见人头、手臂及油画内另一条手臂。碎片外观长期不腐，且会偶尔睁眼、抽动，疑属于被肢解保存的驭鬼者或厉鬼。（原文回跳第987章、原文回跳第1007章）

杨间现已取得三块碎片；已知另有一块在501房间。老李称更多碎片可能在邻房或油画内，但身份、完整数量、拼齐后的结果仍不明。（原文回跳第994章、原文回跳第1007章）

## 原文回跳第1020-1024章·拼全女尸

黑信撕毁后，一楼天井信纸空间显出女尸躯干，501房间取得双腿，505唱片机上的手臂则是最后一块。杨间将头、躯干、双腿与双臂拼全；女尸睁眼后，邮局开始从五楼向下逐层坍塌，真实变化尚未揭晓。（原文回跳第1020章、原文回跳第1024章）
