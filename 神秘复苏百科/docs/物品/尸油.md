# 尸油

杨间在大澳市一所民国老宅改建的餐厅地下室发现：一具被锁链、黑布头罩和脚底黄金针限制的干尸厉鬼，持续滴出黑色尸油。餐厅以尸油灯掩盖或利用其灵异，具体用途不明。（原文回跳第1116章、原文回跳第1117章）

杨间取走大半瓷盆尸油装入啤酒瓶，计划交陈博士研究；该行为是否打破原有关押平衡待后文。（原文回跳第1117章）

#### 原文回跳第1140章·交陈博士研究

杨间将尸油交尚通大厦研究部。陈博士说明厉鬼附属物可能承载短暂灵异，部分尸油可制白色鬼烛；本瓶具体效果需王勇配合约一周研究，制成道具预计更久。（原文回跳第1140章）

#### 原文回跳第1193章·制成黄金尸油灯

陈博士以大半瓶尸油制成一盏黄金油灯。油灯常态近乎不耗油，点燃后能照出隐藏厉鬼，并可能屏蔽持灯者被厉鬼感知或杀人规律；完整机制、对抗时消耗和适用范围待实战验证。（原文回跳第1193章）
