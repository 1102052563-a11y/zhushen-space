# 黑色太师椅

古宅内现有四把外观、木纹和做工完全一致的黑色太师椅。第四日其中一把后的枯手厉鬼曾按死大强，杨间连续以柴刀断其双手，降低其行动力。（原文回跳第924章、原文回跳第944章、原文回跳第949章）

周登据古宅七间房、六座旧坟与首日老人尸体“从左椅换至右椅”的异常，推测本应有七把椅子，且它们可能彼此互通、能将椅上目标转移。第七日收信人是否通过椅子到来、其余三椅去向待后文。（原文回跳第964章）

第七日，四椅可实际接触无形收信人：封住走道、房门后能阻挡其离开；杨间坐上其中一把、收信人坐对面椅时，收信人从不可见状态显现。椅子完整规则、是否真有七把仍待后文。（原文回跳第966章、原文回跳第967章）
