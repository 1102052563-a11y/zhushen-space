# 盖脸纸

盖脸纸是第二站纸灰十字路口中出现的灵异黄纸，尺寸大于普通纸钱，原本贴在一只蜡黄尸体的脸上，用于入殓遮面。周登下车后从漫天纸灰中截获三张残纸。（原文回跳第913章）

杨间认为它是一次性消耗类灵异物品，可能与鬼烛、替死娃娃相似；他从周登手中取走损毁最少的一张。（原文回跳第913章）

周登在鬼林被红旗袍女子追杀、灯笼被夺后，将盖脸纸覆上自身脸部，进入不会引发厉鬼复苏、也不受厉鬼袭击的假死沉睡状态；需他人揭纸才能苏醒。杨间在第四日将一张纸用于杨小花，使其假死并被红色气球带起，苏醒后能否保持存活待后文。（原文回跳第937章、原文回跳第939章）

第六日，杨间揭下杨小花脸上的残缺盖脸纸，她确认假死期间意识清醒却无法感知外界；残缺处使封存不完全。揭纸后她恢复行动，红色气球随失去灵异目标而解除束缚。（原文回跳第954章）
