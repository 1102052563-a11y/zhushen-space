# 鬼宴白米饭

鬼宴白米饭是古宅后方鬼林五座老坟前的青花碗祭品，饭粒半生不熟、未腐败。杨间等人推断第五日为鬼宴，须在第三日报丧的安全期提前取得，错过后难以再进入坟地。（原文回跳第935章、原文回跳第936章）

古宅棺前原有三炷香对应三碗白米饭：周登提前将一炷香插在第二座坟前，致坟塌、红旗袍女鬼离开，杨间在第三日再将余下两炷熄香插入两座坟，换取两碗饭。三香换三饭未触发即时危险；香若在守夜中烧尽，则会透支第五日鬼宴的食物与安全。（原文回跳第936章）

第五日零点，群鬼全面入宅后，老鹰将米撒向鬼、周登将碗饭置地，均未能驱鬼或保命；撒米无效，置碗反被黑椅鬼撞翻并迅速吞食。（原文回跳第949章）

正确用法是以活人鲜血染红米饭、贴身供靠近的鬼取食。每取一粒，鬼会暂时隐去、停止袭击；米饭离人过远或未染血均无效。同一只鬼会再次“饥饿”并重复索取，三碗总量在第五日末逐渐耗尽。（原文回跳第950章至原文回跳第953章）
