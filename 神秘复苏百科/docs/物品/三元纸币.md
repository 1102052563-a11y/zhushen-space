# 三元纸币

三元纸币是太平古镇隐藏古街面具摊退给杨间的绿色异常纸币，现实中不存在这一面额。杨间将女子从古街带走的怒脸面具放回摊位后，面具消失，摊位出现该纸币。（原文回跳第1059章）

其款式与杨间持有的七元买命钱相近，杨间推测两者可能是古街货币；普通情侣买走面具时可能以未知代价付款。纸币用途、交易规则及是否能与七元纸币合用待后文。（原文回跳第1059章）

#### 原文回跳第1060-1064章·古街消费与渡船船费

杨间以三元纸币购得扎纸店纸船，店内异常随即平息。柳三确认异常纸钱有三元、四元、七元三种面额，七元最稀少；午夜黑色渡船收取七元纸币的部分纸面作为船费，余下纸币变为三元。具体面额规则与物品交易价值待后文。（原文回跳第1060章、原文回跳第1061章、原文回跳第1064章）
