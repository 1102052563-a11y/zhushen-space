# 人皮纸

## 概述

人皮纸是杨间持有的一张诡异人皮，可写出未来方案与线索，却会在方案中留下致命漏洞。第658章，杨间根据其利用尸水进入平安科技研究基地、介入灵位实验的现象，认为它并非只会被动书写，而可能借曾吞入的厉鬼活动；其完整能力、来源、意识与最终目的均不详。（第658章）

## 第657-658章·借尸水进入基地的推测

杨间在基地五楼窗边发现暗褐色死人皮和尸水痕迹，鬼童又差点把地上的人皮纸吞掉。人皮纸上留有鬼童的黑青手印，使杨间判断鬼童曾因第二阶段规律触碰到它；尸水则被认出是人皮纸早年在黄岗村吞入、原先由叶俊驾驭的灵异。杨间据此推测，人皮纸能借吞入的尸水从其埋藏地下的位置活动到基地，后被鬼童追逐并吞掉尸水，自己则遗留在楼内。（第657章、第658章）

此推测令杨间重新串联卫景复现、郭凡遭灵位鬼入侵、自己与卫景在灵位实验中失控等事件，认为人皮纸可能预知并利用实验布置了更大的陷阱。它之所以未得逞，或因鬼童这个不在人皮纸预料中的异类介入；这是杨间的判断，不能确认人皮纸是否真的操控尸水、参与灵位异常或存在自主意识。（第658章）

## 使用风险与保留决定

杨间承认人皮纸的方案危险，且每次看似给出活路时都可能留下日后才会发挥作用的漏洞；但他也认为在走投无路时，人皮纸至少提供赌命的机会。八音盒事件中，纸上“相信王小明”的提示在结果上成立，杨间因此没有立刻以柴刀毁掉它。（第658章）

第659章，杨间用市郊别墅地下工作室的模具和黄金制成空心金球，将人皮纸装入后焊死，再以金链挂到鬼童颈上。他打算以鬼童约束人皮纸活动，若出现异常便让鬼童吞掉它；这种“以鬼制鬼”的安排是否可靠、金球能否长期阻止人皮纸活动及鬼童会否反而吞食人皮纸，均不详。（第659章）

#### 原文回跳第1232-1233章·王小明的身份推断

王小明认为人皮纸或许是具有活人意识、却遵循厉鬼行为的驭鬼者或幸存者，而非单纯灵异物品；其长时段未来信息应属推测，内容倾向真实但会隐瞒决定性条件。此为王小明推断，真实身份、来源和意识归属仍未证实。（原文回跳第1232章、原文回跳第1233章）

## 原文回跳第827章·鬼童胁迫下暴露意识线索与覆脸陷阱

杨间为解决第二次八音盒诅咒和完整鬼影侵蚀，取出金球中的人皮纸。纸面先以“遗书”诱导他开启民国古宅第三间房，杨间识别为明显陷阱，命鬼童吞食人皮纸；纸在被吞近半时改写，短暂留下“人的意识到底是什么？”这一问题。（原文回跳第827章）

鬼童松口后，人皮纸又给出方案：在两日后诅咒爆发时解除棺材钉、让鬼影入侵并以人皮纸覆脸，醒来后即可解决问题。杨间认为该方案将自己引向明显陷阱，不予采纳；但“意识”问题被他保留，后成为询问陈博士的核心。人皮纸继续由鬼童以金球看守。（原文回跳第827章）

#### 原文回跳第1316-1319章·木楼救援中的连环提示

王珊珊在棺材木楼二层以人皮纸询问杨间状态，纸先称杨间已“不在这个世界上”、会“永远”受困，后又给出“趴在地上可以看见附近的鬼”及“合上开启棺材可暂封厉鬼”等信息。提示均含部分事实，却将王珊珊和鬼童引向二楼餐桌鬼、棺材及整栋木楼复苏的连环风险。（原文回跳第1316章至原文回跳第1319章）

为避免继续受其摆布，王珊珊在鬼童被餐桌灵异束缚时将人皮纸喂入其体内；因鬼童能力同受压制，纸尚未被消化，后续是否反向影响鬼童待后文。

#### 原文回跳第1320-1324章·从受压制鬼童腹中取回

王珊珊依纸面提示合上无头尸体棺材，短暂压住餐桌鬼，却引起木楼其他棺材与构件灵异大规模复苏，验证提示并未提供无代价生路。杨间苏醒后指出王珊珊喂纸的处置可以理解，但时机错误：被束缚的鬼童无法发动饿死鬼能力消化它。（原文回跳第1320章、原文回跳第1323章）

杨间以鬼域从鬼童腹中直接取出完整人皮纸，重新保管。人皮纸是否已在鬼童体内留下影响、其对木楼连环风险的作用范围均待后文。
