# 鬼骰子

鬼骰子是一红一黑两颗骨制骰子，红骰黑点代表人，黑骰红点代表鬼。王风在鬼邮局三楼送信时取得，双方依次掷点，点数高者获胜；人赢只能令参与的鬼暂退，人输则立即死亡。（原文回跳第930章、原文回跳第931章）

游戏开始后，人必须在十秒内掷出骰子；鬼可以脱离游戏，人脱离则会被鬼杀死。后门厉鬼被骰局拖住期间，王风第五局输给鬼而死，后续信使接手亦死亡；老鹰在八音盒诅咒保护下即使掷输仍未死亡，得以维持游戏至李阳带灯引走外部厉鬼。（原文回跳第930章至原文回跳第933章）

第五日鬼宴中，老鹰在多鬼入侵下以骰局强制中断袭击，避免当场死亡；但一旦退出，体内外的厉鬼袭击会继续，他已被迫长期维持游戏，无法再正常行动。（原文回跳第949章）
