# 灵异火炉

灵异火炉原位于38号房，以带灵异的尸骨为燃料，旁边有红皮厉鬼看守。火炉火光会灼烧活人和驭鬼者，却可削弱、燃烧灵异侵蚀；炉灰可阻碍厉鬼袭击。（原文回跳第1165章、原文回跳第1168章）

杨间以黄金绳拖走火炉，计划利用三楼堆积尸体为燃料焚烧该层厉鬼。火炉会持续复燃并压制附近灵异，使电梯难以运转；三楼点火结果待后文。（原文回跳第1168章、原文回跳第1173章、原文回跳第1174章）

杨间将鬼手伸入炉火，取出燃烧焦骨后以火星点燃三楼尸海。炉火使鬼手获得入侵、点燃人体和灵异的能力，但也持续灼烧杨间；三楼尸鬼一度以尸体压住火炉，最终无法阻止火势扩散。（原文回跳第1178章、原文回跳第1179章）

三楼焚尸后，火炉和红皮守炉鬼仍留在灰烬中。杨间选择将完整火炉留在凯撒三楼，认为其可平衡鬼湖侵蚀却无法安全带离；仅取走一块燃烧焦骨。（原文回跳第1187章）
