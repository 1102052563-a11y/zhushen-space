# 灵异中药

中江市中药铺老人配制的特殊药物，外观为普通油纸包裹的灰白药末，近似骨灰。老人称其只能延缓厉鬼复苏，不能根治驭鬼者问题。（原文回跳第1270章、原文回跳第1271章）

杨间在白水镇将一包强行塞入灵异失衡的刘奇腹中。药力以稳定阴冷灵异压制其体内多只鬼，使失控灵异暂时沉睡，并令其被抹去的五官恢复；药力持续期间刘奇没有复苏风险，但完全消散后的反噬和维持时间尚不明确。（原文回跳第1292章）
