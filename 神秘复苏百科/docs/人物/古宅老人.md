# 古宅老人

古宅老人是红棺内的民国驭鬼者遗体，也是古宅七日丧事的核心。其生前与鬼林五座老坟中埋葬者疑同属七人队伍；生前照片中的年轻状态则在第七日作为红信收信人，通过黑色太师椅显现。（原文回跳第962章、原文回跳第967章）

第四日开棺时，老人尸体坐起，可压制绝大多数入宅鬼。第六日，杨间以鬼影短暂借尸，借其强制抹除灵异的力量消除两只301室老婆婆，再借其压制鬼眼开启八层鬼域重启。（原文回跳第940章、原文回跳第960章、原文回跳第961章）

红信交付给年轻状态后，该人迅速老化为红棺老人尸体，显示年轻收信人和已下葬老人是同一人。尸体随后复苏、封锁古宅并以挥手抹除灵异；其最终状态及与鬼邮局、301室的完整关系待后文。（原文回跳第967章至原文回跳第969章）
