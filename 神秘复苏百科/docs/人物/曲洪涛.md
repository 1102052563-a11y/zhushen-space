# 曲洪涛

曲洪涛是藏在鬼邮局四楼404卧房衣橱内的信使。老鹰认出其身份；他与两名同伴利用曾有厉鬼藏入而异变的衣橱，隔绝内外动静以避开夜间灵异。（原文回跳第893章、原文回跳第894章）

#### 原文回跳第893-894章·衣橱伏击与现身

曲洪涛一方曾用染血木槌击中404撞墙鬼头部，自认为可借此安全藏身。柳青青开衣橱时被其同伴持槌袭击，杨间随后以棺材钉钉住曲洪涛手臂、将其拖出；他承认衣橱内连自己共三人，并被迫唤出王风等同伴。（原文回跳第893章、原文回跳第894章）

曲洪涛是否持有灵异、与王风和第三名同伴的具体关系，以及是否可信均待后文。

#### 原文回跳第896-898章·死于潜伏信使鬼

曲洪涛与王风留在404卧房后，曾因怀疑而想躲回衣橱，被杨间阻止。泥脚印鬼踹开房门时，他在众目下突然僵住、随即死亡；杨间未看清杀人过程。其临死前视线方向包含老鹰、柳青青和王善尸体，后续成为锁定王善尸体的线索。（原文回跳第896章至原文回跳第898章）
