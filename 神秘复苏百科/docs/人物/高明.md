# 高明

## 简介

高明是大京市的一名国际刑警。鬼差事件紧急会议扩大后，他作为赶到总部的顶尖驭鬼者之一在场；副部长曹延华决定让所有已驾驭两只鬼的与会者集体护送王小明前往实验室，高明随队由李军的鬼域带离会议室。原文没有交代其外貌、所驾驭厉鬼、具体职务、过往履历或是否已驾驭两只鬼。（第459章）

## 经历

#### 第459章·加入实验室护送队

王小明认为实验室内仍开启的鬼棺可能与鬼差存在联系，提出亲赴研究；童倩、冯全、李军先后表态同行，曹延华随后下令让在场所有已驾驭两只鬼的驭鬼者集体行动，既护送王小明，也带走鬼棺和其他重要实验物资。原文在列举赶到会议的人员时点出高明是大京市另一名国际刑警，说明他属于此次临时集结的力量之一。李军展开青绿色鬼域，将除曹延华外的与会者一并转移向实验室；高明是否实际抵达、在队中的职责、能力表现及随后生死，均未写明。（第459章）

## 关系

#### 原文回跳第1038章·接手学习会灵异杀人事件

高明夜间赶到学习会公寓，与正在惩处万皓的杨间会面。他得知有人借灵异力量杀人、学生抢夺鬼烛后，决定将万皓带回审查并按程序处理其他涉事成年人；杨间将后续交给他，未知杀人者及手段仍待查。（原文回跳第1038章）

#### 原文回跳第1041-1044章·追查愿望贴纸女孩

高明的眼眶可在无色视野中辨识灵异色彩。他锁定杨子锋并取得愿望贴纸、连衣裙女孩线索，却因顾忌身旁显现的厉鬼而未能救下杨子锋；愿望代价触发后，杨子锋摔死。（原文回跳第1041章）

他以照看苗小善为条件请杨间协查。二人锁定女孩所在小巷，却被其“坏人无法发现或接近”的许愿保护阻隔；杨间以六层鬼域突破后，女孩伴鬼开始显现并出现赵开明等死者诅咒投影。（原文回跳第1043章、原文回跳第1044章）

#### 第645-648章·识别鬼童后拒绝介入

高明此时兼任平安科技研究基地保安队长，实际仍是驭鬼者。他在楼外看见小张跨出大楼后立即倒地，结合此前进入大楼时险遭袭击的经历，确认楼内鬼已形成“进出大楼者会被杀”的封锁规律。他又认出鬼童所穿衣物是原属饿死鬼、后被杨间从姜尚白身上取回的鬼寿衣，因而判断鬼童与杨间有关。（第645章、第646章）

高明认为鬼童能无视其他鬼影响、快速发动连续袭击，硬碰会促使自身厉鬼复苏，故不愿强行处理；他选择远离大楼，把楼内陈博士等人的困境留给杨间或总部处理。第648章，卫景转述高明曾接触鬼童、总部监控也录到其影像；高明是否已向总部完整报告、他自身曾承受何种袭击及以后是否再介入均不详。（第646章、第648章）

#### 原文回跳第1198-1199章·被猎杀引发总部会议

高明被不明人员猎杀，体内厉鬼被夺，只留残破尸体。其死引发曹延华拟召开队长会议，接任总部城市负责人的张雷继续照顾苗小善；凶手、作案动机和被夺厉鬼去向待后文。（原文回跳第1198章、原文回跳第1201章）

杨间现场复盘认为，高明骑车巡逻时因其灵异视野看见平安大厦附近隐藏目标，停下靠近后被瞬间斩首；其死更像撞见凶手后的随手灭口。杨间触发柴刀媒介时，凶手以锈蚀灵异大刀沿媒介反入侵并交锋，身份未明。（原文回跳第1204章）

锈刀者的武器带血，血迹可隔黄金与媒介造成断首灵异伤；杨间七层鬼域重启才恢复。凶手疑长期存活、已近异类，且忌惮秦老，杨间建议总部暂缓冒险追查。（原文回跳第1205章、原文回跳第1206章）

#### 原文回跳第1239章·亡魂画像锁定张羡光

何银儿以高明墨镜招其亡魂。高明确认自己巡查时看见平安大厦方向的灵异身影，刚看清对方便被斩首；其后在会议桌上留下凶手画像，杨间认出为张羡光。亡魂随后失控，媒介被何银儿切断并损毁。（原文回跳第1239章）
