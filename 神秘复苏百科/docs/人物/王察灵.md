# 王察灵

王察灵是二十八岁的大东市负责人、总部内定队长，海归硕士，名下拥有五百米高的宁安大厦。表面温和有礼，爱好各类棋局；其实际灵异实力与王家背景远超普通档案，但完整驾驭情况不明。（原文回跳第845章）

## 王家与能力

王察灵称自己是大东市王家第三代、最后一代。王家自民国起与鬼打交道，拥有一栋遭诅咒的民国古宅；他称祖宅产权虽归王家，却不等同能控制古宅，父亲已进入其中失踪。（原文回跳第846章）

杨间试探时，王察灵身后显现两只独立厉鬼轮廓，分别近似黑布衣老人和较矮鬼影。杨间据此判断他至少驾驭三只鬼且可能持有其他灵异物，但这只是战斗评估，王察灵没有公开完整能力。（原文回跳第846章、原文回跳第847章）

## 经历

#### 原文回跳第845-846章·接待杨间并交出同步怀表

杨间率七人队以鬼域抵达宁安大厦时，王察灵正在与各界棋手聚会。他与杨间不设棋盘在脑中下完一局象棋，被杨间先将而认输；这场对局仅反映双方的试探，不构成灵异胜负。（原文回跳第845章）

王察灵承认摆钟所在古宅属于王家，称自己曾派父亲入内而未归，并交给杨间一块与古宅时间同步的旧怀表。杨间接受怀表但只给予一次信任，警告若受欺骗将直接与其死战。杨间离开后，王察灵命全家福照片中的母亲进入古宅，寻找父亲并避免其与杨间冲突。（原文回跳第846章）

#### 原文回跳第855-859章·被李军监视，诅宅异变待处置

李军抵达宁安大厦后明确表示，自己不是来牵制杨间，而是监视包括王察灵在内的大东市无底线风险。王察灵得知杨间已入诅宅，承认善后可能落到自己身上；其对此次地牢异变、陈桥羊脱困是否知情尚未写明。（原文回跳第854章、原文回跳第855章）

#### 原文回跳第870-874章·显露一代压鬼能力并暂失诅宅控制权

王察灵在陈桥羊逃离时未出手，后以王家一代黑白老人将陈桥羊遗留的厉鬼强行撕裂、压制。他承认自己仍是普通人，只依靠王家一代、二代厉鬼保护；杨间因此强势要求日后取得摆钟乃至接管诅宅，王察灵试探后选择退让。（原文回跳第873章、原文回跳第874章）

他随后进入隐秘安全屋，检查被棺材钉压住的饿死鬼，思考正确时间和位置是否真能触及摆钟。其对饿死鬼的用途、是否准备利用该物重启均待后文。（原文回跳第874章）

#### 原文回跳第875章·饿死鬼失窃与七十分钟重启计划

王察灵确认饿死鬼仍藏在安全屋，承认趁总部处理鬼画、高手被调空时，让王家一代厉鬼将总部封存的饿死鬼盗回大东市。他计划以饿死鬼四十分钟重启抵消古宅摆钟三十分钟重启，形成七十分钟回退循环，试图把古宅时间推回特定过去；此计划尚未实施，且饿死鬼缺乏可控手段。（原文回跳第875章）

饿死鬼额头棺材钉疑似已有锈屑脱落、眼珠曾短暂转动，存在压制松动风险。失窃和计划均未被杨间或总部知晓。（原文回跳第875章）

#### 原文回跳第1226-1229章·击退叶真并受杨间敲打

叶真强行挑战时，王察灵调动爷爷、奶奶两只王家一代亡魂迎战。亡魂可压制叶真鬼域并多次杀死其身体，但替死能力将致命袭击转移回王察灵，双方僵持后叶真承认落败离开。（原文回跳第1226章至原文回跳第1229章）

杨间随后指出叶真本由其引导前来试探，明确王察灵须赴总部会议，并警告其低调、囤积四鬼而不外出的姿态令自己不放心。王察灵担忧饿死鬼盗取与古宅重启计划被察觉，决定暂时扮演好队长角色、延后计划。（原文回跳第1229章）

#### 原文回跳第1199章·继续藏匿饿死鬼并以棋局拖住叶真

王察灵继续在安全屋藏匿从总部盗取、被棺材钉压住的饿死鬼，并以反复下棋拖延前来挑战的叶真，避免直接战斗。他收到杨间赴总部会议的消息后，判断曹延华或借杨间影响其他队长；王察灵自身暂未响应会议。（原文回跳第1199章、原文回跳第1200章）

#### 原文回跳第865-869章·与陈桥羊对峙后放其离开

王察灵与李军进入诅宅后，李军鬼火焚宅被陈桥羊以摆钟重启化解。陈桥羊逃出古宅时提及王察灵父母王陆夫妇、承认曾与二代交手；王察灵召出王家一代黑白老人，陈桥羊以四鬼自保，王察灵因忌惮对方和李军下落不明而未独自开战，放任其离开街道。（原文回跳第865章、原文回跳第869章）

#### 原文回跳第1305章·过去映照中围杀失败

过去映照中的王察灵以王家三代亡魂护身，爷爷、奶奶可无视杨间六层鬼域、挡住长枪和柴刀，并将杨间撕为两截；但他自身仍是普通人，王家亡魂转攻时防护空缺，遂被鬼手扭断脖颈。该死亡仅属过去映照事件，不影响真实历史中的王察灵状态。（原文回跳第1305章）
