# 中药铺老人

中药铺老人是中江市老城区中药铺的主事者，双目失明、身体枯瘦腐朽并带尸臭，却仍以灵异维持意识和行动。他认为自己若死，身边的女子小茹也活不了多久。（原文回跳第1269章）

他承认和大川市王家古宅的老尸是朋友。杨间据此判断他是仍存活的民国驭鬼者，其确切姓名、能力、药铺经营方式和存活原因待后文。（原文回跳第1269章）

#### 原文回跳第1270-1271章·以延缓复苏等待开拓者

老人称民国一代不留固定驾驭法，是因旧路至多令人苟活一世，无法终结灵异；他们期待后人从灵异碰撞中走出不受复苏、寿命和意识侵蚀限制的全新道路。（原文回跳第1270章）

他将三包可延缓厉鬼复苏的灵异中药无偿交给杨间，并明确药铺只管救人、不承担求药驭鬼者作乱的后果。他预备死后入太平古镇棺材铺的棺材，由小茹收尾并使药铺消失。（原文回跳第1270章、原文回跳第1271章）
