# 田晓月

田晓月是鬼邮局第二任管理者。其名字记录在601管理者名册第二页；她被肢解为头、躯干、双腿和双臂，分别封存于玻璃瓶、油画及邮局一楼，拼合后仍意识残缺。（原文回跳第1025章、原文回跳第1028章）

她无意识状态下仍保有管理者权限，可随孙瑞在公寓内转移。其口中曾藏一张黑信纸，留下“警惕张羡光，并且想办法杀了他”的警告，显示第二、三任管理者之间曾存在冲突。（原文回跳第1028章）

田晓月的残留信纸也是旧邮局夜间黑信纸现象的源头。她为何被肢解、张羡光如何脱离或失踪、能否恢复清醒均待后文。（原文回跳第1028章）
