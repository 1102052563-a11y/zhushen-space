# 王勇

王勇是鬼邮局五楼老信使，已送出两封信，原本只差一封即可脱离邮局，却因黑信任务长期中止。他有妻子与孩子，因顾虑家庭而对继续送信犹豫。（原文回跳第998章、原文回跳第1000章）

他驾驭两只鬼并拥有鬼域，持一把能强力压制灵异的铁锹，交战时重创李阳、击碎染血木槌并压制人偶娃娃。柳青青和刘子文战败后，他未杀李阳，向杨间投降。（原文回跳第1001章、原文回跳第1002章）

杨间以一亿元安家费招募王勇，暂以染血尖刀换走其铁锹，并让他协助收容战死信使尸体。王勇是否可靠、能否成为邮局掌控者待后文。（原文回跳第1003章、原文回跳第1004章）

#### 原文回跳第1018-1019章·持铁锹击退开门鬼

黑信撕毁后，杨间归还铁锹以增强王勇生存能力。开门鬼以亮灯再熄灭触发必死规律时，王勇以自身厉鬼遮挡灯光、铁锹拍倒本体，自己未死但所驾驭厉鬼受创；杨间随后肢解开门鬼，使其暂时沉寂。（原文回跳第1018章、原文回跳第1019章）
