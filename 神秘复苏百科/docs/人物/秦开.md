# 秦开

秦开是鬼邮局四楼幸存信使，曾在贴满黑色信纸的房间躲过失控夜晚。他在第900章晨间现身，对杨间解决侵蚀信使鬼持怀疑态度。（原文回跳第900章）

#### 原文回跳第901-902章·观察红信并警惕杨间

秦开没有争夺杨间取得的红信和红色气球，判断王风、老鹰不敢反对说明杨间实力异常。他提醒大强不要抢杨小花保管的气球，并认为杨间的超常实力可能令红信任务难度远超四楼信使承受范围。（原文回跳第901章、原文回跳第902章）

#### 原文回跳第915-916章·熄火后被冻尸鬼杀死

灵异公交在古宅附近熄火时，秦开先被相邻的冻僵女尸搭手，逃下车后仍被其抱住冻结，短时间内化为冻尸死亡。其未展示的手段未能阻止袭击，冻尸鬼随后继续活动、寻找下一目标。（原文回跳第915章、原文回跳第916章）
