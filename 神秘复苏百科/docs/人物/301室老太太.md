# 301室老太太

301室老太太是杨间通过柴刀媒介在明月小区301室看到的驼背皱纹老人。她曾坐在画板前作画，画出年轻时的秦老，也曾让无脸木偶穿红旗袍、再画上与鬼画女子和鬼橱照片女子相同的脸。杨间认为她疑似民国时期遗留的驭鬼者，并怀疑其与灵异公交车上见过的老太太为同一人，但两项身份均未获证实。（原文回跳第817章）

## 死亡与复苏迹象

杨间在301室左侧卧房发现鬼眼无法窥视的红漆木床，床上躺着体型枯瘦的老人尸体，尸体双手捧着鬼邮局黄信。柴刀媒介显示，尸体曾从床上起身到客厅取信；杨间据尸臭、外貌与媒介判断，该尸体就是301室老太太，已死亡约半月至一月，并正处于厉鬼复苏阶段。（原文回跳第818章、原文回跳第819章）

媒介中的老人发现杨间后，未随鬼影收回而消失，反而以虚实交错、黑白色形态部分侵入现实；她在301室外游荡，尚未展示明确杀人规律。床上尸体、黑白媒介老人是否为同一只鬼的两种状态、其后能否完全进入现实与活动范围均待后文。（原文回跳第819章）

#### 原文回跳第820-824章·黑白老人以抹除活人取代现实位置

黑白老人靠近杨间后，会使其身体褪为黑白并从现实消失，同时老人自身逐步恢复颜色与实体。杨间判断该灵异不是普通杀人，而是以受害者为定位，抹除其在现实的存在后，让“过去的鬼”取代其进入现在；该判断来自现场现象，完整触发条件和范围未明。（原文回跳第821章、原文回跳第822章）

杨间以第七层鬼域重启自身，只能回退自身被抹除的状态，无法中断老人锁定。其后他将已肢解的倒视人偶复原并倒转，让人偶盯住老人；老人对杨间的抹除转移至人偶，黑白媒介也随之消退。此结果仅证明人偶能干扰该次入侵，不能确认老人已被关押或床上尸体是否同步失效。（原文回跳第824章）
