# 罗千

## 简介

罗千是被称为“坟场主”的民国时期驭鬼者。中药铺老人曾将其列入民国旧人；过去映照中的秦老为围杀杨间，以灵异公交车将其从坟场木屋接走。（原文回跳第1270章、原文回跳第1307章）

## 过去映照中的能力与行动

罗千发动灵异后可将环境化为坟场、以坟土侵蚀并埋葬目标。杨间的鬼火、鬼湖和鬼影均在坟土中受压，身体也迅速溃为坟土；罗千随后以土坟合拢完成埋葬。（原文回跳第1308章）

杨间以八层鬼域大范围重启回到被袭前，罗千判断自身只能埋葬“现在”的杨间，无法直接埋葬进入过去重启状态的目标，遂让孟小董介入驱赶。该限制仅见于过去映照中的本次交锋，不能据此概括其完整规律。

本页第1307至1308章内容均为白水镇过去区域的灵异映照，不等同于真实历史中罗千的实际经历。

#### 原文回跳第1313-1314章·坟土受鬼童群体压制

罗千随秦老等人再次围杀杨间，坟土与罗文松的门共同压向已被张洞封住灵异的杨间，却被海量鬼童强行抵挡。鬼童吞食鬼差后具备压制灵异的表现，后续鬼童甚至从坟土中重新走出，使罗千无法以坟场清除全部分身。（原文回跳第1313章、原文回跳第1314章）

本段均为过去映照事件，战局未结束。

#### 原文回跳第1315章·释放坟场厉鬼后被吞没

鬼童全面反攻时，罗千释放坟场内关押的多只厉鬼抵挡人潮，仍被鬼童吞没、尸体消失。其后坟土反向覆盖其余旧人，显示鬼童在本次交锋中夺走或继承了相关灵异。该死亡和灵异转移均仅属于过去映照事件。（原文回跳第1315章）
