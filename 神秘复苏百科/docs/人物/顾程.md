# 顾程

顾程是许峰在灵异公交车上认识的民间驭鬼者，皮肤黑紫、面部浮肿、说话迟钝。许峰认为他已让体内鬼部分死机，近似异类；其上车经历、驾驭厉鬼数量和完整背景均不详。（原文回跳第837章）

## 能力

顾程可展开带腐尸恶臭的鬼域，转移自身、他人和鬼童。他还能以口中腐烂惨白脸庞吹气，使李阳瞬间遭受持续窒息；该袭击无法由正常呼吸缓解。其鬼域会被杨间红光鬼域瞬间压制，完整范围、代价和杀人规则均不详。（原文回跳第837章、原文回跳第838章、原文回跳第839章）

## 经历

#### 原文回跳第836-839章·受邀支援、开启铁棺并被杨间困住

廖凡在观江小区被鬼童拆解时接受顾程的高价支援。顾程赶到后用鬼域救走许峰、廖凡并转移鬼童，随二人定位一号安全屋；他只索要棺材钉，并以鬼域优势强迫二人同意。（原文回跳第837章）

顾程与二人强开安全屋、搬出杨间铁棺。开棺后他取得黄金灵异长枪，却在杨间八音盒诅咒结束、红光鬼域覆盖时失去鬼域，无法离开；他随后与许峰、廖凡一同攻击刚苏醒而记忆混乱的杨间。杨间夺回长枪并钉死廖凡，顾程与许峰的后续处境待后文。（原文回跳第838章、原文回跳第839章）

#### 原文回跳第840章·抽中生签仍被物理杀死

顾程以鬼签抽中生签，获得十分钟不被灵异力量杀死的保护，并使体内鬼全面复苏，以高层鬼域短暂对抗杨间。他仍被杨间强行闯入鬼域、掐住脖子，随后遭到物理扭断颈骨死亡；杨间将其尸体封回金属棺，防止遗鬼复苏。（原文回跳第840章）
