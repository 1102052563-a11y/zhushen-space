# 大强

大强是鬼邮局四楼幸存信使使用的假名。他在第900章从401房间现身，称自己夜间接连换过三个藏身处才活下。（原文回跳第900章）

#### 原文回跳第901-902章·觊觎气球后暂退让

大强见杨间取得红色气球后未敢争抢，曾考虑抢夺杨小花所持气球，却因秦开提醒杨间危险、红信任务不能出问题而暂时放弃。他仍把完成红信任务、进入五楼视为离开失控四楼的机会。（原文回跳第901章、原文回跳第902章）

#### 原文回跳第932-934章·以鬼域接替后堂防线

杨间主动入大堂肢解鬼域源头鬼时，大强以自身鬼域接替鬼影，勉强护住红棺附近十秒；事后身体散发尸臭、死气沉重，已逼近厉鬼复苏。古宅的压制令其暂时存活，第三日随队离开古宅报丧。（原文回跳第932章至原文回跳第934章）

#### 原文回跳第940-944章·吊唁日被黑椅鬼按死

大强穿丧服参与开棺吊唁，确认丧服可遮蔽群鬼感知但发声会暴露位置。黑色太师椅后的枯手仍能无视丧服，搭其肩后一按即杀死；杨间以柴刀斩下三根手指仍未及时救回。（原文回跳第940章、原文回跳第944章）
