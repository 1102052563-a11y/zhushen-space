# 柳白穆

柳白穆是大东市诅宅三楼的白发青年，在摆钟团伙中地位较高。他认为古宅环境可克制鬼域，且摆钟诅咒能使外来者更快死亡；其驾驭厉鬼和完整能力未公开。（原文回跳第848章、原文回跳第849章）

熊文文预知其为突入古宅后必须优先压制的目标。杨间从窗户入宅后，以黄金灵异长枪将其钉在三楼墙上，棺材钉压住体内鬼，再以鬼手衍生物破坏身体，柳白穆随即死亡。（原文回跳第848章）

六点摆钟令古宅时间回退至五点半，柳白穆等已死驭鬼者再次从古宅深处走出。其是否保留重启前记忆、原死因是否被完全抹除均待后文。（原文回跳第849章）

#### 原文回跳第850-854章·和谈失败后入十二日门，遭柴刀远程斩首

重启后柳白穆从杨间话中推断自己等人刚被团灭，因惧怕再次被棺材钉压住而提出和谈；杨间借此拖过重启时间，他则带张庆、万铜进入古宅深处，试图探索每十二天出现一次、通向上方未知区域的木门，以寻找摆钟或失踪会长。（原文回跳第850章、原文回跳第851章、原文回跳第853章）

杨间借柴刀媒介隔空斩断其头颅，柳白穆却仍凭诅咒暂保意识，认出袭击来自柴刀。其无头身体已现复苏迹象，张庆、万铜带头颅继续深入台阶；最终生死与台阶内情况待后文。（原文回跳第852章、原文回跳第853章）
