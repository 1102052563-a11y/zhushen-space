# 银子

银子本名何银儿，是总部一名女队长、原鬼邮局五楼信使和大原市负责人，出身太平古镇。她早于曹洋在鬼湖事件中失踪，负责人制服、手机和尸体出现在鬼湖湖底黑棺中。（原文回跳第1079章、原文回跳第1102章）

银子尸体会融化为水渍、又从杨间身后以厉鬼姿态重现，显示她已被鬼湖源头侵蚀或取代。她是否仍保有活人意识、与鬼湖源头的准确关系及能否救回待后文。（原文回跳第1079章）

#### 原文回跳第1080章·融入鬼湖难以压制

杨间以六层鬼域、柴刀三次肢解和棺材钉压制银子厉鬼，尸体仍融入湖水、随即重现。她无法进入杨间分割出的无水区域，显示其灵异与鬼湖水体高度绑定。（原文回跳第1080章）

#### 原文回跳第1100-1102章·灵异复活并继任招魂人

太平古镇旧人将何银儿尸体从鬼湖打捞，以红棺、灵位、招魂香和烧纸复活。何连生死后，她挖下其惨白左眼装入自身，按传承招来自己的魂，成为第四任招魂人和异类；她带灵位、刘老板、无脸人前往大原市重建太平镇。（原文回跳第1100章至原文回跳第1102章）
