# 银子

银子本名何银儿，是总部一名女队长、原鬼邮局五楼信使和大原市负责人，出身太平古镇。她早于曹洋在鬼湖事件中失踪，负责人制服、手机和尸体出现在鬼湖湖底黑棺中。（原文回跳第1079章、原文回跳第1102章）

银子尸体会融化为水渍、又从杨间身后以厉鬼姿态重现，显示她已被鬼湖源头侵蚀或取代。她是否仍保有活人意识、与鬼湖源头的准确关系及能否救回待后文。（原文回跳第1079章）

#### 原文回跳第1080章·融入鬼湖难以压制

杨间以六层鬼域、柴刀三次肢解和棺材钉压制银子厉鬼，尸体仍融入湖水、随即重现。她无法进入杨间分割出的无水区域，显示其灵异与鬼湖水体高度绑定。（原文回跳第1080章）

#### 原文回跳第1100-1102章·灵异复活并继任招魂人

太平古镇旧人将何银儿尸体从鬼湖打捞，以红棺、灵位、招魂香和烧纸复活。何连生死后，她挖下其惨白左眼装入自身，按传承招来自己的魂，成为第四任招魂人和异类；她带灵位、刘老板、无脸人前往大原市重建太平镇。（原文回跳第1100章至原文回跳第1102章）

#### 原文回跳第1216章·新太平古镇与队长会议

何银儿在大原市郊修建仿古街旅游小镇，意图重建太平古镇并可能重开鬼街。杨间上门警告鬼街风险，双方险些交手；何银儿为避免冲突答应次日赴总部参会，并坚持自己会对古镇失控负责。（原文回跳第1216章）

#### 原文回跳第1234章·为养爷爷向柳三寻仇

何银儿在总部确认杀死养爷爷何连生的是柳三。她认为何连生虽曾干扰鬼湖行动，却已离开现场，柳三仍追至太平古镇杀人，故邀柳三至废弃培训基地生死决斗；双方尚未正式交手便被杨间到场打断。（原文回跳第1234章）

#### 原文回跳第1235-1237章·被杨间压服后转求媒介

杨间以鬼域短暂定住何银儿、柴刀斩散她招来的亡魂，刀锋架颈迫其承诺不再向柳三寻仇。何银儿承认无法对抗，暂时服从并照常参会。（原文回跳第1236章）

刘老板建议她以总部档案寻找强大驭鬼者遗物、扩充可招亡魂的媒介。何银儿放弃立即复仇，转而准备搜集旧物增强招魂底牌。（原文回跳第1237章）

高明死后，何银儿以其墨镜招来保有部分生前意识的亡魂。亡魂在桌面留下张羡光画像后失控，何银儿切断媒介，墨镜随之碎毁。（原文回跳第1239章）

#### 原文回跳第1251-1254章·双桥镇连番招魂对抗张羡光

张羡光五具分身与鬼差围杀队长时，何银儿先以三件遗物招来三名亡魂，后又动用太平古镇灵位招来腐朽老人。老人以坟土灵异将五具分身化为土丘，并带走重伤卫景进入鬼差黑暗，疑为协助其驾驭鬼差。（原文回跳第1251章、原文回跳第1254章）

两轮招魂均会快速消耗亡魂维持时间；腐朽老人实际身份、卫景是否获救及灵位损耗待后文。（原文回跳第1254章）

#### 原文回跳第1257-1259章·私塾意识陷阱中获陆志文保护

张羡光将何银儿、柳三、周登、陆志文拖入旧私塾意识场景，随机斩首鬼逐个清除学生。何银儿被选中时，陆志文预设的灵异保护令鬼刀偏砍，暂保性命；随后杨间与黑狼狗入侵私塾，斩首鬼被压住，陷阱开始瓦解。（原文回跳第1257章至原文回跳第1259章）
