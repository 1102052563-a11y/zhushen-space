# 老李（鬼邮局）

老李是早期鬼邮局五楼信使。黑色集体信出现后，他自愿配合其他信使成为夹在邮局压制与房内厉鬼间的异类，死后依托502房间灯光显现，永久持有黑色信件以中断送信任务。（原文回跳第992章、原文回跳第994章）

他以中年男子形象与杨间交流，实际尸体已腐烂在502浴缸。房内灯亮时可短暂显形，灯熄时消失；其不是实体，杨间无法读取记忆。（原文回跳第992章）

老李后认为邮局失控、外界灵异扩散，主张恢复黑信任务，让五楼信使承担送信代价。他向杨间说明黑信规则、油画与玻璃瓶尸体碎片线索后，502房内厉鬼再度复苏，其后续状态待后文。（原文回跳第994章）
