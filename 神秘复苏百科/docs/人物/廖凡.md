# 廖凡

廖凡是参与追杀冯全的驭鬼者，戴兜帽、口罩和羽绒服，声音嘶哑。他为掩盖大东市民国古宅、摆钟诅咒线索，与裴东、许峰追至大昌市郊外；其过往身份、驾驭鬼数量及团伙上级均不详。（原文回跳第831章）

## 能力与物品

廖凡使用“鬼喊人”：从目标身后以亲近者声音呼喊其姓名，目标回头即可能死亡。他以此袭击童倩，童倩转出哭脸鬼回头而避过。连续使用会令喊其姓名的声音逐渐靠近自身，显示有复苏代价；具体必死条件与作用范围未明。（原文回跳第832章）

他持有一辆老旧鬼出租车，车辆可压制鬼雾、隔绝大部分鬼笑声，并能突然跨越位置撞击目标；但熄火后重新启动会伴随尸臭、后备箱撞击和异常震动，具体代价不明。（原文回跳第831章、原文回跳第833章）

## 经历

#### 原文回跳第831-834章·追杀冯全并闯入尚通大厦

廖凡与裴东、许峰以鬼出租车追杀调查摆钟诅咒的冯全，将其撞至重伤、引发鬼雾与坟土复苏。童倩、张韩来援后，他判断杨间没有使用鬼域救援，推测杨间自身出问题，遂与许峰计划趁机进入大昌市夺取资源和棺材钉。（原文回跳第831章）

童倩鬼笑杀死裴东并逼退二人，廖凡以鬼出租车撞飞童倩后没有补杀，转而前往尚通大厦试探杨间。章华称杨间不在，二人仍闯入大厦，后续冲突待后文。（原文回跳第832章至原文回跳第834章）

#### 原文回跳第835-839章·掠走鬼镜后遭杨间钉杀

廖凡与许峰闯入尚通大厦，杀死章华及一名保安，破坏办公室安全屋并掠走鬼镜；他随后在观江小区遭李阳、黄子雅、王珊珊和鬼童伏击，鬼出租车被李阳以堵门鬼强行撞停。鬼童持续啃咬其由人皮、布料、棉花和木杆构成的稻草人身体，迫使他求助顾程。（原文回跳第835章至原文回跳第837章）

顾程开出杨间铁棺后，廖凡试图借鬼出租车逃离复苏的杨间；杨间以夺回的黄金灵异长枪刺穿其头部、以棺材钉压制灵异。失去力量维持后，廖凡的稻草人身体死亡。本页状态改为死亡。（原文回跳第839章）
