# 老鹰

老鹰是鬼邮局四楼信使，持有老旧手枪与鬼骰子。他在古宅红信中多次协助守夜、分析丧事规则，亦曾以骨片弹药短暂击退邮局四楼泥脚印鬼。（原文回跳第895章、原文回跳第898章）

#### 原文回跳第930-934章·承受八音盒诅咒维持鬼骰局

王风与继任者相继在鬼骰局死亡后，老鹰接手。杨间将八音盒诅咒施于他，使其即使掷输仍不会死亡，从而拖住后门厉鬼至报丧纠正。（原文回跳第931章、原文回跳第932章）

#### 原文回跳第949-954章·鬼宴试错后死于诅咒

第五日鬼宴，他先以撒米试错失败，继而以鬼骰局强行中断多鬼袭击，无法再正常离局。第六日凌晨，八音盒诅咒回到杨间身上，证明老鹰已死；柳青青带走其尸体准备安葬。（原文回跳第949章、原文回跳第954章）

#### 原文回跳第970-974章·被复活并加入尚通大厦

杨间以骗人鬼构造新身体，并写入鬼影窃取的老鹰记忆，使其复活、脱离鬼邮局诅咒。其记忆仅保留到杨间最后一次读取的第二日守夜阶段，缺失后续经历；他接受杨间邀请，加入尚通大厦团队。（原文回跳第970章、原文回跳第971章、原文回跳第973章）
