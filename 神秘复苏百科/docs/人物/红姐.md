# 红姐

红姐是由柳青青体内民国女子记忆主导后形成的自称。她称自己并非严格意义的复活者，而是从灵异中诞生，柳青青的意识已经消失。（原文回跳第1002章、原文回跳第1004章）

她掌握红旗袍、红高跟鞋与木偶拼图的使用，曾在五楼以高跟鞋媒介、旗袍尸体拖住杨间，但意识到杨间已成由鬼影主导的异类后停止对抗。（原文回跳第1001章、原文回跳第1002章）

红姐称可让一人永留邮局、成为不再复苏的异类掌控者，并将邮局送信规则改为灵异事件处置；她建议暂留黑信，用其选择掌控者。其真实立场与方案完整代价仍待验证。（原文回跳第1004章）
