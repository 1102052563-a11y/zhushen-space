# 孟小董

## 简介

孟小董是民国时期驭鬼者。中药铺老人曾将其列入仍被记得的民国旧人；原文回跳第1307章，过去映照中的秦老以灵异公交车将她从大川市301室接走，用于围杀杨间。（原文回跳第1270章、原文回跳第1307章）

## 过去映照中的能力与行动

她可让过去的自身取代现实活人而入侵当下。杨间以两只鬼眼反复大范围重启后，她仍能从过去跟至重启后的时间点；其后数百个提菜篮的孟小董从不同时间侵入，显示此能力可随时间和活人媒介持续增殖。具体上限、真实本体所在及是否可在现实稳定复现均不详。（原文回跳第1308章）

她随身携带大量替死娃娃，柴刀攻击可被替死娃娃抵消；其篮中还可取出会显为厉鬼的人偶。杨间以鬼火先烧毁部分替死娃娃，再以一根棺材钉钉住一个映照分身，但其余分身仍持续出现，故不能视为已将其关押。（原文回跳第1309章）

本页第1307至1309章内容均发生于白水镇过去区域的灵异映照，不等同于真实历史中孟小董在该时段的实际经历。

#### 原文回跳第1310-1314章·被十层鬼域击退后再度围杀

孟小董以大量分身触碰杨间，令其重启亦无法摆脱取代侵蚀。杨间十层鬼域使过去自身重叠，叠加柴刀攻击耗光替死娃娃，击退过去数小时内的孟小董；他保留一具被棺材钉压住的映照尸体交给鬼童吞取。（原文回跳第1310章、原文回跳第1311章、原文回跳第1312章）

两点三十分后，孟小董随秦老等人再次出现。鬼童群体喊其姓名、以叠加诅咒削减寿命，并在活人媒介中快速增殖；至第1314章，她仍与其他映照旧人共同对抗鬼童，胜负未分。本段均为过去映照事件。

#### 原文回跳第1315章·被鬼童人潮吞没

鬼童人潮压过围杀者后，孟小董在映照中的当前身体被吞没。她原可由过去再次入侵，但城市已被鬼童占据，新的入侵需要时间而未能扭转战局。该败亡仅属过去映照事件，不改变真实历史状态。（原文回跳第1315章）
