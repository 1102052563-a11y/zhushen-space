# 朱见

朱见是被困凯撒异常走廊约六十年的循环者，原为八九十年代装束的年轻男子，在301号房复活、300号房记录信息。（原文回跳第1151章、原文回跳第1152章）

他曾被未知厉鬼替代或操控，以哭泣、奔跑姿态追赶杨间一行；枪击、童倩哭脸和柴刀肢解后仍活动，最终被杨间以棺材钉压住，其替身/傀儡身份得到确认。（原文回跳第1168章、原文回跳第1171章）

香兰随后在十号房取回朱见封存画像，使其恢复旧记忆并驾驭封存厉鬼，准备与其他循环者共同寻求解脱。（原文回跳第1174章）

取回力量后，朱见支持趁杨间被三楼鬼压制时偷袭。他的厉鬼袭击无法杀死异类杨间，反被燃烧鬼手侵入身体，重伤濒死且持续燃烧。（原文回跳第1179章）
