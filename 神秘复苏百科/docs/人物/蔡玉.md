# 蔡玉

## 简介

蔡玉是鬼邮局二楼男性信使，与王善在一楼时已认识。他对王善所称杨间能硬闯邮局、逼退夜游鬼的经历起初不信，直至见到杨间免疫枪击、处置二楼厉鬼，才承认两者存在巨大差距。其职业、已送信次数和进入邮局前身份均不详。（原文回跳第783章、原文回跳第784章）

## 经历

#### 原文回跳第783-785章·从怀疑杨间到躲入走廊角落

红信出现时，王善提醒蔡玉不要得罪杨间，并说明其不是普通信使。蔡玉无法相信有人能硬闯鬼邮局、击退厉鬼；杨间撕信后，他观察回字走廊结构，推测四个墙角处于房门分界线，可能避开开门拖拽的袭击，遂选择躲入墙角。（原文回跳第783章、原文回跳第784章）

女尸鬼连续杀人后，蔡玉的墙角假设尚未被直接证实，但他暂未遭袭。杨间清除二楼女尸鬼后，他随幸存者进入三楼，不再主张脱离杨间行动，具体后续打算不详。（原文回跳第785章、原文回跳第787章、原文回跳第788章）
