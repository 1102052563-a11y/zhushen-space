# 香兰

## 简介

香兰是杨间在凯撒大酒店四层异常走道的71号房内遇到的女性。她穿红色旗袍，盘着乌黑头发，外表健康、面容白皙；杨间以鬼眼反复观察，确认她有正常活人的血色和气息，并未感到厉鬼特征。她却身处已被水泥封死、外部长期无人可入的酒店深处，这一事实令杨间无法解释其来路。（第602章、第603章）

## 经历

#### 第602-603章·在71号房弹奏钢琴并逃向深处

杨间循与八音盒铃声相同的钢琴旋律进入71号房时，香兰背对门口坐在钢琴前。她演奏时多次错拍，神情紧张、身体发颤，却仍勉强继续弹奏；杨间判断她并非因兴致演奏，而是受某种未明理由驱使。杨间现身发问后，香兰受惊停琴。阿南自隔壁房冲出，她立刻拉着对方逃走；得知杨间是从“出口”进入后，她急切追问出口在哪里，请求带两人离开。杨间尚未解释，阿南已怀疑他不正常并带她离开。二人没有向酒店出口跑，而是朝异常走道更深处逃去。香兰是否来自另一端入口、为何必须弹琴、是否知道71号房内有鬼及最终去向均不详。（第602章、第603章）

## 关系

- [阿南](阿南.md)：阿南听到动静后从隔壁冲出，香兰抓住他一同逃离71号房。（第603章）
- [杨间](杨间.md)：杨间在71号房发现她是活人并询问来路；她则把杨间视为可能来自出口的外来者。（第603章）

第602章、第603章。

#### 原文回跳第1145-1147章·头颅被干尸使用且701复活失败

杨间进入最后灵异房间后，发现弹奏必死钢琴曲的干尸顶着香兰头颅，干尸遭肢解后头颅被楚南取走。楚南称香兰来自701号房，原本能循环复活，但某次死亡后未再回归，实际是否彻底死亡待后文。（原文回跳第1145章至原文回跳第1147章）

楚南认为她复活失败，杨间则暂未确认；其头颅由楚南保管，残躯和复活规则仍待追查。（原文回跳第1150章）

#### 原文回跳第1160-1164章·101房假身与墓碑真尸

杨间以骗人鬼造无头身体、鬼影压制其头内厉鬼，使香兰恢复意识。借她身体和鬼眼查探101房，发现墓碑压住真正香兰尸体；活动的香兰为房间诅咒衍生的假身，因而死后反复重现却无法真正离开。（原文回跳第1161章、原文回跳第1162章）

香兰告知记录笔记在100号房，并带杨间等前往。杨间暂未告知她解除复活循环的方法，后续状态待查。（原文回跳第1161章、原文回跳第1162章）

#### 原文回跳第1172-1174章·集合循环者取回封存画像

香兰判断异常走廊有人驾驭特殊厉鬼、正借走廊失控抹除杨间。她集合复活后的楚南、朱见、董玉兰、王根全进入十号房，从床下画像取回他们旧记忆和封存厉鬼，准备以五人后手寻求脱离诅咒。（原文回跳第1172章、原文回跳第1174章）

#### 原文回跳第1179章·趁火偷袭失败

香兰同意趁杨间受三楼鬼压制时袭击童倩，协同其他四人阻止救援。杨间以燃烧鬼手反杀董玉兰、重创楚南与朱见；香兰释放自钢琴鬼截取的必死诅咒曲，却被杨间八音盒曲抵消，冲突结果待后文。（原文回跳第1179章）
