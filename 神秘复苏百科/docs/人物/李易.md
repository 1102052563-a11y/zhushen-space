# 李易

李易是鬼邮局三楼34号房信使，衣着颓废、常抽烟，对三楼信纸和任务机制较熟悉。他称三楼信使可燃烧黑色信纸随时进出邮局，信纸须卷成长条以延长燃烧；若回邮局途中燃尽，信使可能失踪。该说法主要来自其个人经验。（原文回跳第790章、原文回跳第791章）

他试图以信息和信纸向杨间换钱，后交代三楼快速上楼可尝试截取第三封信或同时持有三封信。34号房本次正收到第三封黄信，任务却因杨间取信而同时绑定31、34号房，地址仍是大川市明月小区7栋301室。李易与郭幽、柳青青是否随杨间实际送信待后文。（原文回跳第790章、原文回跳第791章）

#### 原文回跳第796-804章·大川市逃亡与机场汇合

李易与郭幽、柳青青抵大川市机场后，以一瓶灵异浑水变血判断附近有鬼，三人从停机坪逃离失控客机袭击。其后他接到江艳确认的三千万元汇款，向杨间转达三人愿汇合送信；大川市鬼奴围困下，三人躲在机场厕所和店铺内。（原文回跳第796章、原文回跳第799章、原文回跳第802章）

他与柳青青无法判断郭幽是否被鬼影头侵蚀，亲见杨间按熊文文预知以棺材钉限制影子、郭幽意识消散死亡。李易受冲击但确认鬼确在郭幽身上，随后接受杨间安排借专机过夜。其是否仍参与明月小区送信待后文。（原文回跳第804章）

#### 原文回跳第805-809章·随队进入301室

李易接受杨间以“活着离开鬼邮局”为条件的探路安排，与杨小花、柳青青随队进入猛鬼区。明月小区浓烟使他呕吐、身体迅速枯瘦；他用取自旧送信地点浴缸的灵异浑水验出鬼找人在第三排楼栋靠近，随后跟杨间躲入住户、跳窗脱离。（原文回跳第805章至原文回跳第809章）

抵达301室后，他主张先放下信完成任务，但杨间决定入内查明真相。李易衡量门外有鬼、独留亦危险后，随杨间进入有异常灯光的301室。信使任务是否完成及其房内遭遇待后文。（原文回跳第809章）

#### 原文回跳第819章·被未知灵异掏空死亡

301室异变后，李易与杨小花未能等到通往鬼邮局的信使小路，因而留在小区。他忽然惨叫后站立不动，杨间确认其身体内脏、骨肉皆被掏空，只剩完整皮囊；皮囊一度被灵异操控开口说话，后被杨间鬼手压制、瘫为皮肉。袭击者可能是柳青青，也可能是301室逸出的未知灵异，本批无法确认。（原文回跳第819章）
