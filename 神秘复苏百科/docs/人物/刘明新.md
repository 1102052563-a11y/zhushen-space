# 刘明新

## 简介

刘明新是鬼邮局二楼资深男性信使，约三十余岁，已完成五封送信任务，按其说法再送一封即可正常进入三楼。他重视任务间隔带来的生存时间，反对杨间撕毁红信；其职业、进入邮局前身份和五次任务内容均不详。（原文回跳第783章、原文回跳第784章）

## 经历

#### 原文回跳第783-787章·反对撕信后见证二楼厉鬼被驾驭

刘明新曾伸手阻止杨间取红信，因接触到杨间冰冷如死人的手而退开。红信被撕碎后，他认为杨间剥夺了自己拖延送信、获得一个月安全期的机会，并多次指责其害死信使。（原文回跳第783章、原文回跳第785章）

二楼女尸鬼袭击期间，他避开房门却无有效自保方案，见多名信使死亡后仍质疑杨间的诱饵计划。杨小花获救、李阳成功驾驭女尸鬼后，他得知厉鬼被关入活人体内，受到强烈震动；其是否接受驭鬼者理念、是否继续反对杨间待后文。（原文回跳第785章、原文回跳第786章、原文回跳第787章）

#### 原文回跳第788-789章·随杨间上三楼

二楼楼梯出现后，刘明新和杨小花、蔡玉、王善被迫随杨间上三楼。他担忧杨间不断强行上楼会使普通信使无法适应，也曾谋划脱离控制，但受实力和信使身份限制，没有实施。三楼暂住31号房后，他未在夜间脚步声事件中单独出门。（原文回跳第788章、原文回跳第789章）
