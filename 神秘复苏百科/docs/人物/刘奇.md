# 刘奇

刘奇是杨间、张伟在大昌市第七中的同班同学，也是敲门鬼事件幸存者之一。事件后他因祖父母死亡引发的灵异事件失去多名亲人，遂主动接触低烈度灵异、成为驭鬼者并加入总部，在一年内获候选队长提名。（原文回跳第1277章、原文回跳第1278章）

他身体带有不宜被普通人接触的灵异异常，但具体驾驭厉鬼、负责城市和候选提名依据均未公开。他重视与杨间、张伟的同学情分，明确称此行只为参加聚会，不愿把交情变为利益交换。（原文回跳第1278章、原文回跳第1279章）

## 经历

#### 原文回跳第1277-1279章·重返七中并说明成为驭鬼者的经历

刘奇赴大昌市后与杨间、张伟重返废弃第七中。他说明祖父母曾沾染灵异诅咒，二人同死后尸体在故乡游荡杀人；他发现两具尸体彼此寻找，最终让其牵手合葬才结束事件，但代价是多名亲人死亡。（原文回跳第1278章）

此后他为避免再次无力保护亲人，主动寻找、接触灵异并谨慎驾驭厉鬼，持续处理小型事件后加入总部。七中聚会期间，他与杨间、张伟共同发现张伟挖出的红色灵异斧头，并提醒普通人不应贸然使用灵异物品。（原文回跳第1278章、原文回跳第1279章）

#### 原文回跳第1285-1289章·亡魂道路中试图复活父亲

刘奇随杨间进入白水镇亡魂道路后，因不舍死去亲人，牵住父亲亡魂尝试带离。他的诅咒可将接触目标的灵异、寿命、健康等转移至自身，转移会有折损；本次他以此减轻亡魂前行阻力。（原文回跳第1288章、原文回跳第1289章）

其另一只摇晃鬼可压弯、折断下水道鬼的手臂，但面对三只残缺女鬼效果有限。第1289章末他与萧阳被女鬼手臂围困，红色鬼烛无法点燃，尚未确定是否放弃父亲亡魂或成功脱险。（原文回跳第1289章）

#### 原文回跳第1290-1294章·濒死获救并继续追踪王珊珊

刘奇转移三人行厉鬼灵异后仍无法完全抵抗围困，五官逐渐消失、濒临复苏，萧阳则当场死亡。杨间赶到破坏三鬼配合后，以一包中药强行压住其体内失衡灵异，使五官和意识恢复。（原文回跳第1290章至原文回跳第1292章）

中药药效结束后他仍可能因新转移灵异复苏。刘奇接受父亲亡魂未能带回的结果，随杨间继续深入亡魂道路，在棺材木楼外等待杨间查探；杨间进入异常过去区域后，他的后续处境待后文。（原文回跳第1292章至原文回跳第1294章）

#### 原文回跳第1316-1319章·闯入木楼救援并受餐桌鬼束缚

杨间长时间未出木楼后，刘奇违背独自撤离的约定进入二楼，协助王珊珊确认杨间意识受困。他以自身血液观察并引导木楼外的恶犬进入二层，令恶犬回归杨间记忆；一楼棺材随之开启，木楼灵异开始复苏。（原文回跳第1316章、原文回跳第1317章）

二楼地板灵异将他拖入一张八仙桌映照，桌下厉鬼不断撕咬，现实身体同步失去脚、手掌和大量血肉，且自身灵异被压制。他劝王珊珊优先保证杨间和鬼童安全，至第1319章仍被困、伤势极重但存活。（原文回跳第1318章、原文回跳第1319章）

#### 原文回跳第1320-1324章·获救并随杨间进入楼梯鬼域

王珊珊合棺后，餐桌鬼暂时撤离，但木楼其他构件灵异全面复苏。杨间苏醒后以鬼剪刀顺着刘奇头发看到其与地板厉鬼相连的诅咒线，连续两次剪断、削弱束缚；刘奇靠自身灵异挣脱，伤势仍极重。（原文回跳第1320章至原文回跳第1323章）

杨间取回骗人鬼项链后修复其缺失的双腿、下巴和血肉，效果只是暂时延缓灵异侵蚀。刘奇随后由鬼童背负，随杨间进入楼梯鬼域寻找王珊珊。（原文回跳第1324章）
