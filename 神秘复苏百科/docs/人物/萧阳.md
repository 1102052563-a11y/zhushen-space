# 萧阳

萧阳是大山市负责人，代号“鬼雨”。他在白水镇灵异入侵中失联，因未能向总部建立档案或传出信息而一度被视为可能死亡。（原文回跳第1280章）

他以鬼雨让镇民陷入无意识的沉睡状态，雨水形成水汽遮蔽眼睛、令居民游荡，却使其在现实与灵异交叠的白水镇中免受多数厉鬼直接袭击。萧阳拒绝独自离开，称若不能带走大部分居民便会继续留守。（原文回跳第1282章、原文回跳第1284章）

萧阳曾与王珊珊合作，后见她携鬼童逆着亡魂道路的人流前进并失联。他的完整灵异能力、白水镇源头及撤离方案待后文。

#### 原文回跳第1285-1289章·协助杨间搜人并陷入亡魂道路

萧阳将次日早上六点定为与杨间共同转移白水镇居民的时点，留白色挽联保护幸存者后随杨间、刘奇搜寻王珊珊。服装店衣鬼来袭时，杨间将五鬼沉入鬼湖，萧阳首次见识其压制能力。（原文回跳第1285章、原文回跳第1286章）

他在亡魂道路中再次受小妹亡魂诱惑，却转而协助刘奇带父亲亡魂离开；其鬼雨能减缓下水道鬼侵蚀伤势。第1289章末，他与刘奇被三只残缺女鬼围困，能否脱困待后文。（原文回跳第1287章至原文回跳第1289章）

#### 原文回跳第1290-1292章·死于三人行厉鬼围困

萧阳无法抵挡三人行厉鬼围成的必死袭击，口鼻眼流血后死亡，鬼雨因此停止。杨间赶到时只救回仍以诅咒勉强维持的刘奇，随后将萧阳尸体收入鬼湖水域，准备离开白水镇后再行安葬。（原文回跳第1290章至原文回跳第1292章）
