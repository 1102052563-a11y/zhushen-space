# 小茹

小茹是中江市中药铺老人身边的女徒弟，外表约三十岁、皮肤异常白皙，长期不见阳光且带有阴冷气质。老人认为她依赖自身灵异维持生存，自己一旦死亡，小茹也难以长期存活。（原文回跳第1269章）

她熟悉药铺的灵异中药和来客，起初厌恶杨间的强硬态度；杨间告知张羡光和陈桥羊已死后，她才认识到其实际实力。老人曾建议她跟随杨间接受磨炼，小茹拒绝；杨间承诺老人死后会视情况关照她。（原文回跳第1271章）

她自身驾驭的灵异、拜师缘由和未来去向待后文。
