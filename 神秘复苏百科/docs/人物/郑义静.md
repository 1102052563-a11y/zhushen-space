# 郑义静

郑义静是香江驭鬼者，面容如融化蜡尸，与张志等人受何老板所请来到大兴娱乐城。他自称调停何老板与杨间的冲突，实际在拖延时间，并提出以何老板身家性命和何月莲为赌注。（原文回跳第1123章）

得知孙仁的707门牌困人方案后，郑义静随何老板、骆胜参与针对杨间的计划；其驾驭厉鬼、实际动机和后续行动待后文。（原文回跳第1124章）

#### 原文回跳第1125-1128章·蜡尸入侵失败后沉入鬼湖

郑义静进入未真正化为707的贵宾室后，以蜡尸身体入侵杨间，试图取代其躯壳。杨间体内鬼湖水反向侵蚀，使蜡尸剥落、失衡，最终被水中死尸拖入鬼湖积水，状态按死亡或永久受困处理。（原文回跳第1127章、原文回跳第1128章）
