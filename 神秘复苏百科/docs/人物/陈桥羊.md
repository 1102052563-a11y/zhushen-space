# 陈桥羊

陈桥羊是被困王家诅宅地牢的民国遗留驭鬼者，自称“牧鬼人”。他外表为四五十岁、鬓发斑白的中年人，却认得柴刀、王家世代与摆钟规则，实际存活时间远超外貌所示；其被囚原因、驾驭厉鬼数量和完整能力均不详。（原文回跳第858章、原文回跳第859章）

## 经历

#### 原文回跳第858章·借诅咒笔记脱离书桌陷阱

张庆、万铜在地牢书桌发现诅咒笔记，按笔记警告将其合上后，令被困书桌前的陈桥羊回到“现在”。他称笔记会困住翻看者，需在正确时间由正确的人合上才能脱身；其具体被困时长和笔记完整规律未明。（原文回跳第858章）

得知王家已传至第三代、杨间持有柴刀后，他表明摆钟在诅宅内却只存在于过去，随后宣称要释放王家地牢关押的厉鬼。张庆、万铜意识到自己放出了危险人物，却已无法阻止。（原文回跳第858章）

#### 原文回跳第859章·杀死柳白穆并操纵时间异变

陈桥羊捏碎柳白穆头颅、将其抛出诅宅，称无身躯的柳白穆没有复活价值。他命张庆、万铜为其跑腿，并使摆钟在错误时间响起、怀表时间在前后半小时内紊乱；这显示他与摆钟时间异变有关，但是否直接控制摆钟尚未证实。（原文回跳第859章）

他称王家二代夫妇对自己威胁有限、只有王家一代“老鬼”才令其忌惮，并表示倒计时已开始、将前往寻找杨间。其目标、倒计时含义及将释放多少地牢厉鬼待后文。（原文回跳第859章）

#### 原文回跳第865-869章·压制李军后借摆钟逃出古宅

李军以鬼火焚烧诅宅，陈桥羊以周身灵异压住鬼火；随后将李军困入体内，识破其为鬼皮鬼妆维持的复现体。李军借鬼画窗口和鬼棺黑暗将古宅替换为平安大厦鬼画场景，陈桥羊则以四只手牵手的厉鬼隔开鬼画、鬼棺影响。（原文回跳第865章至原文回跳第868章）

陈桥羊以摆钟重启脱离当前时间段，使鬼画和鬼棺仅短暂退散、自己则成功逃出古宅；张庆、万铜被李军送入鬼画世界。他在古宅外与王察灵短暂对峙后，因忌惮王家一代而暂不动手；杨间随后以鬼域和黄金灵异长枪封住其去路，双方冲突待后文。（原文回跳第868章、原文回跳第869章）

#### 原文回跳第870-874章·牧鬼失利、记忆被夺后由花轿救走

陈桥羊以手腕黑血写下“杀死杨间”，短暂赋予身边厉鬼锁定杨间的规律；又以自身姓名血字剥离身份，暂避鬼童鬼喊人。他的四鬼囚笼可抵住五层鬼域和鬼影，但杨间以六层鬼域钉住一只鬼、鬼影压住一只、柴刀肢解民国衣鬼，令其防护崩解。（原文回跳第870章、原文回跳第871章）

陈桥羊被鬼影侵入后，杨间抹去并盗走约一半记忆。陈桥羊让古宅摆钟失控、放出纸人花轿；花轿撞破杨间五层鬼域并载走陈桥羊，使其逃离。其已失去多只随身厉鬼，完整余力、逃往何处及被夺记忆内容均待后文。（原文回跳第872章）
