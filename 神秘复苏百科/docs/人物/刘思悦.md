# 刘思悦

刘思悦生前是大川市幼儿园教师，死于人头鬼影事件。杨间以骗人鬼项链、鬼影及改写后的记忆令其重现为具灵异痕迹的活人，并赋予她接近赵小雅、取得信任和远离城市的任务。（原文回跳第1045章）

赵小雅将刘思悦主观判定为好人，接受她的照料并赠出一张愿望贴纸。刘思悦的复活并不完整，能否长期存活、是否会受赵小雅伴鬼与愿望代价影响待后文。（原文回跳第1045章）

杨间确认赵小雅伴鬼暂被困，要求刘思悦携赵小雅转移至大昌市。他计划测试许愿鬼下次以刘思悦死亡为代价后能否再次将其复活、实现重复许愿；该构想尚未实施。（原文回跳第1206章、原文回跳第1207章）

#### 原文回跳第1273-1274章·伴鬼回归后继续监护赵小雅

愿望鬼回归后，刘思悦发现赵小雅一夜间外貌长大、伴鬼在夜间活动，且赵小雅的言行已受灵异影响而显著扭曲。她向赶来的杨间说明异常，在杨间将赵小雅送入鬼梦后暂时脱离眼前危险。（原文回跳第1273章、原文回跳第1274章）

#### 原文回跳第1276章·随赵小雅转入尚通大厦

鬼橱消失后，刘思悦背着昏睡的赵小雅随杨间转移至尚通大厦，继续承担看护任务。杨间为二人安排住处与医疗设备，并以李阳、熊文文监视潜伏的许愿鬼。（原文回跳第1276章）
