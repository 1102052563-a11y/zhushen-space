# 王风

王风是藏在鬼邮局四楼404卧房衣橱内的信使之一，持有染血木槌。他与曲洪涛等人利用衣橱隔绝内外动静、躲避四楼夜间厉鬼，也借404原有撞墙鬼作掩护。（原文回跳第893章、原文回跳第894章）

#### 原文回跳第894章·持木槌与杨间冲突

王风用染血木槌击中杨间鬼手，令其短暂麻木，却被杨间以黄金灵异长枪柴刀部分削伤手臂。另一名同伴以未知灵异隔绝鬼影入侵，双方没有继续死斗；王风拒绝交出木槌，暂与杨间对峙。（原文回跳第894章）

#### 原文回跳第895章·被压制、记忆篡改并交出木槌

杨间以鬼影同时压制王风和其驭鬼者同伴，窃取并修改王风记忆后放人。王风交出染血木槌、被要求留在404房间，不得再躲回衣橱；其记忆被改动的具体内容未明。（原文回跳第895章）

他和衣橱内同伴是否为四楼混入的伪装鬼、未知灵异能力的持有者是谁，均待后文。

#### 原文回跳第930-931章·鬼骰局拖延后门，掷输死亡

王风以一红一黑鬼骰子强制后门厉鬼参与掷点游戏，试图拖延入侵。该局人赢只能令鬼短暂后退，人输则立即死亡；他在第五局掷出二点、败给鬼的五点，当场死亡。其尸体随后被樊兴从后门丢入鬼林。（原文回跳第930章、原文回跳第931章）
