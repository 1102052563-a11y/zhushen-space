# 张洞

## 简介

张洞是被称为“鬼宅老人”的民国时期驭鬼者。中药铺老人曾将其列为民国旧人；过去映照中的秦老为确保围杀杨间，令其一同乘灵异公交到场。（原文回跳第1270章、原文回跳第1313章）

## 过去映照中的能力与行动

他出手后，可使杨间的鬼眼、鬼手、鬼火和鬼影等灵异直接沉寂，令杨间近似失去全部灵异支撑、身体无法行动；但其本次未能真正抹除厉鬼本体。其后张洞又以同类能力大范围抹除鬼童灵异，暂时压住鬼童群体。（原文回跳第1313章、原文回跳第1314章）

鬼童以持续增殖的数量抵消压制，并保护无法行动的杨间，张洞遂带领其余旧人向杨间位置强行推进。至第1314章，战局仍在持续。本页内容均为过去映照事件，不等同于真实历史。

#### 原文回跳第1315章·映照崩散前困住杨间意识

鬼童压制其余旧人、过去映照即将崩散时，张洞仍借一条模糊小路绕过鬼童封锁，抓住杨间脖颈并称“送你上路”。世界随后消失，杨间肉身留在现实木楼，意识却被卡入真实与虚幻夹缝；该结果是本批杨间未能完全脱困的直接原因。此事仅发生于过去映照。（原文回跳第1315章、原文回跳第1316章）
