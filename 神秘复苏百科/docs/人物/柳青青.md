# 柳青青

柳青青是鬼邮局三楼34号房女性信使，身着旗袍、披貂绒，穿黑色高跟鞋。李阳曾因夜间听到高跟鞋声而怀疑她与三楼异常有关，但她白天在34号房现身，不能据此确认高跟鞋声是否来自她。（原文回跳第789章、原文回跳第791章）

她在李易与郭幽为第三封信、出售情报争执时主张先确认任务情况。31、34号房共同接到黄信后，她随李易、郭幽抵大川市机场；机场人群异常、李易的灵异水变血后，三人从停机坪逃离。其自身能力、是否持有灵异物及后续送信选择均不详。（原文回跳第791章、原文回跳第796章）

#### 原文回跳第799-804章·躲避鬼奴后见证郭幽死亡

柳青青随李易、郭幽在大川市躲避鬼奴，并决定响应杨间的机场汇合要求。她发现机场内鬼奴对杨间的行动存在异常反应，却无法判断原因；三人抵达后被纳入杨间的诱饵计划。（原文回跳第799章、原文回跳第802章、原文回跳第803章）

熊文文预知郭幽已受鬼影头侵蚀，杨间以影子异常为证据开枪并使用棺材钉限制。柳青青未能阻止，亲见郭幽维持意识的灵异中断后死亡。她与李易随后选择留在专机，明月小区行动待后文。（原文回跳第804章）

#### 原文回跳第805-809章·接受探路条件并进入301室

柳青青与李易、杨小花接受杨间提出的明月小区探路条件：存活者可被带离鬼邮局。她进入烟域后仍较能保持镇定，鬼找人接近时随众人躲入住户，再从二楼跳下；其落地异常轻盈，显示身体或有未明灵异，但她没有解释。（原文回跳第805章至原文回跳第809章）

面对301室内异常灯光，她建议先在门口留信撤离，未被杨间采纳。她判断外面仍有鬼、独自滞留更危险，遂与李易、杨小花一起跟入301室。其能力、信件是否送达和房内状况均待后文。（原文回跳第809章）

#### 原文回跳第810-814章·出现301室残留记忆

301室菜篮人偶消失后，柳青青称自己对房间有疑似“曾居住”的熟悉感，并能指出人偶常在红桌下、需倒转视线才可看见。她无法说明记忆来源，只怀疑其不属于自己；杨间仅以驭鬼者受灵异侵蚀会获得异物记忆作类比，未确认她的能力、旗袍与301室的实际关系。（原文回跳第811章）

杨间留信并被倒视人偶厉鬼追出后，柳青青曾主张留在301室以避开外部鬼找人，后续是否离开、是否因房内灵异受影响及她的具体位置，本批未写明。（原文回跳第811章）

#### 原文回跳第815-819章·与301室红旗袍线索重合后失踪

杨间通过301室遗留媒介，看见屋主老太太曾让无脸木偶穿上一件与柳青青所穿完全相同的红色旗袍，并在木偶脸上画出与鬼画女子、鬼橱照片女子相同的脸。杨间据此判断柳青青的鬼旗袍令她获得了301室残留记忆，但旗袍与木偶、鬼画女子的完整关系未明。（原文回跳第817章）

301室异变时，杨间在楼窗见到疑似柳青青的红旗袍身影，却未能在室内找到她。其后李易被未知灵异掏空为皮囊，李阳认为袭击可能来自柳青青或301室外出的鬼；柳青青本人下落、是否仍保持自我均未确认。本页状态改为失踪。（原文回跳第815章、原文回跳第819章）

#### 原文回跳第820-824章·以红旗袍抵住抹除并交还棺材钉

杨间受黑白老人抹除、无法取回棺材钉时，柳青青主动阻止李阳靠近，称其会死亡，自己则走入灵异范围。她双脚和高跟鞋先褪色消失，但红旗袍愈发猩红，使抹除没有进一步蔓延；她捡起棺材钉交给杨间，助其钉住地面鬼影、恢复身体控制。（原文回跳第822章）

她动作和言语仍僵硬、木讷，李阳无法确认她是驾驭旗袍还是受旗袍操控。她已现身并帮助杨间，故本页状态改为存活，但自我意识和与301室灵异的关系仍不明。（原文回跳第822章）

#### 原文回跳第825章·确认无身体、以旗袍和无脸木偶维持

柳青青揭下面部人皮后，露出无脸木质头部，确认301室消失的无脸木偶已填入她的人皮躯壳。她称自己早年送信时遭厉鬼袭击、肉身已失，只余人皮由灵异维持；当前红旗袍与无脸木偶形成平衡，使其成为驾驭两只鬼的驭鬼者。（原文回跳第825章）

她没有解释自身来历、送信时的具体遭遇或接近301室的真实目的，只称会在鬼邮局四楼再见。杨间暂不阻止其离开，但明确警告不得干扰自己终止鬼邮局的行动。（原文回跳第825章）
