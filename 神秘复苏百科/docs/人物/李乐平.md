# 李乐平

李乐平是大川市负责人、总部队长级人物，外貌普通到难以留下印象。杨间曾在队长人选会议坐在其旁边，却只记得名字、没有面貌记忆；李乐平称自己不是容易被人记住的人，其成因和所驾驭厉鬼均未说明。（原文回跳第793章）

他曾上报解决C级“被遗忘”和B级“猛鬼区”事件，但两份档案都没有处理过程和厉鬼情报。杨间、李阳抵大川市时，李乐平承认当地有未上报的特殊情况；他和数名助手在阳光下均没有影子。其是否本人、无影规律与大川市人头异变的关系均待确认。（原文回跳第794章）

#### 原文回跳第797-799章·人头被发现，假身份仍在活动

杨间追踪其卫星定位手机至人头超市，在货架上发现一颗与李乐平外貌完全一致的人头。杨间据自己无法记住真正李乐平外貌、却能记住白天接待者的矛盾，判断白天的“李乐平”是鬼借记忆和不同人头形成的伪装，真正李乐平可能死亡或因被遗忘特性藏匿。（原文回跳第798章）

该人头是否仍有意识、真李乐平是否存活、假身份如何取得负责人证件和卫星手机，以及其与无头鬼影头的实际关系均不详。本页状态由存活改为失踪，避免把货架人头等同其最终死亡证明。（原文回跳第798章、原文回跳第799章）

#### 原文回跳第800-804章·电话说明驾驭失败与明月小区藏身

李乐平电话中称，鬼影头入侵大川市后，他曾尝试驾驭该鬼，并在行动当天主动遗忘相关记忆，试图以遗忘鬼消除意识侵蚀。尝试失败时，鬼曾控制其身体并侵蚀两名队友；他恢复意识后无力扭转城市局势，只能保留人头和尸体等待补救机会。（原文回跳第800章）

他自称躲在猛鬼区的明月小区，借小区内另一只鬼抵挡外部鬼影头，同时维持小区厉鬼不外溢。此说法与鬼邮局送信地址吻合，但电话身份尚未当面核验；其具体位置是否为7栋301室、是否仍受鬼控制均待后文。（原文回跳第800章）

#### 原文回跳第806-809章·手机线索与熏黑干尸并存

杨间在明月小区外拨打其号码，循铃声取得一部李乐平留下的手机。手机短信警示猛鬼区内有梦游鬼、鬼找人及未知厉鬼，并称他曾遇险到必须用遗忘鬼抹掉整日记忆；信息与此前电话叙述相互印证，却不能直接证明留言者是本人。（原文回跳第806章、原文回跳第807章）

杨间进入小区后发现一具穿负责人制服、黄金胸牌写“李乐平”的熏黑干尸，且判断尸体已死至少半月。尸体与电话、手机线索相矛盾，可能是李乐平本人、鬼影头伪装的受害者或其他未明情况；李阳脱身后又听见房间内声音自称李乐平，身份疑云未解。本页维持失踪状态。（原文回跳第807章至原文回跳第809章）

#### 原文回跳第812-814章·现身并说明异类化计划

李阳脱离断后房间后，见到一具自称李乐平的僵硬尸体追来；杨间开启高层鬼域后看出其为保留活人意识的鬼。李乐平承认自己并无江城、张小小等队友，猛鬼区的梦游鬼、鬼找人和浓烟鬼域都是他所驾驭厉鬼，早前手机档案为保护计划而伪造。（原文回跳第812章、原文回跳第814章）

他称自己驾驭鬼影头不是为普通平衡，而是要以遗忘鬼入侵、取代厉鬼意识，成为保有活人意识的异类。计划仅成功一半：白天或非“黑夜”状态能保持清醒，黑夜会受梦游鬼本能主导；杨间鬼域制造黑夜后令其暂时失控，红光覆盖后意识恢复，清醒时长也由约十二小时增长至十五小时。其自称仍在尝试让梦游鬼遗忘杀人规律，最终是否成功、风险边界均待后文。（原文回跳第814章）

杨间以柴刀戒备，尚未对李乐平动手。李乐平的异类化状态、先前熏黑干尸的实际来源及两人的后续处置均待下一章确认，但其本人存活已获当面确认。（原文回跳第814章）

#### 原文回跳第815-819章·达成暂时合作并接手301室风险

李乐平称明月小区既是自困地，也是隔绝鬼影头入侵的安排；他希望杨间交还失控厉鬼，待自身状态稳定后以条件赎回。杨间衡量两人无根本冲突、且301室风险更紧迫，暂未动手；李乐平承诺不再制造麻烦，双方形成暂时合作。（原文回跳第815章）

301室老人尸体取走黄信、房门无法关闭并导致外部杀人后，杨间要求李乐平在其离开后处理大川市301室事件，代价是留下被压制的鬼找人供其恢复后取回。李乐平接受，杨间则以鬼域将他移出明月小区，避免其在高危区域继续失控。（原文回跳第819章）
