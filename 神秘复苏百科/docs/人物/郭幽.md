# 郭幽

郭幽是鬼邮局三楼34号房男性信使，态度强硬，反对李易为安家费出售第三封信。他认为三人应通过完成第三封信进入四楼，而非把命运交给杨间；其职业、所持灵异物和已送信次数均不详。（原文回跳第791章、原文回跳第792章）

黄信将31、34号房共同绑定至大川市明月小区任务后，郭幽随李易、柳青青到大川市机场。机场灯灭、李易以浑水变血判断有鬼后，他随二人从停机坪撤离，后又躲避疑似失控客机冲撞。郭幽仍主张不能放弃送信，具体去向待后文。（原文回跳第796章）

#### 原文回跳第802-804章·被鬼影头侵蚀后遭棺材钉限制

郭幽与李易、柳青青到机场汇合时表面正常、也保有完整记忆与自我认知，但熊文文预知他会杀死柳青青并导致杨间厉鬼复苏。杨间开枪后发现其影子前后方向异常，影子头部出现带五官的浓黑轮廓，确认鬼影头已侵入其意识。（原文回跳第803章、原文回跳第804章）

杨间将棺材钉钉入郭幽身前地面，限制其影子。黑色影子人头从地面浮起，郭幽随即失去维持意识的灵异、身体仍有心跳却意识消散，最终死亡。他至死不认为自己是鬼，说明鬼影头的意识侵蚀可高度伪装。（原文回跳第804章）
