# 董玉兰

董玉兰是被困凯撒异常走廊的循环者，穿旧式连衣裙，在501号房复活、499号房记录信息。（原文回跳第1151章、原文回跳第1152章）

她和王根全在朱见傀儡出现后未与杨间冲突，转由香兰带往十号房取回封存画像。画像令其恢复过往记忆和厉鬼驾驭，身体留下淤青，随后加入香兰的脱困计划。（原文回跳第1172章、原文回跳第1174章）

她同意伏击受伤的杨间和童倩，却被杨间以燃烧鬼手拖入尸堆、掐断颈骨，尸体随即被炉火点燃。该身体已死亡，是否按循环规则复活待后文。（原文回跳第1179章）
