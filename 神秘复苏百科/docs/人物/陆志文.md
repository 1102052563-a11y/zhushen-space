# 陆志文

陆志文是总部内定的第十二位队长，平时负责特殊安保和灵异档案整理。其身体呈木质纹理、声音与口型不协调，显然非正常活人；具体灵异能力、身份来源和日常行动均保密。（原文回跳第1238章）

高明亡魂留下凶手画像后，陆志文直接报出张羡光的姓名、籍贯、出生年份、父母和旧任职信息，显示其掌握异常详尽的档案能力；这些资料仅能追至张羡光曾任双桥镇小学教师，后续长期失踪。（原文回跳第1239章、原文回跳第1240章）

#### 原文回跳第1257-1259章·预设队长灵异保护

陆志文承认已预先在多名队长身上留下只于生死关头生效的灵异保护：何银儿遭致命袭击会产生偏差，李乐平失控时可短暂保留理智，李军濒死时可留下一丝意识。私塾意识陷阱中，他的保护令随机杀人厉鬼一刀砍偏，救下何银儿。（原文回跳第1259章）
