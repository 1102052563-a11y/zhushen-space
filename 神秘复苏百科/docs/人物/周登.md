# 周登

周登是灵异公交车上的年轻驭鬼者，自称与总部曹延华合作过、知道队长会议。他行事冒险，曾在公交停站时为夺取灵异物品主动下车。（原文回跳第912章、原文回跳第913章）

## 能力与物品

- **人皮面具**：戴上陌生人皮面具后，公交电子屏鬼数由十三增至十四，显示面具会使其呈现厉鬼特征或带来额外灵异；具体机制、代价和是否属于驾驭厉鬼均不明。（原文回跳第912章）
- **实战**：在301室老太太上车导致超载时，他与杨间约定各清理一人，成功击杀一名驭鬼者腾出座位。（原文回跳第912章）

#### 原文回跳第913章·冒险下车取得盖脸纸

周登在第二站主动下车，借人皮面具从纸灰中取得三张残缺盖脸纸，试图进一步拿走铜盆失败。车门即将关闭时，杨间以短暂车门控制打开通路，周登成功回车，并以一张损毁较少的盖脸纸作为救援代价交给杨间。（原文回跳第913章）

#### 原文回跳第925-929章·盗香与白灯笼，提前报丧

周登从后堂取走一炷香、从宅门取走一盏白色“奠”字灯笼，沿后门黄泥路进入鬼林。他将香插到一座旗袍女子墓前，唤出穿红旗袍、红高跟鞋的女子并使其沿路走向古宅；他提白灯笼外出也被杨间判断为提前完成报丧，致使守夜平衡失效。（原文回跳第925章、原文回跳第927章至原文回跳第929章）

#### 原文回跳第935-939章·鬼林遇险、假死返回与吊唁避险

周登被墓中红旗袍女子在鬼林识破人皮面具伪装、夺走白灯笼后，以盖脸纸装死沉睡，直至杨间一行发现并揭纸才醒来。他确认鬼林内有大量黑衣鬼，并称树下多埋尸体与白色丧服；杨间要求其后续服从指挥。（原文回跳第936章、原文回跳第937章）

第四日吊唁开始时，周登主动放弃丧服，改戴人皮面具伪装为鬼、留在大堂避险；该方式能否撑过整日待后文。（原文回跳第938章、原文回跳第939章）

#### 原文回跳第945-949章·获丧服、鬼宴置饭试错失败

大强死亡后，杨间将其丧服交给周登。第五日鬼宴时，周登试将白米饭连碗置地，黑色太师椅鬼却撞翻饭碗、吞食米饭后继续袭击；杨间以柴刀斩断该鬼一只手掌并将周登拉回鬼域，试错失败。（原文回跳第945章、原文回跳第949章）

#### 原文回跳第955-959章·出殡引鬼后被老婆婆抹除

出殡路上，301室老婆婆拦住黄泥小路，常规灵异手段无法触及。周登主动戴人皮面具进入鬼林，将老婆婆引走，为杨间一行争取抵达墓地的时间；厉鬼很快返回，周登被抹除，第二只老婆婆随之出现。（原文回跳第958章）

#### 原文回跳第960-964章·被八层重启救回并推断椅子互通

杨间借红棺老人尸体抹除老婆婆、开启八层鬼域重启约半小时，将周登从被抹除结局救回。第七日来临前，周登汇集四把黑色太师椅，推断古宅本应有七把，椅子可能互通并与收信人到来有关。（原文回跳第961章、原文回跳第964章）

#### 原文回跳第965-969章·协助困住收信人并脱离古宅

周登以黑色太师椅阻断无形收信人，并坐椅堵住走道，协助杨间使收信人显现、完成红信交付。古宅老人复苏后，他作为气球承载者被杨间带离至大洲市；脱离气球后自行向总部汇报樊兴等人死亡，随后离队。（原文回跳第966章至原文回跳第969章）
