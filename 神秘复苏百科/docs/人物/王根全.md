# 王根全

王根全是被困凯撒异常走廊的老农循环者，在801号房复活，为避免深入将信息记录在600号房。（原文回跳第1151章、原文回跳第1152章）

他较早认可杨间为外界封锁灵异的立场。朱见傀儡事发后，他与董玉兰随香兰进入十号房，拿起封存画像并取回旧记忆和驾驭厉鬼的能力，加入香兰的脱困行动。（原文回跳第1152章、原文回跳第1172章、原文回跳第1174章）

他主张与杨间合作，但在香兰决定偷袭后参与行动，以一面镜子映照杨间、试图令镜面和本人同步碎裂。诅咒未能立刻杀死杨间，且王根全已承受反噬裂纹，结果待后文。（原文回跳第1179章）

高大腐烂男尸令王根全尸体迅速腐烂死亡。复活后，他凭事先留下的信息追到黄金门前，请求杨间允许其出门验证自由；离开凯撒即加速腐朽死亡，证明其生命依托酒店诅咒，无法脱离现实侧存活。（原文回跳第1182章、原文回跳第1187章）
