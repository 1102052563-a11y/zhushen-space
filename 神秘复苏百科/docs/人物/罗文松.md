# 罗文松

## 简介

罗文松是民国时期的鬼邮局管理者。中药铺老人曾将其列为民国旧人；原文回跳第1313章，白水镇过去区域中的秦老让其离开映照中的鬼邮局，加入围杀杨间。（原文回跳第1270章、原文回跳第1313章）

## 过去映照中的能力与行动

他可令周边门窗、地面和建筑显出大量通往未知处的“门”，并由这些门叠加发动必死灵异袭击或构成封锁。鬼童以大量分身堵住门后空间，令其无法直接打开通路袭击杨间。（原文回跳第1313章、原文回跳第1314章）

鬼童群体持续喊出他的名字、发动削减寿命的诅咒后，他一度无故死亡，后由秦老重启恢复；至第1314章，罗文松仍在与鬼童对抗，战果未分。本页内容均为过去映照事件，不等同于真实历史。（原文回跳第1314章）

#### 原文回跳第1315章·门域失守后被吞没

罗文松开启层层木门、以深处黑暗消除部分鬼童，却因所有门被鬼童堵住、鬼域遭撕裂而被后方人潮吞没。该死亡仅属于过去映照事件，不等同于真实历史。（原文回跳第1315章）
