# 沈林

沈林代号“鬼相”，为总部十二位队长之一，负责大夏市。他可令众人获得共同记忆，再使记忆与现实重叠，借此从不存在的现实状态出现；具体驾驭厉鬼和异类状态待后文。（原文回跳第1051章）

鬼湖调查中，沈林让中州市重现灾变前的繁华表象，并取代其中一名年轻人，准备亲历其死亡以获知鬼湖杀人规律。其是否会受预演中的死亡影响、能力代价与调查结果待后文。（原文回跳第1054章）

#### 原文回跳第1056-1058章·鬼湖探查与太平古镇定位

沈林借被取代市民的死亡进入鬼湖，发现自身也会受湖中灵异寒意影响。他以记忆替身取代白衣女尸后登岸，确认鬼湖小河延伸到现实，最终锁定太平古镇为关键连接点；其真身所在、白衣女尸身份与湖岸探查结果待后文。（原文回跳第1056章至原文回跳第1058章）

#### 原文回跳第1060-1064章·渡口情报与登船

沈林由鬼奴记忆得知太平古镇渡口午夜会出现载棺黑船，认为这是安全进入鬼湖的路径。他与李军、阿红等至子夜，随后同队登船；途中灵异河流逐步替代现实，后续航程待后文。（原文回跳第1060章、原文回跳第1064章）

#### 原文回跳第1065-1067章·渡船减负并抵达鬼湖

渡船接入未知厉鬼而下沉后，沈林丢弃一只装有沉睡灵异的黑玻璃瓶，显著减轻船的灵异负荷；他与杨间推断渡船和纸钱构成将厉鬼运入鬼湖压制的旧时代关押体系。抵达鬼湖后，具体源头厉鬼仍未见。（原文回跳第1066章、原文回跳第1067章）

#### 原文回跳第1070-1074章·入侵源头记忆反被驾驭

沈林离船后连续入侵鬼湖尸体记忆，找到太平古镇渡口黑棺和棺中女尸线索。他被源头厉鬼贴身入侵、遭反向驾驭；重启至不同记忆仍无法摆脱，只能进入杨间记忆求救。（原文回跳第1071章、原文回跳第1072章）

源头厉鬼沿其能力侵入杨间四年前记忆，遭黑色狼狗群撕碎。沈林在当前鬼湖行动中的本体下落、是否摆脱驾驭及记忆规则结果待后文。（原文回跳第1072章、原文回跳第1074章）
