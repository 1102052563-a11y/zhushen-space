# 赵丰

赵丰是鬼邮局五楼老信使，旧称“勾魂使”，现以杀鱼小贩身份生活。黑色信件重启邮局后，他夜间先行赶往五楼，试图杀死杨间、将信送回502以恢复原有平衡。（原文回跳第995章、原文回跳第996章）

他持一根可燃起磷火、驱散邮局黑暗的白骨，以及一柄可勾出活人部分的锈铁钩。杨间以六层鬼域暂停、长枪棺材钉压制其灵异，远程用鬼影读取并抹除其人格。（原文回跳第996章、原文回跳第997章）

杨间随后将鬼影人格植入赵丰身体，用该身体伪装自己承受五楼信使首轮袭击；赵丰身体持铁钩反制代驾信使。赵丰本人意识已不存在，其身体后续用途待后文。（原文回跳第999章）
