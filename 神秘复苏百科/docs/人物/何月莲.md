# 何月莲

何月莲是何老板私生女，长相与杨间在鬼画、鬼橱照片中见过的女子完全一致。杨间读取其记忆时遭一盏记忆油灯阻挡，仅看到疑似鬼邮局五楼的鬼画碎片；其与鬼画的实际关系待后文。（原文回跳第1122章、原文回跳第1123章）

何老板早年受未知人承诺富裕一生，对方要求其生下一名女儿以待日后抵债。何月莲得知自己可能是交易代价后愤怒；她随后受何老板、骆胜等人指派，准备把杨间带往设有707门牌的贵宾室。（原文回跳第1124章）

杨间已篡改其认知，使她以为自己将707门牌挂在贵宾室门后，实际未触发凶间。她脱离房间后状况、能否摆脱认知影响及与张羡光的关联待后文。（原文回跳第1125章、原文回跳第1128章）

杨间清除贵宾室设局者后回收707门牌，提醒何月莲留意张羡光；她对何老板死亡反应平静，并认为杨间已在自己认知中留下未知后手。（原文回跳第1130章）

何龙答应给她半份遗产，要求她三日后赴大昌市向杨间赔礼并寻找自身秘密线索；何月莲接受后准备离开大澳市。（原文回跳第1138章）

#### 原文回跳第1190-1194章·鬼画女子复苏载体

何月莲主动搬至观江小区寻求杨间庇护，杨间以其二十五岁临界年纪为由，判断张羡光计划接近触发，遂令她赴大汉市地狱公寓见孙瑞、寻找张羡光线索。（原文回跳第1190章）

鬼邮局油画世界内的张羡光灵异备份认出其脸，并揭露现实张羡光计划：收集鬼画女子的灵异拼图，以何月莲为载体令死去的女子“复苏”。她的自我能否保留、张羡光完整目的及计划时点待后文。（原文回跳第1192章、原文回跳第1194章）

#### 原文回跳第1247-1249章·被现实张羡光带走

何月莲留在孙瑞地狱公寓时，现实张羡光带陈桥羊等人借鬼邮局到来。孙瑞被斩首、田晓月受阻后，她无法反抗，只能随张羡光离开；此时鬼画已被夺走并在双桥镇快速扩张。（原文回跳第1247章至原文回跳第1249章）

#### 原文回跳第1260-1264章·继承鬼画女子灵异并保持清醒

张羡光以鬼嫁衣、红盖头、临时画出的绣花鞋和鬼画女子牵手，使何月莲承受多份灵异拼图。她在意识冲突中拒绝被吞没，继承鬼画女子破碎记忆和灵异；鬼画女子意识留下“前生今世”说法后消散。（原文回跳第1260章、原文回跳第1264章）

何月莲最终清醒存活，外貌和灵异状态已变，是否会接受张羡光桃花源计划仍待后文。此时强杀她可能令鬼画全面失控，杨间选择先等待其表态。（原文回跳第1264章）

#### 原文回跳第1265-1266章·拒绝桃花源并留在地狱公寓适应

何月莲明确拒绝桃花源计划，选择接受总部和杨间安排。她收回鬼画鬼域、将画中众人带回地狱公寓，原有鬼画画框随之失去灵异。（原文回跳第1265章）

她暂时留在地狱公寓，由孙瑞观察精神状态并协助适应鬼画女子、鬼嫁衣等灵异；何时正式加入总部及长期平衡情况待后文。（原文回跳第1266章）
