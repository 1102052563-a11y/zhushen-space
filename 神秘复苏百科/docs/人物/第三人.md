# 第三人

第三人是大昌市老城区一名先天重残者。饿死鬼事件后，他被一只难以被注意的厉鬼入侵，靠灵异维持生命并获得在人群中被忽略的特性。（原文回跳第976章、原文回跳第977章）

他为摆脱残疾与无存在感，杀害多人、盗取肢体拼成新身体，自己寄生其中；因张伟等人对其产生怀疑，又杀死相关线人。其在人群至少三人时会被视线与意识自动忽略，人数降至一人或无人时才会显现。（原文回跳第976章、原文回跳第977章）

杨间以鬼域逐步隔离网吧人员，使其曝光后用鬼手压制，读取记忆并抹除其人格，将本体和厉鬼黄金关押。该鬼适合制成降低被发现概率的灵异物品，但具体制作与使用规则待后文。（原文回跳第976章、原文回跳第977章）
