# 骆胜

骆胜是大澳市负责人。他先在电话中答应杨间处理王彬、张显贵的赌场债务，随后改口要求以尚通大厦抵债；杨间判断其可能已被攻破或参与针对自己的圈套。（原文回跳第1112章）

杨间抵达大澳市后，骆胜不现身接待，暗中派人监视，并在大兴娱乐城贵宾室逗留。他对杨间及娱乐城幕后的关系、实际立场和灵异能力待后文。（原文回跳第1115章、原文回跳第1119章）

#### 原文回跳第1124-1128章·以假身参与707陷阱后被清除

骆胜与孙仁、何老板制定707门牌困人计划，但其本人以红线缝合血肉制成的假身现身试探。杨间以鬼域斩首、棺材钉与鬼湖积水压制假身，识破骆胜真身未到；假身残余红线随灵异消散，真身去向待后文。（原文回跳第1124章、原文回跳第1127章、原文回跳第1128章）

#### 原文回跳第1131-1134章·录音诅咒困入梦魇并追杀失败

骆胜以传教士录音诅咒令杨间昏睡、拉入梦魇城堡，并与数名中外驭鬼者企图将其长期围困或在梦中杀死。他亲自参与追杀，却因黑狼狗使鬼梦与梦魇碰撞、现身敌人后方而陷入反制，后续生死待后文。（原文回跳第1131章至原文回跳第1134章）

#### 原文回跳第1135-1137章·梦中逃生后遭现实狼狗咬首

骆胜在梦魇城堡被狼狗群追猎，凯丽将其送回海外庄园现实。狼狗随即从喷水池倒影跃出、咬断其头颅；他仍能靠红线缝合血肉复原，随后放弃继续直接面对杨间。（原文回跳第1135章至原文回跳第1137章）
