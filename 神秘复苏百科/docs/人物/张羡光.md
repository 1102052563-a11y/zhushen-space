# 张羡光

张羡光是送完鬼邮局五楼三封信后离开的早期信使，其灵异备份被困于油画世界的邮局。他自称已死，是该处资历极深的亡魂之一。（原文回跳第1008章）

他说明油画世界收容的是完成最终任务者的意识备份：现实中的本体离开邮局，备份却永远困在此地；外界无人记得时，备份会消失。张羡光认为这等同无间地狱，支持杨间与杨孝利用油画亡魂处理外界灵异事件。（原文回跳第1008章、原文回跳第1009章）

#### 原文回跳第1129章·二十余年前与何老板交易

杨间读取何老板记忆，确认二十余年前的张羡光曾承诺何老板富裕一生，条件是生下一名女儿日后抵债，何月莲因此出现并与鬼画女子同脸。杨间在该记忆中被过去的张羡光诡异注视，黑狼狗才驱散隐患；张羡光是否仍存活待后文。（原文回跳第1129章）

#### 原文回跳第1192-1194章·以何月莲复苏鬼画女子计划

油画邮局内的张羡光备份见到何月莲后承认，现实本体离开邮局后正试图收集鬼画女子散落的灵异拼图。其目标并非普通复活，而是以何月莲为载体汇聚拼图、令原为驭鬼者的画中女子再次复苏；真正目的与缺失记忆仍未明。（原文回跳第1192章、原文回跳第1194章）

#### 原文回跳第1239-1244章·带队夺走鬼画

高明亡魂留下的画像坐实张羡光为高明凶手。张羡光随后与陈桥羊等人趁队长会议潜入平安大厦，以鬼画压制队长鬼域、带走鬼画源头；他持锈蚀大刀一击逼退杨间、曹洋和柳三，队伍成功撤离。（原文回跳第1239章、原文回跳第1243章、原文回跳第1244章）

宋新海在撤离时被李乐平截杀，陈桥羊则确认在队伍中。张羡光一伙离开所用灵异路径仅留下“蜿蜒小路”线索，鬼画去向和其复苏计划进度未明。（原文回跳第1244章）

#### 原文回跳第1245-1249章·鬼邮局转移与双桥镇鬼画扩张

张羡光借鬼邮局撤至大汉市地狱公寓，斩首管理者孙瑞、击退田晓月并带走何月莲。其油画备份称不知现实本体计划，却提示宋新海、聂英平、张先、陈桥羊均可能是旧日同伴，并指向双桥镇废私塾。（原文回跳第1247章至原文回跳第1249章）

现实张羡光在双桥镇放大鬼画鬼域，灰白纸灰迅速扩至大汉市及附近区域，逼八名队长进入鬼画世界追击。鬼画女子复苏计划是否已启动、何月莲具体作用待后文。（原文回跳第1249章）

#### 原文回跳第1250-1254章·桃花源计划与光亮媒介

张羡光公开桃花源计划：由不死的鬼邮局管理者驾驭鬼画，将所有人纳入可控画中世界。他承认自己三次完成邮局最终送信，复活油画中的自己后第三次成为管理者；管理者本体留在邮局，主要灵异力量转给另一个自己。（原文回跳第1250章、原文回跳第1252章）

双桥镇交战中，他以五具可重启分身、锈刀和陈桥羊引来的鬼差围杀队长。何银儿招来太平古镇强大亡魂压制第二波分身；杨间进入教学楼发现五盏尸油灯照影是重启媒介，并进一步识破张羡光须借光亮显现，黑暗中无法被接触或发动袭击。（原文回跳第1251章至原文回跳第1254章）

#### 原文回跳第1260-1264章·本体受困与计划结局待定

张羡光以何月莲作为鬼画女子灵异拼图容器，安排鬼嫁衣、红盖头、绣花鞋和鬼画女子牵手，试图造出可驾驭鬼画的管理者。孙瑞与油画亡魂反制后，他的同伴杜洪、张莹死亡，聂英平被金色火域压住。（原文回跳第1260章至原文回跳第1263章）

杨间以金色火域逼出其现实身体，用棺材钉压制、草绳圈看守并沉入鬼湖。何月莲已成功融合且仍清醒，是否按张羡光设计执行桃花源计划，成为其最后变数。（原文回跳第1261章、原文回跳第1264章）

#### 原文回跳第1265-1268章·桃花源失败，现实本体消亡

何月莲拒绝桃花源后，张羡光承认计划失败。杨间将其带回鬼邮局、解除草绳圈；张羡光自行走出邮局，在阳光下失去管理者保护而消亡，遗留一个疑似用于转移意识的玻璃球。（原文回跳第1265章）

其留在鬼梦私塾的意识备份仍被恶犬束缚。杨间暂不抹杀该意识，要求他以未解秘密和情报赎罪；其能否继续被长期困住待后文。（原文回跳第1268章）

#### 原文回跳第1274章·在鬼梦私塾教导赵小雅

杨间将认知受愿望鬼扭曲的赵小雅送进鬼梦私塾，交给受困的张羡光教导。张羡光判断女孩并非天性恶毒而是不知善恶，因而接受教导任务；此举不改变其仍受恶犬束缚的状态。（原文回跳第1274章）
