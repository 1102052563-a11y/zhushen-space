# 鬼找人

## 概述

“鬼找人”是李乐平驾驭的厉鬼暂称，活动于猛鬼区明月小区。李乐平曾在手机中伪造张小小等同伴档案，将其描述为张小小死后遗留；后亲自说明鬼找人、浓烟鬼域和梦游鬼均属自己驾驭的鬼。（原文回跳第806章、原文回跳第807章、原文回跳第814章）

## 已知规律

李乐平的资料称，鬼找人杀人需同时满足“发现目标”与“靠近目标数米内”两项，触发后即使驭鬼者也可能瞬间死亡。它不分昼夜活动，并可借覆盖小区的浓烟鬼域扩大搜寻范围。距离阈值、何为“发现”、是否有规避手段均未得到完整验证。（原文回跳第806章、原文回跳第809章）

杨间一行接近7栋时，李易以灵异浑水检测到血水流向第三排中间楼栋，杨间同时察觉浓烟凝成又消散的人影，判断该鬼已发现众人。众人躲入二楼住户后，鬼进入客厅翻找并逼近内房，说明它会搜索已发现目标的藏身处。（原文回跳第808章）

## 与堵门鬼的对抗

李阳以堵门鬼封住房间门，暂时使鬼找人无法确认室内众人；但浓烟仍从门缝侵入，门外焦黑枯手持续磨擦，堵门鬼很快显露不支。李阳留下断后，杨间给他一只替死布娃娃；布娃娃引走鬼找人后，李阳从窗口活着脱离。此过程只证明当次替死有效，不能证明堵门鬼或布娃娃可稳定克制鬼找人。（原文回跳第808章、原文回跳第809章）

## 原文回跳第812-814章·被杨间压制关押

替死布娃娃被鬼找人杀死后，杨间重启八音盒诅咒、开启六层鬼域，以鬼眼压住浓烟鬼域，再以鬼手抓住熏黑干尸本体，压制其活动。李乐平承认该鬼本属自身驾驭；杨间将干尸装入黄金箱，归还与处置问题未定。鬼手松开后的复苏风险、压制能维持多久均不详。（原文回跳第812章至原文回跳第814章）
