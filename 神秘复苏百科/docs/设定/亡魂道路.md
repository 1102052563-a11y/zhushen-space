# 亡魂道路

亡魂道路是白水镇夜间出现的异常街道。被灵异侵蚀的居民和已死亲人的亡魂会混在雨中人流内行走，刘奇在此见到已合葬的祖父母。（原文回跳第1283章、原文回跳第1284章）

白水镇流传可从路上带回死去亲人、令其恢复活人的说法，但萧阳无法证实，且尝试者均迷失在路中、最终成为游荡行尸。王珊珊带鬼童逆人流进入，行踪因此中断。（原文回跳第1284章）

#### 原文回跳第1287-1289章·带亡魂离开的代价

亡魂道路会将进入者与同伴隔开，并按人心显现熟悉死者。亡魂本身无法主动触及活人，但活人可主动牵走亡魂；杀死对应亡魂后，该死者将不再在此人视野中出现。（原文回跳第1287章、原文回跳第1288章）

带亡魂离路只能由该亡魂亲属牵引，旁人接触会令亡魂尖叫、腐烂和接近消散。越靠近道路边界，亡魂和牵引者承受的阻力越强，并会招来不同厉鬼阻拦；刘奇与萧阳受三只残缺女鬼围困，实际能否带亡魂离开待后文。（原文回跳第1289章）
