# 倒视人偶

## 概述

倒视人偶是明月小区301室菜篮内发现的青紫婴儿人偶暂称。它表面像闭眼沉睡的裸身玩偶，眼珠上下反装；正常视角无法发现其与桌下厉鬼，倒转视线后才能看见人偶及持有它的淤青人形鬼。（原文回跳第810章、原文回跳第811章）

## 已见表现

柳青青凭疑似鬼旗袍带来的残留记忆指出，人偶常躲在红桌下，且需倒转视角才能看见。杨间倒视后与人偶目光相接，桌下厉鬼随即起身并锁定追杀他；李易、杨小花没有倒视，未被该鬼识别。能否仅靠倒视触发、目光接触是否必要及该规律的完整范围仍不明。（原文回跳第811章、原文回跳第812章）

杨间开启八音盒诅咒后，以柴刀斩断持偶厉鬼手臂，人偶对应手臂同步断裂并发出非人惨叫，显示人偶才是该组灵异的核心或与厉鬼高度绑定。其后杨间以柴刀将厉鬼与人偶手脚、头部分解为碎块，人偶暂时失去活动能力；碎块被收进黄金箱，是否能自行复原或重新拼合后恢复待后文。（原文回跳第812章至原文回跳第814章）

## 原文回跳第824章·倒视后转移黑白老人袭击

杨间为应对黑白老人对自身的抹除，将收集的人偶碎块重新拼合，再倒转人偶令其视线对准老人。人偶随即剧烈挣扎惨叫、局部褪色，老人对杨间的抹除停止且黑白媒介逐步消退。该过程显示人偶可被用作承受或干扰此类袭击的媒介；人偶并未完全消失，是否仍具活动与追杀能力待后文。（原文回跳第824章）

## 原文回跳第825章·视线规则与强制转移袭击

杨间归纳：人偶被揭开、看见目标后会活动；与其眼睛对视者会被盯上；若人偶和另一只鬼相互“看见”，人偶会将对方灵异袭击强制转移到自身并与之对抗。该规律有明显限制，无头、无眼或无法形成视线的厉鬼未必能被锁定。人偶眼睛仍会自主转动，杨间暂将其作为高风险灵异物保存。（原文回跳第825章）
