# 侵蚀信使鬼

侵蚀信使鬼是混入鬼邮局四楼信使中的未知厉鬼暂称。它没有固定显露形体，能无声潜伏在信使体内、侵蚀或取代其意识，使宿主本人也不知自己已被鬼驾驭；王善在四楼遭其侵入后即成为该鬼的载体。（原文回跳第896章、原文回跳第899章）

## 已知表现

- **伪装宿主**：王善作为一楼信使一路随杨间进入四楼，未表现异常；其死后尸体仍能被该鬼驱动，说明鬼可在宿主死亡后继续利用身体。（原文回跳第896章、原文回跳第899章）
- **规则杀人**：鬼先无声杀死王善本人，又瞬间杀死曲洪涛；杨间判断它必须令目标触发未知杀人条件，不能像驭鬼者般随时直接攻击。（原文回跳第896章至原文回跳第899章）
- **借鬼杀鬼**：开门鬼经过王善时停止并点亮走廊灯。杨间推断开门鬼察觉王善为鬼，却受邮局规则限制无法直接示警，只能以亮灯引来其他厉鬼杀死其宿主；此为基于现场顺序的推断。（原文回跳第890章、原文回跳第899章）

## 当前状态

杨间以棺材钉刺穿王善尸体，尸体抽动并发出厉鬼般叫声，确认其被压制。该鬼能否脱离尸体、更换宿主、杀人完整规则及来源均待后文。（原文回跳第898章、原文回跳第899章）
