# 白水镇过去区域

白水镇棺材木楼二层房门后的异常区域，表面呈现为约三年前、敲门鬼事件发生前的大昌市。进入者会取代当时的自己，可见旧日城市、人物和灵异物品，杨间以七层鬼域重启也无法离开。（原文回跳第1294章、原文回跳第1295章）

王珊珊依据时间悖论判断此处不是真实过去，而是灵异构成的过去映照：她的出现没有改写既有经历，进入者实际仍被困在白水镇范围。杨间在其中试图以鬼湖脱离时，反而连接到三年前尚完整、未被自己窃取的鬼湖，证明这里会对接对应时期的灵异。（原文回跳第1298章、原文回跳第1299章）

人皮纸预示杨间会在区域内对应的白水镇于当日六点十分死亡，故进入者须在此前找到出口。区域构成、木楼为何能连接至此及死亡规律待后文。

#### 原文回跳第1300-1304章·第二张人皮纸揭示脱离方向

区域内存在过去映照的第二张人皮纸。杨间从方镜家取得后，先获知求助鬼邮局、秦老均会失败；随后让鬼童将其吞食，鬼童写下“六点前杀死记忆中的陌生人”这一脱离方向。（原文回跳第1301章、原文回跳第1302章）

杨间开始以鬼影清除映照中熟人对自己的记忆，过去总部随即以方镜死亡为由集结驭鬼者围杀。该反制表明区域会阻碍进入者主动斩断与映照世界的联系。（原文回跳第1303章、原文回跳第1304章）

#### 原文回跳第1305-1309章·映照世界的二次反扑

过去映照总部第一波围杀团灭后，区域继续借秦老、罗千、孟小董等对应时期的旧人发动第二波反扑。杨间在映照中临时取得第二只鬼眼和第二根棺材钉，以双眼互相消去复苏躁动而实现无限重启；但孟小董可沿过去时间点持续入侵，罗千又能埋葬当前状态，说明区域能调动对应时代的高危灵异对进入者施压。（原文回跳第1305章至原文回跳第1309章）

杨间把时间退至两点、转移至无人郊外，试图单独消灭孟小董以改变两点三十分后的围杀局面；至第1309章，鬼湖反制未能将其完全沉没，脱离进展仍未确认。

#### 原文回跳第1310-1314章·映照反扑与区域崩解征兆

杨间以十层鬼域击退孟小董、焚毁映照中的鬼梦残躯和杨孝天头颅后，世界开始透明并显出棺材木楼的房间轮廓，说明他与王珊珊正被区域排斥。映照仍在两点三十分以秦老、孟小董、罗千、罗文松、张洞五人发动最后围杀，试图阻止脱离。（原文回跳第1310章至原文回跳第1314章）

鬼童在映照内形成大量分身，暂时保护被张洞封住灵异的杨间；映照内能力表现不能默认带回现实。区域如何完成排斥、杨间灵异能否恢复及五人围杀结局待后文。

#### 原文回跳第1315-1319章·映照结束但杨间意识滞留

鬼童在映照中压制围杀者后，过去世界于两点四十分崩散；但张洞在最后一秒将杨间意识卡入真实与虚幻夹缝。王珊珊和鬼童回归木楼二层，杨间肉身仍在原处却失去回应，说明离开映照不等同完全脱困。（原文回跳第1315章、原文回跳第1316章）

恶犬在刘奇血媒介引导下回归杨间意识，开始作为外部救援对抗滞留状态。此后木楼本体多鬼复苏属于现实中的独立危机，不再是过去映照内的事件。（原文回跳第1317章至原文回跳第1319章）
