# 黑色雨伞

黑色雨伞是灵异公交车抵达大昌市站点时下车的厉鬼，撑黑伞、可使大范围区域持续阴雨。冯全以白色鬼烛将其引至大昌市外无人郊区，暂未关押；该区域至今阴雨不止。（原文回跳第910章、原文回跳第970章）

总部档案暂定代号“黑色雨伞”，危险等级A级；若进入城市，风险可能升至S级。杨间计划三日后与冯全、黄子雅、熊文文处理，结果待后文。（原文回跳第970章、原文回跳第974章）

## 原文回跳第980-984章·嵌套雨域与同化风险

黑雨伞打开后形成伞形阴雨鬼域，停雨时撑伞鬼不可见、下雨时才会出现。棺材钉压住一只表层鬼会引出大量同伞鬼，说明表层鬼并非唯一源头；柴刀也只能肢解其单独个体。（原文回跳第980章至原文回跳第983章）

每把黑伞可令持有者进入更深一层雨域，旧伞会在更深层的雨水中逐渐损坏，必须夺取该层鬼手中的新伞。雨域越深，撑伞鬼数量越少、威胁越高；雨水、积水和湿气会触发袭击，并将活人逐步同化成披黑纱、撑黑伞的鬼。（原文回跳第983章、原文回跳第984章）

杨间独入第三层后遭同化，以第七层鬼域重启自身，被雨域排斥回第二层并带回第三层黑伞。高层黑伞可免受低层鬼袭击的完整规则、雨域层数与真正源头待后文。（原文回跳第984章）

## 原文回跳第985-986章·行动暂缓与雨区封锁

杨间确认高层黑伞可抵御低层雨水，并可能将厉鬼送入更深雨域，具有关押价值；但第四、五层风险未知，遂中止本次行动。冯全、黄子雅、熊文文保留经验，后续以黄金鞋隔绝积水、白色鬼烛引鬼作为准备方向。（原文回跳第985章）

杨间用鬼域隆起地貌围住雨区，冯全等人定期以白色鬼烛把鬼引回封锁区域，避免其游荡离开。事件仍未解决，暂待杨间处理鬼邮局后再行动。（原文回跳第985章、原文回跳第986章）

## 原文回跳第1113章·鬼域开始向南移动

黑色雨伞事件原由冯全监视，后改由童倩、王勇接手。白色鬼烛可短暂吸引、固定其范围，但烛火熄灭后鬼域开始向南移动数十公里，疑有目标在远方吸引；杨间决定完成大澳市行程后再处理。（原文回跳第1113章）
