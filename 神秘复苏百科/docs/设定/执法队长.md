# 执法队长

王小明提出的总部队长约束方案：从队长中选出足以召集、制约乃至处决失控队长的人，以结束队长各自为政的局面。总部属意杨间担任，并要求他促成队长会议召开。（原文回跳第1202章）

若杨间接受，总部承诺将所有关押厉鬼、灵异物品、灵异道具及队长以下驭鬼者调度权交由他支配，限制是不主动释放关押厉鬼；王小明还承诺会告知人皮纸秘密。杨间认为该位置风险极高，暂定当晚答复。（原文回跳第1202章、原文回跳第1203章）

杨间最终将权力、义务和自身生存风险重新权衡，在六点前形成答复，但内容尚未写明。（原文回跳第1209章）

杨间接受职位，但仅在必要时承担约束队长职责，不介入总部日常决策。其立即取得三日召集期限、总部灵异资源调用权，并开始逐一上门邀请队长。（原文回跳第1210章、原文回跳第1211章）
