# 静悄悄事件

静悄悄事件发生在一座被整体疏散、断电封锁的小县城。厉鬼以无眼、无鼻、无口的淤青女孩显现，关键字为“鬼”：说出该字会令其在路灯阴影下出现并袭击。（原文回跳第1218章、原文回跳第1221章）

县城内有大批缺失眼、口、鼻的鬼奴汇聚于居民楼，疑因楼内活人触发规律而被吸引。杨间以炉火焚楼、救出三名记者，但三人离城后仍遭无眼女孩袭击，显示事件未解决。（原文回跳第1218章、原文回跳第1219章）

曹洋曾在县城点燃白色鬼烛并处理其中一只鬼，却被另一只针对自身的未知厉鬼盯住，只能借两鬼制衡躲藏；其称该目标可定为X级。（原文回跳第1219章）

该鬼具唯心特性：棺材钉、柴刀和沉湖均可压制、肢解单个显现体，却无法阻止下次说出关键字后另一女孩再现。卖货郎收走一具显现体后，曹洋暂时摆脱交易追索，但事件源头仍未解决。（原文回跳第1222章、原文回跳第1225章）

卖货郎本身会隔绝接近的厉鬼。杨间以鬼影将静悄悄显现体踢至其货箱旁，卖货郎收货成功；若关键字再次触发，新显现体仍会出现。（原文回跳第1225章）
