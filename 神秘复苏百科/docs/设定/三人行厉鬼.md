# 三人行厉鬼

亡魂道路上出现的三只相同女性厉鬼，彼此牵手同行，面容各仅保留一组五官：死灰眼睛、红唇或惨白耳朵。（原文回跳第1289章）

三鬼可瞬间贴近目标、以手臂围成封闭空间。被困其中的刘奇和萧阳无法借鬼雨或摇晃鬼脱身，且眼耳口流血、生命气息迅速衰减；红色鬼烛也无法点燃。其完整杀人规律、能否关押及刘奇二人能否脱困待后文。（原文回跳第1289章）

#### 原文回跳第1290-1292章·配合被破，三鬼均被压住

萧阳死于围困，刘奇则以转移诅咒勉强维持。杨间赶到后，先用棺材钉压制其中一鬼破坏牵手围困，再以鬼火遮蔽眼鬼倒影、柴刀断首，并以鬼寿衣挡住红唇鬼亲吻，最终将最后一鬼烧成焦黑尸体。（原文回跳第1291章、原文回跳第1292章）
