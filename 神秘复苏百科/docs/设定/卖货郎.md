# 卖货郎

卖货郎是挑扁担、两端挂木箱的民国式诡异收货者，头部被黑布紧缠。它持有一张可收购指定厉鬼的清单，曹洋曾以清单上的厉鬼与其交易，换得帮助其生存的特殊物品或力量。（原文回跳第1223章）

交易失败时，卖货郎会将目标拉入货箱灵异空间，货箱内存在大量过往收购的厉鬼；钉住眼前卖货郎现象无法阻止货箱合拢。杨间和曹洋曾以鬼湖脱出。（原文回跳第1224章）

卖货郎收下静悄悄的一具显现体后暂不再追曹洋，但这不代表唯心的静悄悄源头已被永久收容。（原文回跳第1225章）

卖货郎有隔绝附近厉鬼的能力，曹洋将静悄悄引至其收货范围后，杨间以鬼影将其踢入货箱旁，卖货郎遂将显现体收走。交易仅维持暂时平衡：若有人再次触发关键字，静悄悄仍可能显现并令曹洋交易重新失败。（原文回跳第1225章）
