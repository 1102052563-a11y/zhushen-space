# 梦魇

梦魇是可将睡眠者拉入欧式城堡梦境的灵异，梦内驭鬼者失去灵异能力、成为普通人。骆胜和数名中外驭鬼者能进入该梦境，并借城堡结构隐藏源头、围困目标；其对梦境的掌控并不完整。（原文回跳第1132章、原文回跳第1133章）

传教士的录音诅咒可促使目标入睡，是进入梦魇世界的前置手段。黑狼狗随后使鬼梦的老家村庄、树林与梦魇世界发生碰撞，具体结果待后文。（原文回跳第1132章至原文回跳第1134章）

## 原文回跳第1135-1137章·与鬼梦相连后失守

黑狼狗在梦魇内可数量重现，击溃刘、骆胜等追杀者，并以灵异撞开城堡墙壁。凯丽作为梦魇驾驭者将逃亡者送回现实、自己躲入暗间；鬼梦村庄与梦魇城堡之间形成可往返通路，梦魇控制权受狼狗压制。（原文回跳第1135章至原文回跳第1137章）
