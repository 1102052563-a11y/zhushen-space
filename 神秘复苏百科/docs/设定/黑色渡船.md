# 黑色渡船

黑色渡船会在午夜抵达太平古镇废弃渡口。船上无船夫、仅有油灯，可沿鬼湖连接河道驶入脱离现实的灵异河流。（原文回跳第1064章）

登船须支付异常纸钱。杨间以七元纸币在船头油灯焚烧一部分后，五人小队获准通行，纸币余下部分变为三元；柳三推测船不向被判定为鬼者收取费用，队内疑有一人被船视作鬼。（原文回跳第1064章）

## 原文回跳第1065-1067章·承载灵异的关押船

渡船在中途渡口接入三只未显形厉鬼，船舱随即进水下沉。船承载的是灵异而非物理重量，队员丢弃灵异物品可减轻负荷；李军丢焦黑鬼臂、杨间丢遮脸黄纸、沈林丢黑玻璃瓶后，船暂时上浮。（原文回跳第1065章至原文回跳第1067章）

杨间推断纸钱是引鬼上船的诱饵，渡船会将满载厉鬼运至鬼湖沉没，以鬼湖压制厉鬼；鬼、纸钱、渡船和鬼湖构成民国遗留的关押体系。推断是否完整待后文。（原文回跳第1066章）
