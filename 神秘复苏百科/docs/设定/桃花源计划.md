# 桃花源计划

桃花源计划由张羡光谋划：让鬼邮局管理者驾驭鬼画，利用鬼画可无限扩张的世界把现实人类纳入画中，以此隔绝外界厉鬼、战争、灾害等风险。张羡光认为管理者不会死亡，便可长期维持鬼画稳定。（原文回跳第1250章）

该方案以所有人被纳入受单一管理者控制的灵异世界为代价。杨间等队长承认其逻辑存在可行处，却拒绝将数十亿生命押在张羡光与鬼画灵异上，双方交涉破裂。（原文回跳第1250章）

张羡光为实施计划，曾三次完成鬼邮局最终送信：首次离开留下油画，第二次复活画中自己，第三次成为管理者；后者留守邮局，本体的主要灵异力量则转给复活的另一个自己。（原文回跳第1250章、原文回跳第1252章、原文回跳第1255章）

计划执行中，何月莲成功继承鬼画女子灵异并保持意识。直接杀死她会导致鬼画完全失控，故总部一方暂不处决，等待其是否拒绝张羡光安排；计划未可视作完成或终止。（原文回跳第1264章）
