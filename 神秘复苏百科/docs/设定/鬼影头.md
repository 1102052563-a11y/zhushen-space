# 鬼影头

## 概述

鬼影头是杨间在大川市人头超市中暂定的厉鬼代号。其表现为带五官轮廓的黑色人头影子，能侵蚀活人意识、把大量受害者改造成无影的拼接鬼奴，并借不同鬼奴共享记忆、发声和移动。杨间在关押后确认它是自身无头鬼影缺失的头部拼图，但完整拼合后的意识侵蚀及能否安全驾驭仍未确认。（原文回跳第798章、原文回跳第799章、原文回跳第805章）

## 已知表现

鬼影头控制的鬼奴身体没有影子，脑袋和身体可被拆装替换；人头超市储存大量新鲜人头，腐败头颅会被更换。鬼奴能维持部分活人身份、记忆与社会行为，白天甚至可伪装成负责人、机场职员、服务员和司机，但其行为常有呆滞、无影和头身不协调的破绽。（原文回跳第794章至原文回跳第798章）

源头会通过不同鬼奴回答问题，声音在多人间跳跃，显示其可共享受侵蚀者的记忆和语言。在超市中，它声称“身体烂掉了”“身体就是你”，表明会持续寻找新鲜身体；但这是其借鬼奴表达的内容，不能直接视为完整杀人规律。（原文回跳第799章）

## 影子媒介

杨间发现开灯会照出活人影子，而鬼奴没有影子。鬼影头在灯光下更容易锁定活人，并曾借一具鬼奴脚下的人头影子接近杨间无头鬼影，意图把两段影子拼接为完整形态。杨间、李阳由此判断影子是其重要入侵媒介，但“被照出影子”是否就是唯一触发条件、黑暗中它如何移动均未确认。（原文回跳第799章）

李阳以体内女尸鬼拉扯人头影子，曾短暂阻止其与杨间鬼影拼接；源头随后熄灯、借鬼奴人潮离开。该过程证明影子可被其他灵异干扰，却不表示女尸鬼能够长期关押或克制鬼影头。（原文回跳第799章）

## 李乐平的失败尝试

李乐平自称曾尝试驾驭鬼影头，并在驾驭当天以自身另一只鬼的遗忘能力抹去相关记忆，试图让意识侵蚀一并消失。尝试失败后，鬼短暂控制其身体、侵蚀两名队友并窃取其身份信息；李乐平醒来后逃至明月小区躲避。该叙述来自电话，杨间尚未亲自确认其真实性。（原文回跳第800章）

## 关押现状

熊文文在大川市机场预知郭幽已受鬼影头侵蚀。杨间观察到郭幽前后影子异常、头部黑影有五官轮廓后，以棺材钉钉住地面影子；影子随即从地面浮起成黑色人头并失去活动。郭幽因维持意识的灵异被切断而死亡。该次说明棺材钉可以限制鬼影头，但钉下目标是否为全部源头、其他鬼奴是否会恢复以及棺材钉拔出后的后果待后文。（原文回跳第804章）

## 出处

## 原文回跳第819章·棺材钉拔除后与无头鬼影拼合

杨间为应对301室失控风险，主动从箱中拔出棺材钉，让鬼影头回归无头鬼影。黑影在其脚下扩散、无头鬼影长出头部轮廓，拼图完成后恐怖程度和修复速度明显上升，但也立刻反向侵蚀杨间意识。杨间依靠已开启的八音盒与其对冲，驾驭能否成功待后文。（原文回跳第819章）

#### 原文回跳第820-824章·拼合后失控，暂被棺材钉压住

完整鬼影将大川市大量受害者记忆灌入杨间意识，试图取得身体控制；八音盒令其未被吞没，却一度失去行动能力。柳青青递来棺材钉后，杨间将钉子钉入地面鬼影，令完整鬼影暂时沉寂、恢复身体控制。（原文回跳第820章、原文回跳第822章）

鬼影受钉压制仍与杨间鬼眼互相牵连，令六层鬼域持续时间显著延长；但棺材钉一旦取出，意识侵蚀可能继续。杨间尚未完成稳定驾驭，鬼影头本体也未被重新分离。（原文回跳第823章、原文回跳第824章）
