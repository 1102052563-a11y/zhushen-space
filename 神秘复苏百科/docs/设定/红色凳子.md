# 红色凳子

红色凳子是侵入宁安大厦的未知灵异事件所产生的红色长木凳。木凳本身是连接媒介，不是源头厉鬼；它会无声出现在过道、电梯、楼梯和出口，干扰驭鬼者鬼域并逐渐增多。（原文回跳第860章、原文回跳第861章）

## 已知规律

- **同坐显鬼**：活人坐上红色凳子后，才能看见同坐的源头鬼。源头鬼无法被普通视野、鬼眼、棺材钉或柴刀直接触及，红色凳子是人鬼接触的唯一已知媒介。（原文回跳第862章、原文回跳第863章）
- **压制与杀人**：坐下者下半身及体内鬼会被压制。源头鬼随后可杀死活人，杨间作为异类仍被杀至失去心跳、出现尸斑，只因意识寄于鬼影而未彻底消失。（原文回跳第863章）
- **媒介破碎不等于源头消失**：杨间遭袭后红色凳子自行破碎，但新的木凳仍持续出现，说明破坏媒介不能关押源头鬼。（原文回跳第863章）

## 当前风险

宁安大厦内已出现电梯塞满木凳与尸体、大厅尸体集体让出同坐位置等升级迹象。杨间判断厉鬼正在复苏，木凳数量和杀人规律可能继续变化；普通人若尝试坐下极可能死亡。（原文回跳第864章）

## 原文回跳第865-869章·以完整鬼影逐条破坏媒介

鬼童试图穿过大厅凳子封锁，却在门口无路可走，表明红色凳子形成的路线对鬼童也有高危限制。杨间令完整鬼影逐条坐上木凳，让源头鬼袭击鬼影；鬼与鬼冲突使媒介木凳和其上尸体失去灵异支撑、相继碎裂，开出一条离开大厦的通道。（原文回跳第866章）

这只是暂时清除路径上的媒介，并未关押源头鬼；宁安大厦仍熄灯、受灵异侵蚀。杨间命冯全留守观察扩散，童倩、黄子雅协助封锁周边，红色凳子事件后续风险未解除。（原文回跳第866章）

## 原文回跳第875-876章·替死娃娃冲突后的暂时关押

杨间让病人张志东坐上最后木凳、以其鲜血绑定替死娃娃，迫使源头鬼同时遵守“杀张志东”与“杀替死娃娃”两条冲突规则。其他木凳媒介随之全部消失，源头鬼仍坐在最后木凳、陷入挣扎后的特殊平衡；杨间带走这条木凳及其上鬼影，宁安大厦事件暂时解决。（原文回跳第875章、原文回跳第876章）
