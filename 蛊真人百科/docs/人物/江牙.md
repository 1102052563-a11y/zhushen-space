# 江牙

## 简介

江牙是古月山寨的正式蛊师。第12章傍晚，他与一名未具名女同伴在山寨唯一的客栈饭堂角落同坐。江牙身材高瘦、面皮苍白，穿深蓝武服、宝蓝头带和竹芒鞋；腰系镶有刻着黑色“一”字铜片的青布腰带。该服饰与铜片表明他是一转蛊师，方源从其散发的真元气息判断，他应是一转高阶。（第12章）

原文还通过方源判断交代，江牙已有二十多岁而仍只到一转高阶，资质应为丁等，比丙等方源更低；他很可能只是后勤蛊师而非战斗蛊师。此为方源依据年龄、修为和真元气息作出的判断，江牙本人未说明资质和职务。（第12章）

## 能力

- 一转高阶蛊师：江牙的腰带铜片刻“一”字，且方源感到其真元气息应为一转高阶；本批未展示其具体蛊虫或杀招。（第12章）
- 身份威慑：他仅凭正式蛊师身份和言语，就使六名猎户由醉后叫嚣转为惊惧赔罪，体现蛊师与凡人间的地位和力量差异。（第12章）

## 经历

#### 第12章·客栈压迫猎户

客栈饭堂内，六名猎户因被角落的江牙出言嘲讽，硬着头皮花两块元石买下一坛青竹酒。江牙随后现身，先以“练手”相逼，见猎户认出自己是一转蛊师后，又提走酒坛闻酒。他没有接受猎户主动赔罪，反而摔碎酒坛，指责他们这些凡人敢花两块元石喝酒、是在其为元石发愁时向他炫富。

猎户们惊惧地交出零碎元石，最大一块不超过四分之一；江牙并未收取，转而扫视饭堂，令猎户和独酌老人避开目光。他临走前警告众人不得再喝青竹酒。女同伴开口称其为江牙，并劝他教训到此为止、不要为难凡人；江牙因同伴劝阻而回到座位。（第12章）

#### 第12章·与方源的短暂对峙

江牙刚放话禁止饮青竹酒，方源便取出两块元石要求店小二上酒。江牙认为此举在拆自己台，转身以阴冷目光盯住方源；方源坦然对视，没有回避。江牙感知到方源身上的真元气息，随即改变态度，称其为“学弟”。方源点头后带酒离开，二人未动手，也未形成进一步约定。（第12章）

#### 第23章·经营草人傀儡小铺

江牙在学堂蛊室隔壁出售草人傀儡。面对七名还价学员，他称每具三块元石且仅余七具，又向方源表示可留一具；方源拒绝后，其他学员担心缺货而停止砍价购完七具。江牙随后称另有一具“压箱底”继续推销，方源仍未购买，改买十片月兰花瓣。江牙对同为蛊师的方源维持友善态度，与其在客栈面对凡人猎户时的傲慢形成对比。（第23章）

## 关系

- 未具名女同伴：二人同坐客栈，女同伴以江牙之名劝其停止为难猎户；身份、关系不详。（第12章）
- [方源](方源.md)：客栈中短暂对峙。江牙认出方源同为蛊师后收敛敌意，以学弟相称。（第12章）
