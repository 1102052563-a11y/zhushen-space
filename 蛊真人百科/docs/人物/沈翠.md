# 沈翠

## 简介

沈翠是方源的贴身丫鬟，姿容在原文中被称为中等，常穿绿衫、长袖长裤和绣花鞋，黑发配珍珠簪。她的母亲是舅母身边的沈嬷嬷，沈嬷嬷担任府中管家并受舅母信任，因而沈翠在府内亦有可倚仗的关系。（第3章）

## 经历

#### 第3章·清晨服侍与试探

开窍大典当天，沈翠在方源居所楼下等候，端来调好的温水供其洗脸，并以沾雪盐的柳条供其漱口。她随后替方源穿衣结扣、抚平衣褶，并多次以贴近举动示好。方源依据重生前经历，认为她既是舅父舅母安插的眼线，也因预期自己可能拥有甲等资质而试图攀附，希望成为侧室、由奴转主。

方源没有接受她的示好，直接令其退下。沈翠对其反常的冷淡感到奇怪和委屈，但受方源此时气势震慑，最终只答应后离开。此事未改变她的身份或归属，亦未显示其修行能力。（第3章）

#### 第9章·转向方正

方正同意过继后获舅父舅母优待，沈翠在其房外通报热水已备，随后带着媚意进入房中行礼。原文直接将她的态度与方正甲等资质相连，称方源仅丙等而方正甲等，攀附方正才是“大富贵”。她由此前试探方源转而向方正示好，显示其追逐的对象随兄弟地位逆转而改变。（第9章）
