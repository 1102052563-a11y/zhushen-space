# 贾富

## 简介

贾富是本次进入古月山寨商队的领头人，姓贾名富，拥有四转修为。他为中年人，圆饼麻子脸、身材肥胖，盘坐于宝气黄铜蟾头上率队入寨。（第39章）

## 经历

#### 第39章·率商队抵达古月山寨

商队因途中遭遇幽血蝙蝠、在绝壁山又遇山雾而迟至五月才到青茅山。贾富乘高二米五的宝气黄铜蟾进入古月山寨，货物以麻绳固定在蟾背；其后还有黑皮肥甲虫、驼鸡、山地蜘蛛、翼蛇和多种驮货蛤蟆。古月博以族长身份亲自迎接，双方互称兄弟并维持和气贸易关系。（第39章）
