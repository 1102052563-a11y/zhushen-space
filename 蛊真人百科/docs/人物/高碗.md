# 高碗

## 简介

高碗是漠之分家的中年家奴，脸色蜡黄、吊梢眉，身材高大且肌肉发达，双臂有大量伤疤。他虽非蛊师，却长期练拳脚，处于凡人武艺巅峰；方源判断其力量、敏捷、承受力均超过自己这一十五岁一转初阶少年。（第31-34章）

高碗仗漠家势力寻找方源，又受漠颜命令守在学堂宿舍外。他误判一转初阶月刃只能造成浅伤，最终未识破方源已有中阶真元，成为方源为保秘密而杀死的对象。（第32-35章）

## 能力

- 凡人拳脚：高碗苦练拳脚，左前臂坚硬如铁板，能在战斗中挡开方源指击；活动开后体力和出拳速度明显胜过方源。（第34-35章）
- 生擒意图的限制：他想生擒方源、给其苦头，却不敢杀害古月族人，因这会引来漠家清理门户；此顾忌使方源在近战中一度压制他。（第34章）

## 经历

#### 第32-33章·寻人、误判与看守

高碗以漠家大小姐找方源算账为由，在客栈威胁方源，并认为自己壮年拳脚可压制刚开窍少年。漠颜到场后，他跪地谄媚请安；方源利用孪生相貌戏耍漠颜，使众人一度不确定其身份。漠颜受宿舍规则所限离开时，命高碗在门外死盯方源。高碗在潮湿寒冷夜里通宵守候，心中叫苦。（第32-33章）

#### 第34章·与方源近战

方源温养空窍、吸收三块元石并把元海精炼为中阶真元后出门。高碗试图抓其赴漠颜处认错，双方交手；方源先戳其腰际未遂，发现其拳脚与体格优势后拉开距离。高碗对方源狠辣攻击要害感到后怕，仍想凭体力和生擒意图取胜；方源则不留手，攻击眼、喉、下巴、后脑、裆部和腰侧，使高碗因顾忌杀人而一度落于下风。（第34章）

#### 第35章·月刃斩首

方源体力渐弱，高碗以为学堂内不能动月光蛊，试图言语打击。方源却催动中阶真元发射月刃，高碗以双臂硬挡，前臂被深切至可见断骨；他惊觉伤害超过初阶月刃预期后逃跑求救。侍卫赶来但只旁观，避免高碗反伤方源。

失血使高碗减速，方源追上后连发两记月刃命中其脖颈，斩下头颅。高碗身躯仍奔出十米才倒地，至此死亡。方源因尸体伤口可能暴露自己中阶真元与酒虫秘密，向侍卫要刀，拖着无头尸体离开，后续处置本批未写。（第35章）
