# 花酒行者

## 简介

花酒行者是数百年前活动于青茅山一带的五转蛊师，古月族人称其为魔道采花大盗。古月一族流传的版本称他在山寨作案、被四代族长击败后偷袭致族长重伤，最终被族长击毙；但第15章花酒行者遗藏内的留影呈现了不同经过：四代族长先在酒宴中试图以毒蛊害他，战败求饶后又以月影蛊暗算，最终反被花酒行者一拳击杀。（第7、13、15章）

留影与遗藏残留物显示，花酒行者在杀死四代族长并击退家老后，已受月影蛊拖累；他逃至山壁秘洞，催发生长酒囊花蛊和饭袋草蛊以供疗伤和生活，但最终仍被月影蛊拖累而死。具体死亡时间不详。（第14-16章）

## 外貌·性格

留影中的花酒行者双目细长，光头无发，穿粉色长袍，宽袖随风，衣襟领口敞开并露出结实白皙的胸肌。他自称以花酒为名、不会轻易中酒中毒蛊；面对四代族长的求饶和家老围攻，他言辞轻蔑、行动激烈。其对四代族长背叛酒宴交易极为愤怒，也拒绝在元海受限后屈从为奴。（第15章）

## 能力

- 五转修为：古月一族传说和留影均将花酒行者列为五转蛊师，曾与同为五转的四代族长交战。（第7、13、15章）
- 近身战力：在月影蛊限制元海真元后，他仍以一拳击中四代族长心窝，将其击飞并造成内脏碎裂；随后又迅速击倒围攻家老。（第15章）
- 独门毒蛊：留影中他称四代族长中了其独门毒蛊，只有自己有对应解蛊；具体蛊名和效果未详。（第15章）
- 酒虫与供给蛊：其遗藏内有酒虫，以及已枯死的酒囊花蛊、饭袋草蛊。二者灌注真元后可分别产出花蜜酒和米饭，推测曾用于其生活供给，但原文未明确归属过程。（第14章）

## 经历

#### 第13-14章·遗藏被方源寻得

方源为寻找酒虫，在青茅山竹林以两块元石购得的青竹酒作诱饵。酒虫受酒香吸引后饮至醉态，方源没有立即捕捉，而是跟随其飞行路线，穿过竹林、溪流和河滩，抵达瀑布冲刷出的巨石缝隙。方源在缝隙深处进入约八十平方米的隐秘空间，先收下睡熟的酒虫，再拨开酒囊花蛊和饭袋草蛊的枯藤死根，找到包裹其中的一具白骨骷髅，并确认其为花酒行者。（第13-14章）

#### 第15章·留影中的四代族长之战

秘洞石壁出现光影。留影显示花酒行者原本欲以元石购买古月一族月兰花，却被四代族长假意设宴并在酒中下毒蛊；花酒行者未中毒，击败对方。四代族长求饶，表示愿吃奴隶蛊、每周提供三十斤月兰花瓣和三千枚元石，换取花酒行者定期解毒。花酒行者接受按期供给的提议，却在言语中蔑视对方。

四代族长趁近身时以四转月影蛊限制花酒行者元海真元，反要求对方投降为奴。花酒行者暴怒冲击，一拳击中四代族长心窝，使其吐出夹杂内脏碎末的鲜血后死亡。旁观家老围攻，花酒行者迅速将其打至死伤倒地；正要继续时腹部突发异状，他留下日后再来收拾的威胁并遁入山林。此留影与古月族内的英雄传说相反，说明历史叙述由获胜一方保留。（第15章）

#### 第16章·遗藏残余与死亡原因

方源搜查遗骸后仅找到十五块元石、死去的花草类蛊、酒虫和石壁中的留影存声蛊。他据花酒行者先与同阶四代族长激战、再与近十位家老交战的经过判断，其蛊虫大量消耗；逃入秘洞后为疗伤催生酒囊花蛊和饭袋草蛊，却仍被月影蛊拖累致死。三百年间其余蛊虫均已死亡，酒虫靠酒囊花蛊勉强存续，直至食源枯竭才外出觅食。（第16章）
