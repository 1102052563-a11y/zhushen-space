# 古月漠颜

## 简介

古月漠颜是古月漠北的亲姐姐、古月漠尘的孙女，已为二转中阶蛊师。她第31章完成家族侦察任务归寨，得知弟弟两次在学堂大门被方源击昏后，表面答应祖父不干预小辈竞争，内心却决定按自己的方式保护弟弟。（第31章）

她身材高挑，穿蓝色武服、赤色宽边腰带，腰带铁片刻“二”字；面容因马脸特征而仅算中等。长期任务使其带有风霜气，进入客栈时以二转身份形成明显威势。（第32章）

## 能力

- 二转中阶蛊师：赤色腰带和刻“二”字铁片表明其二转身份；本批未展示具体蛊虫和战斗招式。（第32章）
- 侦察任务：曾受家族委派外出十余天侦察狼巢，判断来年将有狼潮，约三只雷冠头狼。（第31章）

## 经历

#### 第31章·返寨与狼巢侦察

漠颜从十余天侦察任务归来，看到弟弟练拳且脸有伤，向祖父追问后得知漠北两次被方源打昏。她报告狼巢接近满员，来年必有狼潮、约有三只雷冠头狼。漠尘认为三寨可各自分担一只，压力尚可，并要求她不要插手漠北与方源的竞争，称失败能磨炼男人、以大欺小会破坏漠家规矩。漠颜口头答应，实际另有打算。（第31章）

#### 第32-33章·客栈寻人至宿舍受阻

漠颜派家奴高碗找到方源，亲自到客栈以弟弟受辱为由威胁教训。方源故意反问谁说自己是古月方源，使漠颜怀疑他可能是甲等方正；她随其至学堂宿舍，才发现对方从未否认身份。漠颜想入内抓人，却受学员宿舍不得擅闯、擒拿学员的族规限制。

方源故意敞门、暴露后背并让她动手，使漠颜更顾忌族规和家族牵连。她骂而不得、守而无果，最终离开并命高碗留守。其后本批未再出现，高碗与方源的冲突亦未显示她是否知情。（第32-33章）

#### 第37章·禁闭与停止追究

高碗被方源杀死、尸体又被切碎送到漠家后门后，漠颜因愤怒想再次抓方源。漠尘指出她此前介入小辈争斗已坏规矩，且方源的碎尸盒同时表达息事宁人与若继续追究便公开闹大的威胁。漠颜受罚禁闭七天，并被命令此后不再找方源麻烦。（第37章）

## 关系

- 古月漠北：亲弟弟。她因弟弟被击昏而寻方源，但祖父要求她不直接干预。（第31章）
- 古月漠尘：祖父。漠尘将她的护弟冲动与漠北的成长竞争区分处理。（第31章）
- [方源](方源.md)：因漠北之事寻其麻烦，却被方源利用宿舍规则制约。（第32-33章）
- 高碗：漠家家奴，受命留在宿舍外监视方源。（第32-33章）
