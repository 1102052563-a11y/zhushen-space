# 留影存声蛊

## 来历与归属

留影存声蛊藏在花酒行者遗藏的石壁中。方源在第14章拨动枯藤、发现花酒行者遗骸时将其惊动；第15章起，石壁投出花酒行者与古月四代族长旧战的影像与声音。方源判断这是花酒行者布下的留影存声蛊，能够刻印并投射影像。（第14-16章）

本批没有显示方源捕获或炼化此蛊。它仍在遗藏石壁内反复播放同一段记录，现归属不详。（第16章）

## 能力效果

- 刻印与投射：可保存影像和声音，并在被惊动后向外投射。遗藏内所播内容包括四代族长酒中下毒、月影蛊偷袭、花酒行者击杀四代族长和击退家老的过程。（第15-16章）
- 食物与存续：以光芒、声音为食。山壁秘洞持续存在红光，入口石缝又联通外界，能传入小瀑布轰鸣，因此该蛊得以在秘洞中生存。（第16章）
- 消耗性：方源称其只能记录一次，属消耗型蛊虫；本批没有展示其是否还能再次记录。（第16章）

## 价值与使用记录

第16章，方源搜遗骸仅得十五块元石、数只死蛊和酒虫，判断真正更有价值的是石壁不断播放的内容。影像能证明古月一族公开族史不实，方源认为青茅山其他山寨高层可能愿意出比古月家族奖赏更高的价格购买此证据；但他尚未交易，也未向家族报告遗藏。（第16章）

## 现归属

仍嵌于花酒行者遗藏石壁，方源知晓其存在与价值。（第16章）
