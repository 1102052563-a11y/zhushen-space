# 酒虫

## 来历与归属

酒虫是一转蛊虫，生活以酒水为食。方源从前世记忆得知，花酒行者遗藏中有酒虫，且该虫将在未来因一名醉酒族人散发酒香而现身、引人发现秘洞；重生后，方源连续购酒并在寨外散发酒气，希望抢先引出它。（第7-8章）

第13章，方源以两块元石购得的青竹酒在未探索的竹林多处滴洒，终于见到酒虫贴在青矛竹上。第14章，他等待酒虫醉饮后跟随其飞行路线，进入瀑布后的巨石缝隙和秘洞；酒虫在花酒行者遗骸旁的死根上睡熟，被方源收入怀中。第20章，方源以春秋蝉气息摧毁其残余意志，炼化完成；酒虫进入其空窍。（第13-14、20章）

## 形态与能力

- 外形：体型如蚕宝宝，胖乎乎，通体散发珍珠般白光；在月下贴于青矛竹时，方源将其看作一点雪影或浑圆珍珠。（第13-14章）
- 飞行：酒虫可凌空飞行，飞行时团成一团，像白色小汤圆；正常速度极快，方源徒步难以追上。（第14章）
- 食性与醉态：以酒水为食，受到青竹酒强烈吸引；饮酒后会醉醺醺、飞行速度降至平常一半，成为方源能够追踪的关键。（第14章）
- 价值：虽为一转蛊虫，方源称其价值高于部分二转蛊虫，作为本命蛊也比月光蛊更好；具体效用尚未在本批展示。（第14章）

## 使用记录

#### 第13章·青竹酒引虫

方源在竹林分多处倾倒青竹酒，最后一次将余酒全数倒进草丛。起初他准备认定失败，月光重现后却见酒虫贴在青矛竹上。此时酒虫尚未与方源接触，仅被酒香引来。（第13章）

#### 第14章·引路至遗藏并被捕获

酒虫在方源后退两百步后飞至酒液草丛，连续饮用花骨朵和花蕊中的酒露。方源等其吃饱、醉态明显后才跟随；酒虫飞至距地面约一米五处，带方源抵达巨石缝隙。秘洞内，它栖于花酒行者遗骸旁的枯死根团并睡去，方源先将它收入怀中，再发现遗骸。（第14章）

## 现归属

方源已炼化，存于其空窍青铜元海。（第20章）

#### 第17-20章·反噬后炼化完成

方源估算炼化酒虫至少要十一块、最多十六块元石，耗两天两夜并用十二块元石后，酒虫仅约炼化十五分之一。其残留的花酒行者意志极强，甚至孤注一掷反噬方源；春秋蝉因此显形，气息瞬间击溃酒虫意志。第20章，方源再次释放春秋蝉气息，使酒虫残存意志不敢抵抗，随即以青铜真元将其完全炼化。炼成后酒虫听从方源指令进入空窍，并主动远避春秋蝉。（第17、19-20章）
