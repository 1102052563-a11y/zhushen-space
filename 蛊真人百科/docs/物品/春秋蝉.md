# 春秋蝉

## 来历与归属

春秋蝉是方源在重生前炼成的蛊虫。围攻方源的正道各派在第1章要求他交出此蛊，并将其视为方源必须交出的目标。方源自述，为炼成春秋蝉，他曾杀害数十万人、历尽艰辛；围攻者则指控他为炼蛊杀了千万人的性命。两处数字来自不同叙述立场，本批原文未对具体总数作统一确认。（第1-2章）

方源在必死局面中发动春秋蝉并自爆，成功回到五百年前的古月山寨。重生后，他明确发现春秋蝉没有随自己一同带回，因此本批末该蛊不在其现有持物中；他仅表示自己前世既能炼成，今后仍可再图炼制。（第1-2章）

## 能力效果

- 「逆转时光」：方源称春秋蝉的作用是逆转时光，能令使用者逆流光阴、回到从前；其重生结果成为本批唯一的实际使用记录。（第1-2章）
- 排名：方源称春秋蝉在十大奇蛊中名列第七。（第1章）
- 使用代价：每次使用必须付出生命，并将整个身躯和全部修为作为驱动力量；使用前无法确认传说是否真实，因此持有者不敢随意试用。（第2章）
- 消耗性不明：方源推测春秋蝉可能是只能使用一次的消耗类蛊虫，但本批没有证实此推测。（第2章）

## 使用记录

#### 第1章·围杀中的发动

方源在山中遭正道群雄包围，已无生路。面对敌人交出春秋蝉的要求，他选择悍然自爆；紧接着叙事转至五百年前的青茅山，显示该蛊发动后令其重生。（第1章）

#### 第2章·重生后的确认

方源在古月山寨确认自己确已重生，故认可春秋蝉逆转光阴的效用；同时确认该蛊本体未随重生带回，现归属不详。（第2章）
