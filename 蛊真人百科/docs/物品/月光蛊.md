# 月光蛊

## 来历与归属

月光蛊是古月一族通过秘法培育的蛊虫，原文称其并非天然蛊虫、其他地方没有，是古月一族的镇族蛊虫和标志象征。学堂蛊室用一排白银盘存放一转月光蛊，供刚开窍少年选作第一只蛊虫。（第8章）

方源原本想以花酒行者遗藏中的酒虫作本命蛊，但在尚未找到酒虫的情况下，从蛊室中随意选取一只月光蛊作为保险。第10章他已开始炼化，但半小时仅炼化约十二分之一，故本批末该蛊仍未完全归方源控制，也尚不能确认其已成为本命蛊。（第8、10章）

## 形态与层级

- 外观：晶莹剔透、弯弯如月，如蓝水晶；重量近似薄纸，大小如寻常玉坠，可透见掌纹。（第8章）
- 层级：一转蛊虫。原文说明一转蛊师通常使用一转蛊，越级催动高阶蛊会付出惨重代价，饲养高阶蛊的消耗也可能超出低阶蛊师承受范围。（第8章）
- 自主意志：月光蛊是生灵，炼化者须以真元抹去其意志；受炼化时会反抗并驱逐侵入真元。（第10章）

## 炼化记录

#### 第8章·自蛊室选取

方源在蛊室的月光蛊盘中选取一只，放入口袋带走。他知道第一只炼化的本命蛊与蛊师性命交修，蛊虫死亡会重创蛊师；选择月光蛊并非其最优打算，而是酒虫寻觅未果下的保底方案。（第8章）

#### 第10章·第一次持续炼化

连雨三日阻断寻虫后，方源在房中调动青铜真元灌入月光蛊。真元使其月牙尖端出现青铜绿意，但月光蛊持续抵抗。十分钟时方源耗一成真元；炼化半小时后耗去三成、元海只余一成四，蛊体仅约十二分之一被炼化。方源停止供给后，蛊虫仍会将真元逐出，估计六小时可恢复原状，因此需一边补充真元一边持续炼化。（第10章）

## 现归属

方源持有，炼化未完成。（第8-10章）

第11章，方源估计自己以丙等资质炼化月光蛊，若该蛊意志较弱约需五块元石，若抵抗顽强则至少八块；他搬入客栈支付两块元石后仅剩四块，因此月光蛊炼化仍面临资源缺口。（第11章）

第20章，方源以春秋蝉气息压制月光蛊意志，几乎未受抵抗便将其炼化。炼化后该蛊未进空窍，而是在方源额头中间形成淡蓝色弯月印记；全过程不足五分钟，且未消耗元石。（第20章）
