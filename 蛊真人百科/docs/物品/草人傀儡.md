# 草人傀儡

## 来历与用途

草人傀儡是古月学堂用于月光蛊攻击训练、考核的目标。第22章，学堂家老让已炼成月光蛊的少年各对一具草人傀儡练习月刃；第24-25章的检查中，每名学员以三次月刃攻击草人，作为成绩评定依据。（第22、24-25章）

学堂蛊室隔壁的小铺也出售草人傀儡，供学员课下练习。江牙将每具售价定为三块元石，并称货源有限。方源从制作成本判断，草人傀儡连同真元投入的成本约一块半元石；他没有购买，因其前世经验足够，不需借傀儡反复练习。（第23章）

## 特性

- 练习目标：可承受月刃攻击，用于校正发射、方向和命中精度。（第22、24-25章）
- 自愈：草人不是普通草制人偶，而是一转草人蛊制成，具草木系轻微自愈能力；若只切出伤口，断裂草茎会重新生长并愈合。（第22章）
- 破坏条件：需砍成两截或造成彻底破坏才不能立刻复合。方源第25章以两记月刃连续命中颈部，令草人头颅掉落。（第22、25章）
- 价格：学堂旁小铺售价三块元石，本批无其他渠道价格。（第23章）

## 使用记录

#### 第22章·月刃初练

学堂家老以月刃切断十米外草人傀儡厚三十厘米的颈部，演示月光蛊攻击。少年练习时，多数月刃飞偏、消散或相撞；方源斜射一刃切开一具草人颈部大半，伤口随后复合。（第22章）

#### 第25章·月刃考核

古月漠北、古月赤城、方正均三次命中草人，伤口随后自愈。方源故意把第一刃射过草人头顶，后两刃连续命中同一颈部，最终斩下头颅，造成当场最显著的破坏效果。（第25章）

## 现归属

古月学堂与江牙经营的小铺持有多具，具体数量不详。（第22-23章）
