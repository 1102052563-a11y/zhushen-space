# 时间线

本页按章节顺序记录已完成批次的关键事件。

- **第1章**：方源在正道群雄围杀的绝境中发动春秋蝉并自爆，重生至五百年前的古月山寨；古月一族为开窍大典祭祀。（重生与修行起点确立）
- **第2章**：方源确认春秋蝉逆转时光的效用，决定先借家族资源提升修为；方正夜访兄长。（确定先修行、后取机缘的次序）
- **第3章**：方源遣退试探的沈翠，与方正前往家主阁参加开窍大典。（兄弟间长期失衡显露）
- **第4章**：古月漠北与古月赤城在花海中均获乙等判定，方源被点名测试。（开窍测试进入主角阶段）
- **第5章**：方源走至二十七步，形成元窍，开窍成功并判为丙等。（正式取得蛊师修行起点）
- **第6章**：方源确认丙等、元海四成四；方正走至四十三步，获甲等，族长决定亲自培养。（兄弟待遇逆转）
- **第7章**：学堂讲授蛊师九转并启动本命蛊炼化考核；方源继续寻找花酒行者遗藏中的酒虫。（修行与寻宝两线展开）
- **第8章**：方源从蛊室取得月光蛊作保底选择；方正以甲等身份前来传达舅父舅母召见。（方源的资源消耗加剧）
- **第9章**：方正同意过继，方源拒绝过继与独立门户方案；冻土夫妇谋划陷害方源。（父母遗产继承权受威胁）
- **第10章**：大雨阻断寻虫，方源开始炼化月光蛊并确认丙等真元恢复与资源劣势。（暂转入炼蛊准备）
- **第11章**：方源识破沈翠色诱构陷，放走沈翠后搬入客栈。（避开舅父舅母的直接陷阱）
- **第12章**：江牙以蛊师身份压迫猎户；方源购买青竹酒出寨。（以剩余资源孤注一掷寻酒虫）
- **第13章**：方源在最后未搜竹林以青竹酒引出酒虫。（花酒遗藏出现直接线索）
- **第14章**：方源跟随醉酒虫进入瀑布后的秘洞，捕获酒虫并发现花酒行者遗骸。（成功找到遗藏入口）
- **第15章**：秘洞留影展示四代族长暗算花酒行者反遭击杀的经过。（古月族史叙述被动摇）
- **第16章**：方源搜得酒虫、十五块元石及留影存声蛊线索，决定独吞遗藏。（修行资源暂获补充）
- **第17章**：方源开始炼化酒虫，发现其能精炼真元但残留意志极强。（本命蛊炼化受阻）
- **第18章**：方源与方正决裂，并取得五块半元石；冻土决定继续利用方正牵制方源。（兄弟关系正式破裂）
- **第19章**：酒虫反噬时春秋蝉显形，方源确认其为虚弱的六转本命蛊。（重生遗留的核心底牌现身）
- **第20章**：方源借春秋蝉气息炼成酒虫与月光蛊，率先完成学堂考核。（取得本届头名）
- **第21章**：方正炼成月光蛊却发现方源已领头名奖励，漠尘与赤练将结果归为运气。（兄弟竞争加深）
- **第22章**：学堂教授月刃；方源隐瞒一次精准命中，月刃考核设十块元石奖励。（攻击训练开始）
- **第23章**：方源核算三蛊养育成本并囤积五坛青竹酒。（资源压力持续）
- **第24章**：拳脚教头教授近战，月刃考核展开，漠北和赤城均三击命中。（考核竞争形成）
- **第25章**：方源以连续两记月刃斩下草人头颅，方正再受挫。（最佳表现待评）
- **第26章**：方源获十三块元石；学堂设中阶、班头及副班头激励。（资源竞争升级）
- **第27章**：方源以拳脚堵门击倒同学并索每人一块元石。（首次公开勒索）
- **第28章**：学堂家老默许有分寸的斗殴，方源收齐五十六块元石。（资金骤增）
- **第29章**：方源购二十坛青竹酒，并以酒虫炼出半成中阶真元。（启动中阶精炼）
- **第30章**：学员苦练拳脚后再遭堵门，漠北和赤城挑战方源均败。（对立持续）
- **第31章**：漠颜归寨，得知弟弟受辱后暗自寻方源麻烦。（漠家二转介入）
- **第32章**：方源以孪生身份戏耍漠颜，将其带至宿舍。（对方受规则制约）
- **第33章**：漠颜留高碗看守；方源以中阶真元温养空窍。（中阶修行推进）
- **第34章**：方源耗三块元石精炼真元后与高碗近战。（体格劣势显露）
- **第35章**：方源用中阶月刃斩首高碗，拖尸离去。（首次杀死当代人物）
- **第36章**：高碗死讯震动学堂，方源承认将尸体分尸送往漠家后门。（事件升级为分脉矛盾）
- **第37章**：漠尘以家族名誉为重，赔方源三十块元石并禁足漠颜。（漠家选择妥协）
- **第38章**：方源从人祖规矩故事推演各方立场，确认漠家不会继续追究。（以规则判断局势）
- **第39章**：贾富率商队进寨，方源进入临时商市寻找赌石机缘。（商贸期开始）
- **第40章**：方源进入赌石场，筛出六块可能藏有癞土蛤蟆的紫金石。（赌石准备完成）
