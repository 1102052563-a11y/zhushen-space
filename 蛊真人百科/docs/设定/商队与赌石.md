# 商队与赌石

## 商队贸易

南疆十万大山间山林险恶，猛兽和蛊虫众多，凡人难以穿行，个人至少需三转蛊师才有闯山资格。山寨经济与贸易因此困难，商队是主要贸易形式：以成群蛊师、凡人和驮兽结队，互助跨越山岭。（第39章）

贾富所率商队以宝气黄铜蟾、黑皮肥甲虫和多种蛤蟆等驮运货物。商队到寨后搭出帐篷和地摊，形成临时商市；对客栈、酒肆等本地商家而言，商队是年度重要收入来源。（第39章）

## 蛊虫沉眠与赌石

蛊虫缺食通常会饿死，少数会自我封印沉眠以求生：月光蛊可能褪为灰石、形成石壳；酒虫则会结为白色蚕茧。蛊师若意外唤醒其中活蛊，可能获利，因此各地流传赌石发财故事。（第40章）

赌石场出售外观疑似封存蛊虫的琥珀、化石和顽石。小型场十块石头约八九块为实心，即便开出蛊也多是死蛊；但开出活蛊通常可获利。石中蛊虫难以温和探测，选择只能靠经验、猜测、运气和偶然灵感，故被称为赌场。（第40章）

## 本批赌石场

方源进入的帐篷赌场占地约一亩，按柜台分为每块五、十、二十元石的不同价位。方源依据前世记忆，知道商队首夜有一块紫金石开出癞土蛤蟆；他从二十多块紫金石中按体积、石皮形态筛出六块候选，判断有八成把握目标在其中。交易与解石结果本批尚未发生。（第40章）
