# 蛊虫喂养

## 基本原则

蛊师修行不仅包括炼蛊和用蛊，也必须养蛊。蛊虫各有食物需求：有的吞食泥土，有的吸收星光，有的服用眼泪，有的吸食九天云气。食物不合或供给不足会影响蛊虫存续；花酒行者遗藏内的花草类蛊便因秘洞无阳光而逐渐枯死。（第16、23章）

蛊师理论上可炼化无限数量蛊虫，但实际通常只养四五只同等级蛊虫。主要原因是蛊虫品级越高，食物越昂贵或越难寻，养得过多会造成财力压力；即使养得起，蛊师真元和精力有限，也未必能有效使用。（第23章）

## 方源三蛊的食物

- 月光蛊：吞食月兰花瓣，每日早晚各一次，每次两片，即每天四片。一块元石可买十片花瓣；花瓣无存储手段时只能放五天。（第23章）
- 酒虫：以酒为食。一坛青竹酒价值两块元石，可支撑四天；若用浊酒或米酒，每天需数坛，不仅成本未必更低，也容易引人怀疑。（第23章）
- 春秋蝉：直接饮用光阴之河的河水维持生机。光阴之河无形无色、推动万物动作，流淌在每个生灵身边；方源认为此食物无需花费元石购买。（第23章）

## 成本与资源压力

方源核算月光蛊与酒虫的日常食物，平均每天接近一块元石，远高于凡人一家三口一月约一块元石的生活费。他在炼蛊、养蛊与生活消费后，资产从一度的四十四块半元石降至二十块；若无新收入，只能维持大半个月。（第23章）

蛊师还须为催动蛊虫消耗真元，并以元石恢复。普通学员为提高月刃熟练度需反复练习，甚至购买三块元石的草人傀儡；养蛊、练蛊、用蛊相互叠加，构成低阶蛊师的持续资源压力。（第22-24章）
