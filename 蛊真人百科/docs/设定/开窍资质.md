# 开窍资质

## 测试方式

古月一族在开窍大典中，将十五岁少年带至家主阁地下溶洞。测试者需淌过一条宽三丈有余的地下河，踏入对岸由家族培育的月兰花海；花海深处的灵泉因元气浓郁而形成无形压力。希望蛊化作光点投入测试者体内，帮助其顶住压力并向前行走，前进步数据此显示是否具备蛊师资质以及资质等级。（第4-5章）

希望蛊的光点会在体内汇聚于腹部。第5章方源行至二十七步时，光团在两肾中央炸开，形成元窍，即为开窍成功。原文将元窍视为踏上蛊师修行、获得长生希望的起点。（第5章）

## 分级标准

- 十步以下：没有修行资质。（第5章）
- 十步至二十步：丁等资质。（第5章）
- 二十步至三十步：丙等资质。（第5章）
- 三十步至四十步：乙等资质。（第5章）
- 四十步至五十步：甲等资质。（第5章）

第4章另以家族培养结果说明各等资质的通常前景：丁等经约三年培养可成为一转资深蛊师，是家族基石；丙等经约两年大多可成为二转蛊师，是家族中坚；乙等常被作为未来家老培养，约六七年可成为三转蛊师；甲等若出现，家族会倾斜资源细心关照，约十年可成为四转蛊师并具竞争族长之位的条件。这些是家族叙述的通常情况，非对每名测试者的保证。（第4章）

## 本批测试实例

古月陈博前进三步、古月藻榭前进四步，均被判无资质；古月漠北走三十六步、元海六成六，被判乙等；古月赤城也走三十六步并被判乙等。方源走至二十七步后开窍，根据步数标准属丙等，第6章确认其元海为四成四；方正走至四十三步，被判甲等。测试显示，并非所有族人均能修行；原文称一般十人中有五人能修行已属不错，而古月家族因先祖血脉的缘故比例可达六成。（第4-6章）
