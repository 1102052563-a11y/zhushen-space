# 一转中阶

## 境界位置

蛊师每一转大境界分初阶、中阶、高阶、巅峰四个小境界。一转初阶的真元为翠绿色青铜真元；一转中阶的真元为更凝练的苍绿色青铜真元。学堂家老宣布，未来三个月内率先晋升一转中阶的学员可获三十块元石，并拥有优先挑选第二头蛊虫的权利。（第26、29章）

学堂还以三个月后的中阶成绩设置一名班头、两名副班头：班头每七天得十块元石补助，副班头每七天补助五块。方正、漠北、赤城都把此竞争视作荣誉和地位争夺；方源则认为其本质是家族以资源和权位调动学员竞争。（第26章）

## 酒虫凝练路径

方源第29章以一成初阶真元灌入已炼化酒虫，酒虫将其化作酒雾；再以一成初阶真元融入酒雾后，原本一成真元只余半成，但转为苍绿色的中阶真元。即以两成初阶真元，可凝练半成中阶真元。（第29章）

方源元海容量为四成四。若将全部初阶真元转换为中阶真元，约需消耗近十八成初阶真元，故须用元石反复补充元海。酒虫使他在一转初阶时提前拥有中阶真元，但本批未写明其何时全数转换并正式达到中阶。（第29章）

第33章补充说明，初阶蛊师的窍壁为白色光膜，中阶蛊师的窍壁为水膜，高阶则为石膜。蛊师须不断消耗真元温养窍壁，使光膜转为水膜，方可完成初阶至中阶的晋升。方源第33-34章以酒虫所得中阶真元温养光膜，并以元石反复补满元海；是否已成功转为水膜，本批未明确。（第33-34章）

## 资源与竞争

元石是加快真元恢复和推进转换的关键。方源没有亲友资助，选择通过堵门收取同学元石来支撑酒虫精炼；漠北、赤城、方正则分别有分脉、祖父或养父母的支持。资质高者天然真元储量与恢复更优，资源会进一步放大速度差距。（第26-30章）
