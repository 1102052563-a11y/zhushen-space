# 元石

## 性质

元石是此世货币，也是天地精华凝结物。酒肆掌柜在第8章收取方源的元石碎块时，原文说明元石既用于衡量一切商品价值，也能被蛊师使用、帮助修行，兼具货币和商品属性；方源以地球黄金作类比，称此世可视为单一元石本位制，故元石购买力惊人。（第8章）

对蛊师而言，元石还可提供天然真元。蛊师将元石握于手中，可抽取其中自然元力补入空窍元海；因此元石不仅能支付酒、蛊虫相关花费，也是弥补资质差距、加快修行和炼蛊的重要资源。（第8、10章）

## 本批使用与数量

方源为用酒气引诱酒虫，连续七天每天购两坛酒，已把原先积攒的元石几乎耗尽。第8章他购酒时只取出仅剩的元石碎块；第9章舅父古月冻土给方源和方正各六块元石，供炼化蛊虫时补充真元。冻土还以两百块元石作为方源十五岁独立门户的资助，但方源拒绝。（第8-9章）

第10章，方源炼月光蛊半小时耗去三成真元，仅余一成四；他取一块元石吸收，约半小时便把元海补回丙等容量上限四成四。该实例说明元石可迅速恢复真元，但也意味着炼蛊会消耗有限储备。方源本批称手中仅有六块元石，且无古月漠北、古月赤城那样的长辈支持，因而不认为自己能靠资源赢得本命蛊炼化考核。（第10章）

## 与资质的关系

真元也可自然恢复：丙等方源每小时约恢复四分，六小时二成四；甲等方正每小时约恢复八分，六小时四成八。月光蛊能在六小时内驱逐约三成真元，故方正可主要依靠自然恢复持续炼化，方源却需吸收元石才能赶上驱逐速度。元石可以部分补足资质造成的持久差距，但数量是否足够仍决定实际效果。（第10章）
