# 月刃

## 定义与催发

月刃是月光蛊发出的淡蓝色远程攻击。学堂家老演示时，先以意念将额头月牙印记所代表的月光蛊移至掌心，再灌入真元，最后并拢五指、前伸挥掌，将凝聚蓝光发射为月牙形刃光。（第22章）

月光蛊是古月一族标志蛊虫，月刃因而是学堂少年最早学习的攻击方式之一。家老称此类远程催发方式亦可运用于其他蛊虫，但本批实际演示仅限月光蛊。（第22章）

## 威力与距离

学堂家老以三转白银真元催发月刃，切断十米外草人傀儡厚三十厘米的颈部，之后仍飞行约六米才消散。方源将月刃归为中远程攻击，因其有效攻击距离只有十米。（第22、24章）

一转少年发出的月刃在威力、稳定性与方向上均显著低于家老。初练时，有些月刃只现一瞬便消散，有些飞两三米即崩解，有些严重偏离。草人傀儡可自愈，故须连续精确命中同一部位或造成足够强的破坏，才能斩落其头颅。（第22、25章）

## 消耗与限制

催发一记月刃约消耗一成真元。丙等蛊师通常只能连续催发三四次便接近耗尽；第22章有丙等学员称自己元海只有三成八，最多能发三记。资质高者因元海和恢复较强，获得更多练习机会；其他人则须用元石补充真元。（第22章）

方源认为，一转新手使用月刃次数少、难形成持续有效打击，更适合作杀手锏和威慑，基础拳脚反而更持久可靠。这是方源基于经验的判断。（第24章）

## 本批实例

第25章考核中，古月漠北、古月赤城、方正均三发三中。方源先故意射偏一记，后两刃间隔不足半米、连续命中草人颈部，将其头颅斩落；学堂家老与学员一时无法判断是运气还是实力。（第25章）
