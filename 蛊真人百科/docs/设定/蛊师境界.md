# 蛊师境界

## 蛊师的定义

第7章学堂家老说明，此世有成千上万、数不胜数的蛊，分布在矿土、草丛乃至野兽体内。人类先贤逐步发现蛊虫奥妙；开辟空窍后，以自身真元喂养、炼化和操控蛊虫、从而达成各种目的的人，被统称为蛊师。（第7章）

蛊虫是蛊师实力的关键。蛊师可通过空窍元海中的真元催动、炼化蛊虫；初次炼化的本命蛊与蛊师性命交修，若本命蛊死亡，蛊师必遭重创。蛊虫本身也分为对应蛊师境界的九大层次，一转蛊师通常使用一转蛊，越级催动高阶蛊或饲养高阶蛊都会带来难承受的代价。（第7-8章）

## 九转与四阶

蛊师共有九大境界，自一转、二转、三转逐级至九转；每一转大境界又分初阶、中阶、高阶、巅峰四个小境界。开窍后的少年均是一转初阶。学堂家老称六转以上的每一人都是传奇，他本人对具体情况也不清楚；古月一族历史中未出过六转蛊师，但有过五转、四转蛊师。（第7章）

## 资质影响

- 丁等：元海约占空窍两三成，通常最高一转或二转。（第7章）
- 丙等：元海约占四五成，通常止于二转，少数可到三转初阶。（第7章）
- 乙等：元海约占六七成，可修至三转甚至四转。（第7章）
- 甲等：元海约占八九成，常被认为最适宜修行，可修至五转。（第7章）

资质同时影响真元恢复。第10章以方源、方正作比较：丙等方源每小时约恢复四分真元，甲等方正每小时约恢复八分；这使方正在持续炼化月光蛊时可较少依赖元石，而方源需额外补给才能维持炼化成果。（第10章）
