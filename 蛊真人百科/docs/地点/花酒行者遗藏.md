# 花酒行者遗藏

## 位置与入口

花酒行者遗藏位于青茅山后山瀑布分支附近。方源跟随醉酒虫穿过竹林、溪流和河滩后，看见其飞入一块倚靠垂直山壁的灰白巨石缝隙。该缝隙由瀑布分支的长期冲刷形成，细长水流像银色巨蟒般贴壁落下，平时形成的水帘遮住入口；连续三天三夜大雨后，入口前河滩积起浅水，流水源头即为巨石缝隙。（第14章）

入口缝隙最初可容两名成年人并行，方源入内后需对抗水压前行；深入数十步后水压减小，石缝却越来越窄，他只能侧身穿过黑暗。再行二十余步见红光、五六十步后抵达一条光缝，最终进入山壁内约八十平方米的空间。（第14章）

## 洞内构造与遗留物

洞内有不明来源的昏暗红光，四壁潮湿生苔，空气却干燥。大半石壁被枯藤和凋零花茎覆盖；方源辨认其为酒囊花蛊与饭袋草蛊。二者都是一转天然蛊，灌注真元后可分别产出花蜜酒与米饭，但洞内植株已经枯死。藤根在墙角结成死根团，酒虫栖息其上，花酒行者白骨骷髅则被死根枯藤包裹。（第14章）

第15章，方源试图继续剥开枯藤时，石壁出现带声音的留影，重现花酒行者与四代族长的旧战。留影显示古月一族流传的故事与当时实情不符：四代族长先在酒宴下毒失败，后以月影蛊暗算，反遭花酒行者击杀。此地因而不仅是遗物藏处，也保存了改写家族传说的证据。（第15章）

## 发现经过

方源此前不知遗藏位置，仅知道未来可能由酒虫引路。他在元石将尽、月光蛊炼化资源不足时，以青竹酒孤注一掷，等酒虫喝醉后没有立即捕捉，而是跟踪其飞行，由此找到入口并进入。此发现让方源取得酒虫并见到花酒行者遗骸；但第15章留影后洞内仍有未知威胁，遗藏内其他物品和机关本批尚未揭示。（第13-15章）
