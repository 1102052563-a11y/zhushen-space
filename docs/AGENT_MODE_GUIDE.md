# 🤖 Agent 正文模式 · 使用攻略

> 一句话：这是**另一种可选的正文生成方式**——AI 不再"一口气把正文吐出来"，而是像真人写手一样**带着工具干活**：先查你的角色档案、翻旧剧情、查世界书和原著资料库，在草稿区打磨，最后把成稿"发布"成正文楼层。不开它，游戏和以前一模一样。

---

## 一、它和普通正文生成有什么区别？

| | 普通模式（默认） | 🤖 Agent 模式 |
|---|---|---|
| 生成方式 | 一次调用，流式输出 | 多轮"思考→查资料→写稿→修订→发布"循环 |
| 设定一致性 | 靠每回合注入的档案快照 | 模型**主动查**它需要的档案/往期剧情/世界书，写谁查谁 |
| 正文格式 | 状态栏 / `<state>` 等照常 | **完全一样**（状态解析、演化、洞察全部照常跑） |
| 速度 | 快 | 慢（多次调用，典型一回合 4~8 次） |
| 花费 | 1 次调用 | **数倍于普通正文**（每次调用都带完整上下文） |
| API | 正文 API | **完全独立的 API**（不开就绝不调用它） |

**适合**：重头戏、群像戏、吃设定一致性的复杂回合、想让 AI 自我修订出更高质量正文的时候。
**不适合**：日常水段落、赶进度刷剧情（用普通模式更划算）。两种模式**随时一键切换**，同一个存档里想用哪个用哪个。

---

## 二、快速上手（三步）

1. **配 API**：设置 → 正文生成 → ⚡API 配置 → 拉到底部「🤖 Agent 正文模式」→ 勾选启用 → 在「Agent · 独立 API」里填接口（或勾「复用正文 API」偷懒）。
2. **选模型**：**强烈建议用支持函数调用（function calling）的模型**（GPT-4o / Claude / Gemini / DeepSeek V3 等及其中转）。不支持也能玩——协议选「自动」，它会自动降级成文本协议。
3. **发送**：像平时一样输入行动、点发送。输入框旁的 🤖 按钮会点亮；之后每回合正文都由 Agent 生成，再点一下 🤖 即可切回普通模式。

> 💡 API 优先级：`agent 接口路由`（可多选做故障转移）＞ 独立单配置 ＞「复用正文 API」。评稿子代理另有独立的 `agentReview` 路由（不配则用 Agent 主接口）。

---

## 三、运行中你会看到什么

1. **发送后聊天区先没有新楼层**——别慌，这是正常的。进度都在**输入框上方那条时间线**里：
   - `第 1 轮 · 调用模型…` → `✓ player_get`、`✓ chat_search`（它在查资料）
   - `✍️ 正文起笔（草稿流式预览）…` → 草稿开始**流式流进聊天区**（和平时的打字感一样）
   - `📤 已提交楼层（第 1 次）` → 正式成稿落地
   - `🧐 评稿人审阅成稿中…`（若开了评稿）→ `✅ 评稿通过` 或 `📝 评稿要求修订`
   - `✅ 运行完成` → 状态栏结算、各演化阶段照常开跑
2. **时间线可折叠/展开**，运行结束后保留最近一次记录供回看；「回合洞察」面板顶部也会记一行本回合的 Agent 概要（几轮、几次工具、耗时）。
3. **想停就停**：⏹ 停止按钮随时取消。已发布过的正文会保留在楼层里（但不结算数值）；一次都没发布就取消，则什么都不留。

## 四、独门功能

### 🎯 中途指引（运行中"喊话"）
Agent 干活时你突然想改方向？**直接在输入框打字、点发送**（按钮此时显示 🎯）——确认后这句话会作为"指引"插进它的下一轮，例如：
- 「基调改成阴郁一点，别写打斗」
- 「让白夜提前出场」
- 「结尾留个钩子，别把 BOSS 写死」

指引**不会成为聊天楼层**，只影响 Agent 接下来的行动；最多攒 8 条，没消化完的会在运行结束时丢弃（时间线会提示）。

### 💾 跨回合记忆（persist/）
Agent 有自己的小本本：它会把"未了的伏笔、约定、关系近况"记在 `persist/` 备忘里，**下一回合自动带上**。只有干净收尾（✅ 完成）才会保存改动；随存档走、新游戏清空。你也可以用中途指引让它「把 XX 记进备忘」或「删掉 XX 那条备忘」。

### 🧐 评稿子代理（AI 审 AI）
设置里开启后，Agent 每次想收尾，都会先把成稿交给**评稿人**独立审一遍（结构模块齐不齐、有没有答非所问、数值矛盾、流水账）：
- 合格 → 放行收尾；
- 不合格 → 修改意见回喂给它，**逼它修订后重新发布**才能收尾。

「最多评几轮」建议 1（每拦一次多花一次调用）。评稿建议挂一个**便宜但严格**的模型到 `agentReview` 路由；不配就用 Agent 主接口自审（也有效果）。

### 🗂 配置档案（一键切模式）
把当前整套配置（工具、轮数、协议、评稿、API、路由）存成档案，随时一键切换。推荐存两份：
- **快速档**：轮数 8、评稿关、便宜模型 → 日常推进；
- **深度档**：轮数 24、评稿开 1 轮、旗舰模型 → 关键剧情。

### 🎲 工具开关
「工具开关」折叠区里可以关掉不想让它用的工具（比如不想让 AI 主动摇骰就保持 `dice_roll` 关闭——默认就是关的）。写文件/发布/收尾这些核心能力恒开，关不掉。

## 五、设置项速查

| 设置 | 默认 | 说明 |
|---|---|---|
| 轮数上限 | 16 | 一回合最多几次模型调用。写不完会按已发布版保留（见"部分成功"）。日常 8~16 够用 |
| 工具调用预算 | 40 | 一回合最多执行多少次工具。耗尽会催它立刻交稿 |
| 工具协议 | 自动 | 自动＝优先函数调用、报错自动降级文本协议；老/杂中转可直接选「仅文本协议」 |
| 评稿子代理 | 关 | 开了更稳但更贵；1 轮足够 |
| 复用正文 API | 关 | 默认完全独立，勾上才共用正文接口 |

提示词想自己调？预设中心里搜「Agent」：**成稿契约**（正文必须长什么样）、**收尾铁则与流程**、**评稿人**（⚠ 首行 PASS/REVISE 协议别改坏）三条都能编辑、能恢复默认。

## 六、常见问题 & 排障

**Q：报「Agent 正文模式需要独立 API」？**
还没配接口。去设置里给它配独立 API，或勾「复用正文 API」。

**Q：报「模型未按工具流程工作」？**
模型不会用工具、一直直接吐正文（系统会纠偏几次，实在不行才报这个）。对策：① 换支持函数调用的模型；② 协议切「仅文本协议」；③ 点 ⟳ 重新生成再试一次。

**Q：显示「⚠ 部分成功（已保留成稿）」？**
正文已经发布过、但没走完收尾流程（比如轮数耗尽）。**正文有效、数值照常结算**，只是跨回合备忘没保存。想减少这种情况就调高轮数上限。

**Q：为什么比平时慢/贵？**
每一轮调用都携带完整上下文，这是 Agent 模式换取质量的固有成本。省钱技巧：轮数调低、评稿只开关键局、给 `agent` 路由挂高性价比模型、用"快速档/深度档"两套档案按需切换。

**Q：会影响我原来的玩法吗？**
不开就**零影响**。细纲、剧情指导、数据库推进、召回、世界书这些照常生效（它们的产物会带进 Agent 的第一轮）；⟳ 重新生成、↩ 回退、分支树也照常。唯一差别：Agent 模式下"思维链预填"自动跳过（与工具调用互斥）。

**Q：正文里会不会混进工具调用的痕迹？**
不会。成稿契约明确要求正文只写正文；工具过程只出现在时间线里。万一某回合翻车，⟳ 重生成即可。

| 日常推进 | DeepSeek V3 / Gemini Flash 级 | 8~12 | 关 | 自动 |

玩得开心。有玄学问题先看时间线的错误码，再去开发者面板翻本回合的每轮请求日志。
